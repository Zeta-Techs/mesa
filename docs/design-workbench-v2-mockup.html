1底色统一 + 左缘语义微锚点

分组底色从过浅的气泡色回到全站统一的 .ccode-well；仅在项目「等你 / 在跑 / 出错」时亮一道 2.5px 左缘色线，0.2 秒扫出重点，零整卡染色。

2任务行「双区对齐」，视线不折返

现状的状态灰字紧跟在长短不一的任务名后，起点参差不齐；改为「左任务名 · 右侧状态+呼吸光标 · 定宽等宽时间」，扫读像表格一样顺滑但无表格线。

3卡点收进暗槽，组尾动作降噪

「卡点」从散落的黄字收成内嵌浅暗条；「＋ 记下一个目标」平时降到 60% 静默微字、悬停项目时亮起；无事项目化为可点胶囊而不是顿号长句。

4右栏拍板行内直达 + 定时去描边

「等你拍板」用琥珀光标标需要你定的事、绿色标待验收成果，行内直接给轻量「允许/去评审」；「定时任务」改左时刻右详情，「现在跑」悬停才露。
