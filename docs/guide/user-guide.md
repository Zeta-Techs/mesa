## 1 全局约定

Mesa 是装在电脑上的 **AI 科研工作台**：把本机的终端 AI 管起来，围绕一个课题文件夹干活。

- 可以接九家：Claude Code、Codex、Gemini CLI、Qwen Code、OpenCode、Kimi Code、CodeBuddy Code、Cursor CLI、Grok Build。装一家就够。
- 界面叫 **Mesa**，数据文件夹仍叫 `ccode`（课题里的 `.ccode/`、家目录下的 `~/ccode/`）。备份、换电脑按这个找。

三条贯穿全部页面的规矩：

| 规矩 | 含义 |
|---|---|
| **课题是家** | 对话、步骤、文件、定时任务都挂在课题文件夹上，不挂在某次聊天上 |
| **成稿走副本** | 要进课题的正式成果在隔离的工作副本里做，你评审后才合并；随口问一句用「＋新对话」，那直接改课题文件夹 |
| **密钥不出门** | 界面只显示尾号；默认只注入到这一次运行，不改电脑上 CLI 的全局配置 |

产品为什么这么设计，见 [docs/architecture.md](../architecture.md) §10 决策记录。

### 1.1 界面总览与快捷键

左边是侧栏，从上到下四段：

- **Mesa** 字标（点击展开 / 收起为图标）
- **工作入口**：工作台、新对话（点一下就是一段空白对话，右键看最近的随手聊）、运行、对话。有 Agent 在跑时，「运行」行尾出现绿点和数量
- **项目**：「项目」标题行（右侧 **＋** 添加项目）→ 课题超过 5 个时出现搜索框（Esc 清空）→ 按 **科研 / 编程 / 工作 / 未添加** 分组的课题列表，组头可点收起，收起状态下次打开还记得。课题多时列表自己滚动。鼠标移到课题行上，右侧出现 **⋯**（右键同一份菜单）：置顶、在终端打开、重命名、在访达中显示、复制路径、从 Mesa 移除、清除痕迹、删除目录。置顶的课题单独排在最上面的「置顶」组
- **资源与管理**（底部一条细线隔开）：连接、技能、MCP、用量、设置

点课题直接进它的项目页；点「工作台」回总览。正在看的课题在项目页时铺底色高亮；切到别的页时它只保留加粗，提醒你「上次在哪个课题」。把侧栏收成图标后，工作入口下面多一个**文件夹图标**，和其他图标一样只管「去项目页」（悬停显示当前课题名）；换课题用顶栏左边的**项目芯片**——点旁边的 ⌄ 打开项目切换面板：顶上是搜索框，打开就能直接打字筛（命中的字会加亮，结果右边标着科研 / 编程 / 工作）；不搜的时候按分组列出，组头可以收起，和展开态侧栏的收起状态是同一份；课题超过 8 个时最上面先给「最近」打开的 5 个。当前课题打勾，有 Agent 在跑的标绿点。**↑ ↓** 选、**回车**进去、**Esc** 先清搜索再关面板；右上角也能直接添加项目。

**顶栏左边**会随侧栏形态变：侧栏展开时这里是空的——项目和运行状态侧栏里都有，不再重复。侧栏收成图标后，这里常驻**项目芯片**（不在项目页时点名字回到那个课题，已在项目页时点名字直接打开切换面板；点旁边的 ⌄ 总是打开切换面板），以及有 Agent 在跑时的**活动芯片**。侧栏展开时，有 Agent 等你确认，「运行」那一行的点会变黄、写着「N 待确认」。

**活动芯片**写着「2 运行中」或「1 待确认 · 3 运行中」（有人等确认时变黄）。点开是正在跑的 Agent 列表：等确认的排最前、标黄，每行写着标签名、哪家 Agent、在哪个目录、现在的状态（待确认 / 工作中 / 已回复）。点哪行直接跳到那个终端标签；最下面是「打开运行页」。在 Mesa 之外的终端里跑的会话这里只报个数，没有标签可跳。

**完全隐藏侧栏**（⌘\ / Ctrl+\）后，顶部中间是一枚**灵动岛**。平时它只报状态：你在哪一页（图标加页名，比如「▢ 运行」），有 Agent 在跑时后面接一句「2 运行中」（有人等确认时变黄写「1 待确认」），某个 Agent 刚跑完或断开会短暂冒一句播报。鼠标移上去岛展开成可操作的一排：最前面是 **恢复侧栏**，然后是全部页面，最右边是可以点开的活动胶囊和播报。这时项目芯片常驻在顶栏左边，是隐藏侧栏时唯一的切项目入口。

**右键菜单和 ⋯ 菜单**全应用长得一样：每项前面有图标，同类动作挨在一起，删除、清除这类收不回来的动作统一沉在最下面、用红字并和上面隔开一条线。打开后可以直接用 **↑ ↓** 选、**回车**执行、**Esc** 关闭；灰着点不了的项，悬停会说明为什么。

**确认框**也是统一的样子：顶上一句加粗的问题；要是这一下会影响好几样东西，下面会列一张小表写清每样的去向——绿色是「保留」，红色是「彻底删除 / 不可恢复」，其余照常；最后一条「注意」放提醒。删除、清除这类收不回的操作，确认按钮是实心红色、写的是要做的动作（「删除」「清除」「移除」），**默认选中的是「取消」**：顺手按回车只会关掉框，真要执行请点红色按钮（或按 Tab 移过去再回车）。

| 操作 | Mac | Windows / Linux |
|---|---|---|
| 切换九页 | `⌘1` – `⌘9` | `Ctrl+1` – `Ctrl+9` |
| 命令面板 | `⌘K` | `Ctrl+K` |
| 打开设置 | `⌘,` 或菜单栏 Mesa → 设置… | `Ctrl+,` |

顶栏右边、命令面板左边有一个「**?** 帮助」按钮。点开是三组入口：**使用**（使用教程、产品说明书）、**支持**（反馈与提需求、报告安全问题、诊断与日志）、**应用**（检查更新、关于 Mesa）。带 ↗ 的三项在浏览器打开对应页面，其余四项都在应用里弹窗完成，用法见 [1.6](#16-帮助菜单反馈诊断检查更新与关于)。菜单用 Esc 或点空白处关闭。

**外观**：Mac 和 Windows 上左侧栏与顶栏是磨砂的（壁纸透出），右侧工作区是不透明圆角面板；Linux 上为实心。系统开「减少透明度」时回到实心。透明度在 **设置 → 外观 → 侧栏 / 顶栏透明度** 调：一排六格 **全透 / 25 / 50 / 75 / 85 / 原样**，点一下立即生效，可以对着左边的侧栏直接比。「原样」是主题本来的样子（默认），越往左越透出桌面磨砂；「全透」完全不铺罩色，选中那一行只剩文字和图标变色，花哨或深色壁纸下不好辨认。经验上：纯色或柔和的壁纸可以往 50–75 调，照片类壁纸留在 85 或原样。选中行的底色会跟着一起变淡；侧栏里的搜索框是一层薄雾，任何档位都不会变成一块实心的框。

**Mac 菜单栏**（仅 macOS）：屏幕顶部的系统菜单栏有 Mesa 的命令入口——「Mesa」菜单里的**设置…**（⌘,）与**命令面板**（⌘K），「窗口」菜单里的最小化 / 缩放 / 全屏 / 关闭，「帮助」菜单里的 Mesa 文档与反馈问题。Windows 和 Linux 没有菜单栏惯例，同一批命令走上表快捷键。

### 1.2 三种工作方式

添加项目时选一次，**界面里之后不能改**（表单上写「已选定，不可更改」）。要换就另建项目。

| 方式 | 适合 | 主画面 |
|---|---|---|
| **科研** | 文献、实验、论文 | 步骤（或目标）+ 文献 + 文件 |
| **编程** | 写代码、开分支、PR | 工作树 |
| **工作** | 工作文档、日常材料 | 目标 + 文件预览 |

设计文档里第三种叫「工作」，不是「办公」。

### 1.3 两条路：＋新对话 vs 开始 / 新建目标

这是最容易用反的地方。

| 你想 | 用这个 | 它改哪里 |
|---|---|---|
| 问一句、改个别字、解释一段 | 项目里 **＋新对话** | 直接改课题文件夹 |
| 出一版要收进课题的成果 | 步骤 **开始**，无流程时 **新建目标** | 隔离工作副本，你验收后合并 |

**＋新对话** 不会把「未完成的目标」「验收后才进项目」这些塞给 AI。它只知道：这是哪个课题、里面有什么、规则是什么、你这次说了什么。这一段开场说明叫**对话注入**，觉得长或不想带，在 **项目设置 → 对话注入** 里可以改成自定义或关掉（见 3.3）。

### 1.4 待处理（收件箱）

窗口顶上（Mac 在标题栏）出现 **待处理** 和数字。要你拍板、处理的事在这里：

| 类型 | 例子 |
|---|---|
| 待确认 | Agent 在等你确认一条命令 |
| 可合并 | 步骤做完了，改动可以合并 |
| 冲突 | 工作副本和主文件夹改了同一处 |
| 更新 | Mesa 自己有新版本 |
| 人工请求 | Agent 写了求助条（补检索词、某篇下不到） |
| 依赖 / 配置失效 | 环境缺东西（如 git）、定时任务用的连接已不存在 |

另有几类**通报**：文献新命中、待核验、待发送、技能（内置技能有新版这类）。

点进去是一句话 + **去处理**。全部处理完，图标自己消失。

通报类条目（文献、可合并、待核验、待发送、技能）可以点收件箱**右上角的「全部已读」**一次收起——标题栏收件箱下拉、工作台「待你处理」标题行、项目页待处理下拉里都有。**待确认、冲突、依赖、更新、配置失效、人工请求不会**被它收走：这些要你逐条拍板，收走了就没人看见了。被收起的条目状态一变（比如又有新命中）会自己回来。

**不会进这里的**：Agent 说完一轮等你下一句——那是每天都发生的事。

### 1.5 状态与图标对照

| 图标 / 文字 | 位置 | 意思 |
|---|---|---|
| 绿点 | 工作台项目卡、侧栏项目树 | 这个课题此刻有 Agent 在跑 |
| 黄点 / **待确认** | 工作台「待你处理」、顶栏**待处理** | 有事等你处理 |
| 虚线转圈圆 | 运行页标签 | 悬停写「生成回答中」。它停了只代表这一轮说完，不代表 Agent 退出 |
| 黄点 ● | 运行页标签 | 悬停写「待确认」。没激活的标签要悬停或聚焦才看得见 |
| 实心强调色小圆 | 步进器名称旁 | 这一步你主要负责。悬停写「这一步主要靠你」 |
| 灰点 | 步进器名称旁 | 你和 AI 一起定。悬停也是这句话 |
| 无点 | 步进器 | 主要是 AI 做 |
| 圆下小字 | 步进器大圆正下方 | 这一步现在的状态：进行中 / 等你确认 / 等你查看 / 待评审 / 有冲突 / 已完成 / 已归档；没开始的不写 |
| ✓ / 已存 | 待获取行 | 这篇 PDF 已收进 `papers/` |

**操作结果提示**：点完一个动作，页面顶部会出现一条浅底提示条，左边的图标说明结果——绿色对勾是成功，蓝灰 i 是说明，琥珀三角要留意，红色叉是失败。第一行加粗的是结果，下面几行灰字是你需要知道的补充（比如「获取了多少模型」下面写「名单不会自动改」）。看完点右边 **知道了** 收起。右下角弹出的小提示是同一种写法，字多的会停留更久。

### 1.6 帮助菜单：反馈、诊断、检查更新与关于

顶栏「**?** 帮助」里，除了三个带 ↗ 的网页链接（使用教程、产品说明书、报告安全问题），其余四项都在 Mesa 里弹窗完成，不用离开应用，也不会跳到设置页。

#### 反馈与提需求

把遇到的问题或想要的功能直接发给 Mesa 开发者。

1. 选 **类型**：功能需求、缺陷、疑问、其他。选「缺陷」会在详情框里铺好「做了什么 / 预期 / 实际」三行，照着填；没填的行发送时自动去掉。
2. 写 **标题**（一句话说清）和 **详情**。两样都填了，右下角的发送按钮才能点。
3. 需要时加 **附件**：
   - **截图**：直接粘贴到详情框，或点「截图」选文件。最多 3 张、单张不超过 2MB；加进来显示缩略图，右上角 × 移除。
   - **诊断包**：点「诊断包」，现导出一份脱敏诊断包挂上（系统与运行信息、最近日志，不含密钥和环境变量）。报缺陷时附上它，定位会快很多。
4. 「附上版本、系统环境与最近的错误日志」默认勾着。点 **看看会附什么** 能逐字看到附带内容，不想附就取消勾选。
5. 在底部选 **发送方式**，再点右下角按钮：

| 发送方式 | 按钮 | 点了之后 | 附件 |
|---|---|---|---|
| 邮件应用 | 打开邮件应用 | 本机邮件应用打开写好的邮件，收件人、主题、正文都已填好，你点发送 | 带不了：存到下载文件夹，需要你在邮件里手动添加 |
| 网页邮箱 | 打开 Gmail 等 | 浏览器打开你选的邮箱（QQ / Gmail / Outlook / 163）。Gmail、Outlook 正文已预填；QQ、163 只打开邮箱首页，全文已复制好，粘贴即可，收件地址在表单里点「复制」 | 同上 |
| 邮箱直发 | 发送 | 用你自己的邮箱从 Mesa 里直接发出，开发者回信直达这个邮箱 | 截图和诊断包作为真实附件 |

Mesa 会记住你上次选的发送方式。邮箱直发第一次使用时按钮显示「配置邮箱…」，配置方法见下一节。

**怎样才算做成**：邮箱直发提示「已用 … 发送」，表单清空并关闭。邮件应用和网页邮箱是交给别的程序发的，Mesa 不知道你发没发，所以表单底部会出现一条提示：有附件时给出「打开截图文件夹」「诊断包：在访达中显示」（Windows 是资源管理器）；发出后点 **已发出，清空草稿**，还没发就点 **还没发，保留**，草稿留到下次。

左下角 **复制全文** 把主题和正文一起复制，粘贴到微信、GitHub Issue 等任何地方格式都不散。不要贴 API 密钥或 token：诊断包已脱敏，但你自己复制的终端输出可能还带着。

【配图】反馈表单：发送方式选「邮件应用」，附件里有一张截图和一份诊断包。

#### 配置邮箱直发

发送方式选「邮箱直发」后点 **配置邮箱…**（配过之后点提示行里的「修改」）。

1. 选邮箱服务商：QQ、163、126、Gmail、Outlook，或「自定义」后填服务器地址和端口。
2. 填 **发件邮箱** 和 **授权码**。授权码不是登录密码，要在网页版邮箱设置里开启 SMTP 服务后生成；输入框下面写着对应服务商在哪里开。
3. 点 **保存并测试**。Mesa 当场连一次邮箱服务器验证授权（不发信）：通过就回到表单，以后直接点「发送」；没通过，原因写在按钮上方——授权码不对时会列出逐条排查步骤。

授权码只存在本机（仅你本人可读的文件），界面不会再显示。换邮箱或换服务器要重填授权码。配置页底部 **清除配置** 删掉邮箱与授权码。

#### 诊断与日志

出了问题、准备反馈之前先打开这里。

- 中间是本次运行以来最近 100 条应用日志，最新的在最下面，时间按本机时区（鼠标停在时间上看日期）。标题旁写着有几条错误、几条警告；点 **错误与警告** 只看有问题的。右边两个小按钮：刷新、复制当前列出的日志。
- 点右下角 **导出诊断包**，几秒后上方显示「诊断包已导出到下载文件夹」和文件名，点「在访达中显示」能找到它。
- 导出之后右下角变成 **附到反馈…**：直接打开反馈表单并带上这份诊断包（此前类型还是「功能需求」且详情没动过时，类型自动切到「缺陷」）。
- 左下角 **依赖体检与配置快照** 跳到设置 → 诊断，那里查 Git、Node.js 等依赖是否装好，也能导出当前生效的配置快照。

日志只存在内存里，重启 Mesa 就清空；要留下证据，请导出诊断包。

#### 检查更新

点开就当场向 GitHub 查一次（启动时已经发现新版本则不再重查），结果都在弹窗里：

- **已是最新版本**：写着当前版本和平台，可以点 **重新检查**。
- **发现新版本**：显示新旧版本号和更新说明。点 **下载并安装**，弹窗里有下载进度，装完 Mesa 自动重启，进行中的对话请先保存；有后台任务在跑时会先问你。下载过程中弹窗不能关。
- **检查更新失败**：写明原因，多数是连不上 GitHub。点 **重试**，或点 **去发布页下载** 到 GitHub 手动下载安装包，覆盖安装后设置与数据都在。
- 开发版不检查更新，弹窗会直接说明。

已经知道有新版本时，帮助菜单「检查更新」一行的末尾会标出版本号。设置 → 更新走的是同一套流程。

#### 关于 Mesa

显示应用图标、版本与平台（如「v0.9.3 · macOS · Apple 芯片」）。版本旁的复制按钮把这一行复制下来，报问题时贴上。下面一行是更新状态，点它进入检查更新。

- **GitHub 仓库**：在浏览器打开源码、发布记录与 Issue。
- **开源许可与致谢**：在同一个弹窗里打开许可页。「致谢与数据来源」写着 Mesa 用到的字体、图标、文献数据来源和设计参考，很长的许可全文默认收起，点「展开许可全文」查看；「组件许可」列出随安装包分发的全部第三方组件，可以按名字或许可搜索（比如输入 MPL）。左下角 **返回** 回到关于页。

### 1.7 命令面板（⌘K）

不想找按钮时，按 `⌘K`（Windows / Linux 是 `Ctrl+K`）打开命令面板，打几个字、回车就到。

**打开会看见**：快速操作（新对话、新建项目…、添加已有文件夹…，有新版本时还有「安装 Mesa vX」）、最近打开的 5 个项目（行尾写着科研 / 编程 / 工作）、九个页面（行尾是切页快捷键，改过快捷键这里跟着变）、外观（切换主题…、显示 / 隐藏侧栏）、帮助（反馈与提需求、诊断与日志、检查更新、关于 Mesa）。

**搜索**：直接打字，结果按匹配程度排序，标题开头对得上的排在前面。下面这些平时不列、搜得到：
- **更早的项目**：打项目名或路径里的一段。
- **设置分区**：打「设置」列出全部分区；也可以打你想改的东西，比如打「代理」会出现「设置：网络」，行尾写着命中的词「代理」。
- **单个主题**：打主题名（如「琥珀」）直接切换。
- **使用教程、产品说明书、报告安全问题**：在浏览器打开，行尾有 ↗。

**切换主题**：选「切换主题…」打开主题格子，和设置 → 外观里的主题卡长得一样：上排深色、下排同名浅色、最下面是自定义配色，正在用的那格右上角打勾。方向键在格子间移动（↓ 从深色跳到同名浅色），回车切换；也可以直接打主题名筛选。输入框为空时按 ⌫ 或 Esc 回到全部命令。开着「跟随系统深浅」时内置主题收敛成一排「配色」（自定义那一节仍在），选的是配色，深浅仍随系统。

**键盘**：↑↓ 移动（到底会绕回顶部），回车执行，Esc 关闭。用拼音输入法打字时，选候选词的那次回车只上屏，不会误执行命令。

## 2 工作台

进来第一眼。左边是你手上的活，右边是等你拍板的事，下面是最近的项目和对话。

**正在进行 / 最近在做**

| 状态 | 显示 |
|---|---|
| 还没有课题 | 空态：**从一个项目开始** + **添加项目**（点了跳到项目页） |
| 有课题、有 AI 在跑 | 标题 **正在进行**，大卡上课题名 + 实心 **继续工作** |
| 有课题、此刻没人在跑 | 标题 **最近在做**，点大卡上的 **继续工作** 回到上次停下的地方，不是新开一轮 |

终端标签关掉不等于扔掉：点 **继续工作** 按那一次运行找回。有一种情况接不回：上次那一轮你还没跟 AI 说一句话就关掉了，或者 AI 刚启动就退出了——这时 AI 还没把对话存下来，没有可接的内容。Mesa 会在原目录直接开一段新对话，并在右下角提示一句，不会再报「No conversation found」后退出。

大卡里的 **上次停在** 一行，是这个课题最近一次对话里你对 AI 说的最后一句话，帮你在点 **继续工作** 之前想起当时让它干什么；点这一行会打开那段对话。大卡下面是其他手上有活的课题，排在同一块里、一行一个：课题名旁边的小标签是工作方式，后面一句是它现在的状态（如「整理数据待验收」）。有 AI 在跑的行首有绿点，等你确认的是黄点，没事不画点。点整行同样是继续，鼠标停在行上能看到它的「上次停在」。

**记下一个目标**

「正在进行」这一块下面有一行小字 **＋ 记下一个目标**。点开是一行输入框：想到一件要交给 AI 的事，写一句话点 **记下**（不记了点 **取消** 或按 Esc），它会作为一个目标记进所选项目，**不会马上开工**。之后到那个项目的目标列表里，选好 Agent 再点 **开始**。

- 只有能用目标的项目才出现在可选范围里：工作项目，以及选了「不使用研究流程」的科研项目。编程项目用工作树开发，不在这里记。
- 只有一个可选项目时，输入框右边直接写「记到「项目名」」；有多个时可以下拉切换，默认选当前大卡上的项目；大卡项目不能记目标时，默认选你最近用过的那个。
- 记下时用的是项目页「新建目标 → 记下」的默认设置：整个项目当资料，做完由你验收再写回。要只带部分资料、或只想让 AI 讨论不写文件，请直接到项目页用 **新建目标** 展开 **资料和 Agent** 设置。

**待你处理 / 待你验收**（有内容才出现，宽屏在右侧，窄屏在下方）

- **待你处理**：收件箱前几条。条目属于某个项目、而正文里没写项目名时，行尾会用小字标出项目。冲突、待确认、人工请求这类要你拍板的条目，处理按钮一直显示；文献新命中这类通报，按钮在鼠标移到行上时才出现。
- **待你验收**：目标跑完等你勾选的，排在「待你处理」下面，点一条直接打开它的验收。

打开 Mesa 停在工作台时，「待你处理」就是完整的，不必先去项目页转一圈；有 AI 跑完，这里也会跟着更新。

**最近项目 / 最近对话**

页头右上角有次要按钮 **新对话**，和侧栏、⌘K 里的是同一个，用法见 [8.1 新对话](#新对话随手问一句)。

## 3 项目页

点左侧栏里的课题进来，整页是当前课题的工作面；换课题直接点侧栏里的另一条，不用退出去。

### 3.1 项目列表（左侧栏）

- 位置在左侧栏中段：搜索框在上面，下面按 **科研 / 编程 / 工作** 分组（组头可点收起 / 展开），还没添加的仓库单独一组，组头写 **未添加**，沉在最下、默认收着，点组头展开。当前打开的课题有底色高亮。
- 名字左边：这个课题里有 Agent 在跑是绿点，悬停写「运行中」；没事不画点。要你处理的黄点不在这——看顶栏**待处理**和工作台。
- 添加课题在 **项目** 标题行右侧的 **＋**，点开是 **新建项目…**、**添加已有文件夹…** 和 **创建示例课题**（右边标着「演示」）。**新建项目** 不弹系统选文件夹窗：填项目名（也是文件夹名），默认建在「文档」里（可点 **更改位置…**），选好工作方式点 **创建**，Mesa 建好文件夹并登记。**添加已有文件夹** 是先选电脑上已有的文件夹，再填名字和工作方式。一个课题都没有时，项目页空态上也有 **添加项目** 和 **✦ 创建示例课题** 按钮。
- 鼠标移到课题行上，右侧出现 **⋯**；点它或右键课题行，都是同一份菜单，分四组：**置顶 / 在终端打开 / 重命名项目**；**在访达中显示**（Windows 叫「在资源管理器中显示」）**/ 复制项目路径**；**从 Mesa 移除**（只摘掉登记，文件夹和工作区都不动）；红字的 **清除 Mesa 痕迹… / 删除项目目录…**（前者保留文件夹、清掉 Mesa 留下的东西，后者整个目录进回收站）。移除、清除、删除都会再让你确认一次。
- **置顶**：常用的课题点 ⋯ → **置顶**，它会从原来的分组里挪到列表最上面的「置顶」组（按置顶先后排），再点 **取消置顶** 放回去。置顶只记在这台电脑上，不改课题本身。**在终端打开**：在运行页开一个终端标签，目录就是这个课题，适合直接敲命令。

### 3.2 添加项目

| 步骤 | 界面 |
|---|---|
| 1 | 系统选目录窗口（没有文件夹先在访达 / 资源管理器建一个） |
| 2 | **添加项目** 表单：路径、**项目名**、**工作方式**（三选一） |
| 3 | **添加** / **添加中…** |
| 4 | 科研项目接着弹 **选择研究流程模板** |

**选择研究流程模板**

- 首句：「「项目名」已添加。写论文请挑一套流程；只读文献、写笔记，选下面的「不使用研究流程」。」
- 可先填 **课题主题（可选）**，占位示例「如 GLP-1 受体激动剂的心血管结局」。填了以后每次开工都会带给 AI。
- 每张模板卡写着名字、步数徽标和一条路径：

| 模板 | 步数徽标 | 卡片上的那一行 |
|---|---|---|
| **英文综述** | 5 步 | 文献检索与筛选 → 精读笔记 → 大纲 → 初稿 → 润色定稿 |
| **科研论文** | 8 步 | 计算实验向实证论文：文献检索与筛选 → 精读与研究空白 → 实验设计 → 执行 → 分析 → 论文大纲 → IMRaD 初稿 → 投稿准备（湿实验/问卷需自改实验步） |
| **数据处理** | 4 步 | 数据登记与质量检查 → 清洗整理 → 探索性分析 → 结论与建议报告 |
| **毕业论文** | 8 步 | 文献检索与筛选 → 精读笔记 → 开题报告与综述 → 研究方法 → 实验执行 → 结果分析与章节 → 全文初稿 → 格式与定稿 |
| **投稿与返修** | 2 步 | 首投：期刊格式适配 → 投稿材料；返修：按轮次回复审稿意见 → 修订稿 → 再投稿清单。徽标按首投那两步计。点进去先选 **首投** 或 **返修**；返修再填 **返修轮次**，每一轮是单独一步 |
| **LaTeX 论文** | 4 步 | 把已有成稿转成 LaTeX（也可从笔记从零写）：搭骨架 → 章节写作 → 编译排错 → 定稿导出 PDF |

- **不使用研究流程**（只读文献）/ **稍后再选**（只关弹层，项目页还会提醒）。

**项目全局设定**

选中模板后进填写屏，标题是「「模板名」的项目全局设定」。英文综述问五项：综述角度、目标篇幅、读者与文风、去向、综述深度。都是自由填写。

- 空着的项会以「名称：（提示）」留在项目设置的规则里，也出现在每一步任务书的**待确认的全局设定**；AI 开工或跟你商量时会先逐项问你。
- 按钮：**‹ 换个模板**、**暂不填写，稍后补充**、**保存设定并应用模板**。
- 综述深度分 **标准档** 与 **严格检索档**；界面上注明「严格检索档不是系统综述」。

### 3.3 项目设置（顶栏 ⋯）

科研项目这个抽屉从上到下是：

| 分区标题 | 里面有什么 |
|---|---|
| **基本** | **项目名**（**重命名**）、**课题主题**（**编辑**）、**项目路径**（**复制**） |
| **规则与验收** | 折叠的 **规则**、有记录才出现的 **验收记录 N**、折叠的 **对话注入**——和编程 / 工作项目同一节。验收记录一条一行：「文献检索与筛选 · 文件已进入项目 · 2 个文件」，右边是多久前；定时巡检的写成「文献雷达 · 巡检已采纳」。悬停看版本号和文件清单；你写过备注的，下一行是备注 |
| **研究流程** | 「当前 N 个步骤」+ 主按钮 **选择模板** / **更换模板**；下一行是 **另存为模板** 和 **不使用研究流程**（点前会再确认一次） |
| **文献与数据（N）** | 默认折叠（刚添加的项目会自动展开一次）。展开后文献来源只读，旁边写「在流程线里改」。进料是 **从 Zotero 导入**、**导入 RIS / BibTeX**、**重新扫描目录** |

没有研究步骤时，**规则** 展开后还有 **写回时跳过** 和 **技能**。有研究步骤的科研项目不显示这两块。工作方式不在这个抽屉里。按 **Esc**、点遮罩或右上角 ✕ 都能关掉抽屉。

**对话注入**（三套项目都有，折叠着）解决的是：＋新对话、问 AI，以及编程页工作树「进入」、定时巡检开聊——这些**直接开聊**的入口开头那段项目说明（课题名、目录、顶层文件清单、课题主题、规则、长期知识……），有人嫌长、有人想换成自己的写法。展开后是三个圆角选项：

- **自动**（默认）：系统按档案卡现拼，你什么都不用管。
- **自定义**：自己决定开头说明里带哪些项目信息，再补几句你自己的话。切到自定义后看到两样东西：
  - **带上哪些项目信息**：一排可点的标签——项目基本信息（项目名、工作方式、项目目录）、文件地图、课题主题、工作环境、项目规则、人的决定、技能纪律、长期知识、已验收。亮着带勾的会带上，点一下取消，再点一下带回。悬停标签看这个项目**现在**这一段是什么；勾着但当前为空的标签后面写「（空）」，开对话时自动省略。顺序是固定的，不用自己排。第一次切到自定义时全部勾上，和「自动」一样。
  - **我的补充（放在说明末尾）**：一个普通文本框，写你想每次都交代给 AI 的话，例如「回答用中文；改代码前先列出计划」。不写也行。
  - 点标签立刻保存；补充在离开文本框时保存。想调整段落顺序或逐字改版式，点 **编辑源文本**，换成整份模板原文（`{{项目规则}}` 这类花括号段每次开对话按项目当时的内容填入，段与段空一行），改完点 **回到勾选**。源文本改成了勾选放不下的版式（顺序调过、文字夹在中间）时，勾选区会写明「用勾选改不了」，给你 **编辑源文本** 和 **改用勾选**（项目信息按固定顺序排、其余文字并进「我的补充」，不丢字）两条路。改乱了点 **恢复默认模板**（会先问你一句）。
- **不注入**：开对话只带你说的话，AI 不认识项目背景。

展开 **预览下次注入**，看到的就是下一次开对话实际发出去的全文：它跟着你正在改的档位和模板走，停手不到半秒就刷新，不用先点别处保存；开着的时候改了规则或长期知识，点右边的 **↻** 按项目当前内容重新读取。编辑框失去焦点、切换档位时自动保存，旁边闪一下「✓ 已保存」；直接按 Esc 或点遮罩关掉抽屉，没存的改动也会补存。显示「（不注入：开对话只带你说的话）」就是关掉了。做成标准：预览内容和你想要的一致，再开一条新对话，开头出现的说明与预览相同（从文件行、文献资源点「问 AI」是例外：开头那句的项目名按既有行为填那份文件或资源的名字，预览按项目名显示）。注意两点：模板被你清空时「自定义」不生效，仍按自动来（界面会写明）；开工任务书、「验收后写入」这些走评审的注入不归这里管，不会因此变样。写错的花括号（比如 `{{不存在的段}}`）会原样发出去，界面上会点名提醒；单独成行的 `----` 是应用拼接「你说的话」的分隔符，写进模板会让 AI 分不清说明到哪里结束，界面上同样会提醒。

**稿件载体** 不在项目设置里。打开 **编辑研究流程**，折叠标题是 **稿件载体与外部工具（按需选择）**（没有稿件那一项时写成 **按需补齐交付**）。选项是文献库、数值图、结构 / 装置示意、稿件载体（Markdown / Quarto、LaTeX（原生源码）、已有 Word（人工插件验收））。

编程项目和工作项目的 **项目设置** 少一层「基本 / 研究流程 / 文献与数据」：第一节标题 **规则与验收**（规则；工作项目在没有研究步骤时同样有 **写回时跳过** 和 **技能**；下面是 **验收记录 N**），同一节里还有折叠的 **对话注入**（用法见上），接着是 **项目长期知识**（默认折叠，标题旁边写着有效条数；展开后可人工确认结论、修订、作废）。按 **Esc** 或点遮罩也能关掉。

### 3.4 项目页签

页签钉在课题名下面，划到文件或任务底部也能直接切。每个课题记住你上次停在哪个页签。

三种工作方式都是这五个页签。任务那一页的名字随方式变：

| 工作方式 | 任务页签 | 这一页是什么 |
|---|---|---|
| 科研 | **科研任务** | 有流程是步骤线；点过 **不使用研究流程** 且没有步骤时，是目标列表 |
| 工作 | **工作任务** | 目标列表 |
| 编程 | **编程任务** | 分支地图：基准分支在最上面，工作树和本地分支挂在它下面，每条写着比基准领先、落后多少个提交 |

另外四个都叫 **对话 / 定时任务 / 文件 / Agents**。

**对话页签**：只列这个课题的对话。CLI 还在运行的对话，标题前有一个绿点；停在「等你确认」的换成黄点；在研究步骤工作区里聊的对话，标题右边写是哪一步（例如「文献检索与筛选」），编程项目写工作树名，主文件夹里的对话不标。悬停一行出现 **继续 / 重命名 / 归档**。

**Agents 页签**：给这个课题定「谁干什么」。每家 CLI 一张卡：设为**项目默认**、挑这条 CLI 在本项目用的连接和模型（只影响本课题，不动配置页）。卡下面列出分到这家 CLI 的目标。下面再分三组，标题和名册一样，卡片也和名册一样（名字在左，右边是状态标签）。**专属绑定**留空跟随项目默认，三张卡是 **项目对话**（只给项目「对话」页的 **＋ 新对话**；已经有的对话点继续仍回到原来那条）、**问 AI / 聊想法**（科研项目：文件问 AI、跟 AI 商量任务书、聊想法都走它。编程和工作项目这张卡只叫 **问 AI**，没有聊想法）、**沉浸阅读对话**（只在科研项目。文件页点「沉浸阅读」后，右侧对话栏自动开的会话用它，下次进入生效。编程和工作项目不出现这张卡）。再下面**定时任务**也是同样的卡片，一条一张，右边标已指定或跟随默认；没钉连接的卡上写着这次实际会用哪条（课题的项目默认；课题没设默认时写「运行时再决定」，改用设置页的 AI 专用配置；项目默认那家不能跑定时任务时写「项目默认不能用于定时任务」，运行时同样改用设置页的 AI 专用配置）；没有任务就不出现。科研项目有步骤时铺开 **科研步骤**；另外建过的目标仍出现在 **目标** 里，可以改这一条的连接。没有研究流程时这一组叫 **新建目标**。工作项目是 **工作目标**，同一套。编程项目是 **开工**，列出工作树，都用项目默认，不能按树改，也不出现沉浸阅读对话。某一步绑了，开工弹层和「AI 干活」行上的「继续」（AI 没在跑时出现，接着把这一步做到完成标准，新开一轮）会优先用它；AI 正在写或等确认时这一行只有「去终端看看」，回到正在进行的对话；「跟 AI 商量一下」这类讨论入口不吃步骤绑定，保持全项目一致的商量体验；步骤改名/换模板可能让绑定失效，失效条目带 ⚠ 可清）。

## 4 科研任务页

有研究流程时是步骤线，没有时是目标列表。

### 4.1 步进器

- 顶上一排大圆，每一步一个，名称用学术习惯叫法（文献检索与筛选、综述大纲…）。
- 名称旁的小圆点见 [1.5](#15-状态与图标对照)。悬停写的是「这一步主要靠你」或「你和 AI 一起定」，不是「你来」。
- 步骤卡头部另有文字徽标 **你来** / **一起**（主要是 AI 做的那一步不标）。悬停分别是「这一步主要靠你，AI 打下手」「这一步你和 AI 一起定」。
- 图例在步进器右上，整条流程里出现过对应角色才画：**角色提示**、**你主要负责**、**你和 AI 一起定**。
- 每个大圆正下方一行小字写这一步现在的状态：**进行中**（AI 在跑）、**等你确认**（AI 停在一个要你点确认的地方）、**等你查看**（AI 这一轮说完了，在等你看）、**待评审**、**有冲突**、**已完成**、**已归档**。还没开始的步骤不写字，整排都没开始时这一行不占位置。

**N 处改动未存入历史**：步进器下方右侧这行小字，是你在项目文件夹里改过、还没存进历史的文件（点开能 **存进历史** 或 **打开改动**）。下一步 AI 的工作副本从最近一次存入历史的内容建出来，没存的改动它看不到。Mesa 自己的项目档案（`.ccode/` 里的项目设置、任务书草稿，以及 `.gitignore`）不算在内：开工前和打开评审时 Mesa 会自己把它们存进历史，不用你操心。

### 4.2 当前步骤卡

点某个圆，下面出现当前步骤卡。没有内容的行不出现。有的话，从上到下是：

1. **确定文献来源**（这一步要问文献从哪来才有）
2. **稿件载体**（这一步会换正式稿才有；不挡着点「开始」）
3. **先定几件事**；还有没答的写成 **先定几件事（还有 N 件）**（配置了开工前要定的事才有）
4. 开工前的人工事项，一行一件，标题就是事项名
5. **AI 干活：{这一步的名字}**
6. 进行中和收尾的人工事项，标题仍是事项名。没有单独一行叫「收尾」或「你要做的事」
7. **你核对后，保存进项目**。这一行的按钮才是 **去评审**
8. 一条分隔线，左边只写 **可选**。下面是保存进项目之后才做的事，例如 **同步到文献库**、**继续精读笔记**（按钮 **去笔记夹**），以及不挡开工的工具项

标了可选、但仍排在上面主干里的人工事项，行尾有 **可选**。分隔线下面那一段本身就叫可选，行上不再重复这个字。前提排在 **AI 干活** 之前。

左侧强调色竖线标的是**现在该做的那一行**。**确定文献来源** 选了别的来源、或这一步已经开工，就算交代过（默认的「让 agent 检索」开工后也算），竖线会往下走到 **去评审**，不会一直停在来源那一行。做完的行左边是空心圆、文字变淡；只有打勾的人工事项才划删除线，**AI 干活** 做完不划掉。

**精读那一步的进度**：精读开工后，**AI 干活** 下面多一行小字，例如「已写笔记 42 / 199 篇 · 全文 30 · 仅摘要 12」。按 `notes/index.json` 数：标成已读完的才算写完，只按摘要记的单独计数（补到全文后再精读）。AI 还在写时大约每 20 秒刷新一次，切回 Mesa 窗口也会刷新。

### 4.3 主按钮状态

这些字出现在对应那一行的右侧，不是整张卡只有一颗按钮：

| 按钮上写的 | 在哪一行 | 什么时候 |
|---|---|---|
| **开始** | **AI 干活** | 这一步还没开过工 |
| **开读这一篇**，旁边仍有 **开始** | 同上 | 只在示例课题的精读步，而且已经有 PDF。这时 **开读这一篇** 是主按钮，**开始** 缩成次要 |
| **去终端看看** | 同上 | 只在 AI 正在写或等你确认时出现。回到那次对话。和下面的「继续」不会同时出现 |
| **继续** | 同上 | AI 没在跑（包括已经跑完，左边会写 **Agent 已跑完**）时，占掉「去终端看看」的位置。新开一轮，用这一步在 Agents 里绑的配置（没绑则用「问 AI / 聊想法」那条，再没有就用项目默认）。这一步自己的工作区卡片上不再重复一颗「继续」。上次会话是另一家 Agent 时先问一句： **带上上次对话**（用户原话逐条原文带上，助手正文附在文末；配了提炼模型时再加一节「要接上的结论」，不改写原话）或 **不带，直接开**。同一家则不问 |
| **恢复工作区** | 同上 | 这一步的工作副本已收起，占掉「开始」的位置 |
| **去评审** | **你核对后，保存进项目** | 有产出可以看。AI 正在写回答或等你确认时先藏起来 |
| **去处理冲突** | 同上 | 工作副本和主文件夹改了同一处，占掉「去评审」的位置 |
| **提交产物** / **提交中…** | 要你交文件的人工事项 | 这一行有落点、还没完成。悬停是「选文件提交到落点 …；也可直接把文件拖到这一行」 |
| **去笔记夹** | **继续精读笔记** | 保存进项目之后才能点 |

**开始** 的悬停提示是「直接开工也行，AI 会在对话里问你缺的信息」：上面的待定项都不拦着开工。

### 4.4 先定几件事

有的步骤在开工前就能定几件事（篇幅、读者、实验规模等），节点写成 **先定几件事** / **先定几件事（还有 N 件）**。

| 方式 | 怎么用 |
|---|---|
| **方式一 · 直接选择** | 展开 **直接选择（N 项待定）**；都答完了，这一行改成 **直接选择（已定）**。点选项，或点 **全部用推荐值**。选项不合适时是 **其他…**（没有预设选项时是 **写一句…**），写完点 **记下**，拿不准点 **开聊** |
| **方式二 · 和 AI 商量** | 展开 **和 AI 商量（可选）**，点 **跟 AI 商量一下**。AI 通读任务书、逐个问你，按回答改任务书 |

商量过之后按钮变成 **继续讨论**，接回上次那条对话，不新开一轮。没有决策项的步骤不标「方式二」，**跟 AI 商量一下** 直接挂在 AI 那一栏。

**哪些问题会在这里问、哪些不会**

| 问题类型 | 出现位置 |
|---|---|
| 决定后面每一步（篇幅、读者、去向、目标期刊） | 项目层的全局设定，每步任务书自动带上 |
| 开工前就能答、答了影响执行 | 步骤的决策项，就是这里 |
| **要先看到数据才定得了**（纳入标准、精读力度、分析粒度） | 不在这里。AI 跑起来后拿数字，写进收件箱「人工请求」问你 |
| 只有人能做（下载付费全文、放入成稿） | 人工事项 |
| 三选一的稿件载体、用哪套软件交差 | 用得上的那一步才问 |

只有卡片上标明必须批准的问题，不答才不能点 **开始**。

### 4.5 想法卡

| 按钮 | 作用 |
|---|---|
| **聊想法** | 回到这张卡上一次的对话；没有对话才新开 |
| **◈ 沉淀进任务书** | 只在这一步还没开工时出现。AI 先写出要追加的结论，你改完再写入任务书 |

### 4.6 人工事项

只有人能做、且做完会在项目里留下痕迹的事。步骤卡上每一行有勾选框，标题就是事项名。做法写在行下；长了才收进 **怎么做**。标 **可选** 的，不做也能往下走。

**怎么做 / 落点** 出现在开工确认层里的人工事项清单：展开后有做法，有落点的再写「落点：…（放到这里系统会自动勾上）」。

综述检索步这三件：**配置学术检索 MCP**、**核对待确认篇目**、**下载付费墙文献全文**。精读步（综述、科研论文、毕业论文三套模板）有一件可选的 **抽查 3 篇笔记**：AI 交付后，这一行下面直接列出挑好的三篇，点开对照原文看。定稿步这三件：**更换引用样式**、**逐条决定审查报告**、**逐条裁决 [待核实] 与存疑条目**。逐项说明见教程对应章节。

### 4.7 开工确认层

点 **开始** 不会立刻跑，先弹确认层，标题是 **开始 {步骤名}**，标题行右边小字写这一步的工作区名。右下是 **取消** 和主按钮。

层里每一行左边一个小标签、右边是内容，从上到下：

| 标签 | 界面上的字 |
|---|---|
| 读入 | 这一步开工时项目里已有的输入，例如「included.md · 6 篇」「papers/ · 27 篇」。缺的必读文件写成「文件名 · 还没有」（黄底）。点芯片在下面看文件开头 |
| 产出 | 这一步要交的文件名 |
| 执行 | 一行身份「Agent · 连接 · 模型」，旁边 **更换**。这一步在项目 Agents 页绑过**专属默认**时直接用绑定的（旁边标「· 本步骤默认」）；没绑按项目默认/上次开工用的。还没有能用的连接时写「还没有可用连接。」，链接是 **去添加** |
| 思考档 | 这条连接能设思考档时才有，默认「不设（用绑定默认）」，只影响这一次 |
| 技能 | 这一步挂的技能，可 × 去掉或 **＋ 添加技能**（改动写回这一步，以后开工都用）。下面一行小字「已启用到 {Agent}」；技能没装或没分发到所选 Agent 时，换成一块「技能与工具检查」，写明缺什么，旁边 **去技能页分发** 和 **重新检测**，必需技能没就绪时主按钮点不了 |
| 权限 | 「可写：步骤工作区、项目根 papers/（原始文献）」。悬停看完整说明：清洗后的数据、图、成稿写在步骤工作区，经你评审后才合并进项目 |
| 任务书 | **查看 TASK.md**，展开可改这一次。改过之后旁边标「已改」，可以 **恢复默认拼装** |
| 开工接驳 | 主仓里有没存进历史的清单新行（纳入清单/待获取清单）或笔记时出现，**默认已勾上**：「开工接驳：清单 N 条新行 / M 篇未提交笔记」。勾着＝开工前先把这些存进历史，本轮直接用得上；取消勾选＝按现状开工（它们不进本轮，也不拦合并，开工后仍可从改动面板存进历史） |
| 积累芯片 | 「读入」行出现「积累 N 条」＝项目积累清单（`papers/reading-list.md`）的条数，N 为 0 不出现 |

右下主按钮的字，按这个顺序取第一个成立的：

| 按钮 | 意思 |
|---|---|
| **开始中…** | 已经在建工作副本，或正在把改过的文件存进历史 |
| **先加连接** | 这个课题还没有能用的 AI |
| **仅开始准备** | 当前决定只允许做准备 |
| **先做无依赖工作** | 有决定还没批准，再确认一次也只能做不依赖那些答案的部分 |
| **仍要开工** | 上一步还有收尾事项没勾，或这一步要读的上一步产物还没保存进项目。第一次点的仍是「确认开始」，点过之后变成它，再点才真开 |
| **记下并开始** | 你改过本步要读的文件还没存进历史。点了先存进历史再开工 |
| **确认开始** | 上面都没有时的正常开工 |

**换连接与「存为本步骤默认」**：点 **更换** 展开三列（Agent / 连接 / 模型）改这一次。旁边有勾选 **存为本步骤默认（下次开工直接用它）**——勾上才把当前选择记为这一步的默认；不勾只是这一次用用，原有的步骤默认不动。已经存过默认又改选时，下面会写明「已存默认 X；本次用 Y」。清除某一步的默认去项目 **Agents → 专属绑定 → 科研步骤**。

**上一步还没保存进项目**：这一步要读的文件，是前面某一步的产物、而那一步还在进行、等你评审或有冲突没解决时，层的最上面会出现一块提醒：「上一步「…」AI 已交付、等你评审，还没保存进项目。这一步要读的 included.md、… 现在还是项目里的旧版。」右边是 **去评审**（有冲突时是 **去处理冲突**），点了关掉这层、直接打开那一步的评审。下面一行写「建议先保存进项目再开工；要按现状开工就点「确认开始」，按钮会再问你一次。」——和收尾提醒一样，第一次点「确认开始」只是表态知情，按钮变成 **仍要开工** 再点才真开。

**上一步收尾提醒**原话：「上一步「…」还有 N 件收尾事项没完成（…）——跳过审阅直接开工，上一步要返工时这一步也得跟着作废。」还没点过时接着写「建议先回去过完再来；确认跳过就点「确认开始」，按钮会再问你一次。」点过之后改成「再点一次「仍要开工」即继续。」

**有待拍板**时层里写「待拍板：…」。硬暂停时按钮点不了，后面写「硬暂停：…。待补或不批准不能开工。」只允许准备时写「当前决定只允许准备，不能当作正式开工授权。」软暂停时写「软暂停：建议先回答；再次确认只允许先做不依赖这些答案的工作。」

### 4.8 决策暂停策略

每一步的任务书里有一段 **决策暂停策略**。编辑研究流程时，这一项的三个选项是：

| 选项 | 意思 |
|---|---|
| **一般问题可按可逆兜底继续** | 默认 |
| **软暂停：未答需二次确认，只推进无依赖工作** | 没答完只能做不依赖答案的部分 |
| **硬暂停：结构化决策全部回答后开工** | 题没答完不能当正式开工 |

写进任务书的正文是这三句之一：

- 「hard_pause：遇到新的待拍板问题，写入 .ccode/help-wanted.md 并暂停本步骤，等待人明确答复后继续；不得自行采用推荐值或「未回复即继续」。」
- 「soft_pause：遇到待拍板问题，写入 .ccode/help-wanted.md 并暂停受影响的操作；只可推进无依赖、可逆的部分，等待人明确答复后恢复受影响的操作。」
- 「auto_continue：一般问题写入 .ccode/help-wanted.md 并附可逆兜底方案，可按兜底继续；涉及目标/对象范围、关键处理规则、结论范围、隐私、伦理、合规、主指标或不可逆操作时必须等待人明确授权，不得默认同意。」

下面接着「本步中途没有必须等人拍板的事项。」或「本步必须停下来等你：」，条目来自这一步的拍板题和人工事项。有交付后才轮到你的事，再写「达到完成标准后交给你（不要自行宣称已通过）：」。最后一句固定是：「一批工作、一次 git 提交或进度汇报不是停工理由；未达完成标准且不必拍板时，用户没说停就继续。」

写完一批、git 提交、报个进度不在停工清单里。

| 情况 | 怎么办 |
|---|---|
| 它在该停的地方停 | 按收件箱或卡上的提示拍板 |
| 它不该停却停了 | **不要点「开始」**。用当前步的圆或工作台 **继续工作** 回到原来那个终端，说「不必拍板就做到完成标准」 |
| 上下文写满后它又停一轮 | 再回一句即可 |
| 它需要你补信息 | 收件箱「人工请求」；点 **去终端回答** 回到那次对话答复。不回，它按每条后面的兜底继续 |

### 4.9 评审页

点 **去评审** 打开。页签按步骤类型不同，**最多三个**：

| 步骤类型 | 页签 |
|---|---|
| 检索 | **清单 / 过程 / 文件** |
| 精读 | **笔记 / 过程 / 文件** |
| 大纲、初稿、定稿 | **稿件 / 过程 / 文件** |
| 实验、分析、清洗（产物含复现入口或质量报告） | **结果 / 过程 / 文件** |

**文件** 页签看增删；**过程** 看 AI 的做事记录。

**稿件** 页签：

- Word 在 PDF 前面；PDF 标签会提示先看是否乱码。
- 顶上黄字扫描提醒：摘要含 [待核实]、正文含空白编号（G1…）、N 处「待绘制」。
- 意见框：直接写，或在稿件里划一段点 **加进意见**（追加到同一个意见框）。
- **退回修改**（接回原来那条对话，按意见改现稿）/ **按意见重写**（同一工作区新开会话，按大纲和笔记重写）。两者都**不保存进项目**。

**保存进项目**

| 按钮 | 什么时候 |
|---|---|
| **提交并保存进项目** | 有未提交的改动 |
| **保存进项目** | 没有待提交的改动 |

提交信息可以留空，Mesa 会写一句很短的默认说明。

**冲突**：两边改了同一处时按钮变成 **去处理冲突**，按文件在「任务分支 · {分支名}」和「主分支 · {基准分支}」两栏里点 **选用**，也能一键 **全部任务版 / 全部 {基准分支}**；要逐行掺，去预览编辑器手改。主文件夹自己还有未保存进历史的改动时，合并会被拦住，评审里可以就地先存进历史。只是 Mesa 自己的项目档案（`.ccode/`、`.gitignore`）有改动时，打开评审 Mesa 会先替你存进历史，不会拦你。

**保存进项目只表示文件进了课题，不等于你接受其中的科学结论。**

### 4.10 裁决与审查报告

润色、定稿、期刊格式适配、返修会先写一份**审查报告**，不改正文。

| 控件 | 说明 |
|---|---|
| **接受** / **拒绝** / **修改** | 逐条点。选 **修改** 必须写一句要改成什么样（「修改时写一句」） |
| **全部接受** | 一次接受全部 |
| **让 Agent 按决定继续** | 全部点完后出现，回到这一步原来的对话改稿 |

拒绝的不改。改了数字、因果、样本或结论范围，会单独列在修改记录的「科学改动」里。

**逐条裁决** 是另一件事：只处理定稿里还标着 [待核实] 的句子，以及引用检查里疑似编造、元数据存疑的条目；没有条目时写「勾上跳过」。每条填完「裁决：」才算完成。

### 4.11 完结文件

每一步都保存进项目之后，项目卡上才出现 **完结文件**。后来追加了步骤、那些步骤还没做完时，这块先不出现。

分组：最终稿 / 可以接着改的稿 / 图 / 文献从哪来 / 核对与修改 / 精读笔记。每份文件左边是文件页同一套类型标，右边是名字；附图和精读笔记先显示篇数。笔记点开后每行是论文题名，右边是对应 PDF，没有全文写「无全文」。上面的框用来收窄。

### 4.12 不使用研究流程：目标

科研任务页的标题是 **目标**。空的时候写「这次想完成什么？」，说明是「写清要交付的成果，再选择资料和 Agent。」

**新建目标** 弹层里，输入框上方写 **要完成什么**。可以先点 **记下**（进行中写成 **记下…**），也可以直接点 **开始**（进行中写成 **正在准备…**）。默认权限是 **写入并验收产物**，旁边还有 **只讨论**。展开 **资料和 Agent** 才能改资料、技能、权限和用哪家 AI——选完 Agent 和连接后还能点 **模型**（不点用这条连接的默认档）。这个模型跟着目标走：开工、重试都用它。

目标跑起来之后，卡片上是 **继续**。跑完等你看时，按钮写 **验收产物**，分组标题是 **待验收产物**。打开后勾选要留下的，右下是 **带着意见再出一版**（意见框旁注「不满意再出一版」）和 **接受 N 项**；一项都不勾是 **不带回产物，完成**。失败或停掉之后，原来的「开始」变成 **重试**。已经完成的可以 **再来一版**。点卡片上的 **详情** 能看历程：「生成 → 意见 → 第 2 版 → 已接受」，每一版和每条意见旁写多久前（悬停看具体时刻）。收进 **已归档** 之后可以 **恢复**，也可以 **删除**。删除只把这条从已归档里去掉，项目里已经接受的文件还在；还有内部副本时要先 **释放副本空间**。

文献雷达在 **定时任务** 页，PDF 在 **文件** 页。工作方式选「工作」时，同一套列表的按钮换成 **验收文档**、**待验收文档**、**采纳 N 份**、**不带回文档，完成**。

## 5 定时任务页

上半是 **文献雷达**（仅科研类课题；还没建雷达巡检任务时这一块不出现，删巡检会连它的关键词一起删），下半是定时列表。雷达巡检全部停用时，卡头在「上次巡检」旁标 **已暂停**：列表还在，但不会再有新命中，到下面的任务行重新打开开关。

### 5.1 文献雷达：订阅

雷达卡头的图标按钮只留看文献用的：**订阅**、**筛选新命中**，再加一枚指标表按钮——没装时写 **下载表格**，装了写 **表格**（有新版时带一个小圆点）。跑巡检、看历史都在下面的定时列表里，卡头不再放 **立即跑** 和跳到列表的时钟。**订阅** 打开订阅表，一行一条，**＋ 加一行** 加、行尾 **×** 删：

订阅行只有一个框：**关键词**（占位「关键词，如 mixture-of-experts」）。arXiv、OpenAlex、Crossref 三个库都会查，每次回看最近 7 天、已见过的自动去重，不用挑也不用填窗口——想限定库、改时间窗或加网页检索，用下面的 **编辑源文件** 手写。

保存只作用于这一条巡检。同一个项目里两条巡检各有各的关键词。没有任何订阅、也还没攒下命中时，卡头写「文献雷达 · 还没订阅读」，旁边是 **订阅关键词**。关键词被清空、但雷达已经攒下命中时，整张卡照常显示以前的命中，上面另起一行黄字「还没有订阅关键词：下面是以前攒下的命中，巡检不会再有新命中」，旁边是 **订阅关键词**。还没建雷达巡检任务时这一行整个不出现。多条巡检时，关键词从每条巡检行上的 **关键词** 打开。删除巡检时，这一条的关键词一起删除。

**编辑源文件**：在弹层里直接编辑这一条巡检的订阅源文件，不跳页。文件还不存在时先建一份只有格式说明的空清单；已经存在时一个字都不改（表里没保存的改动也不带过去）。

### 5.2 定时巡检

**＋ 定时巡检** 打开「定时巡检」弹层，三选一：**文献雷达**、已有的巡检技能、新建巡检技能。雷达的说明是「按周期跑文献雷达，新命中追加到 notes/inbox.md。」建好后在这一行点 **关键词** 添加，每条巡检互不影响。频率选 **每天** / **每周**，列表里显示成「每天 09:00」「每周一 09:00」。自建巡检技能在 SKILL.md 里声明 `provides: lit-watch` 也能点亮雷达卡，但新增计数、待采纳评审这些雷达专属能力只认内置的「文献雷达」技能。

| 项 | 说明 |
|---|---|
| 运行配置（可选） | 界面原话：「文献雷达选 Codex。没有后缀的只在课题目录里写。写着「会批准全部操作」的不要用于定时巡检。」（新建弹层是完整三句，编辑任务时只有前两句）第一项是 **跟随项目默认**：用这个课题 Agents 页设的默认连接和模型；课题没设默认、或默认那家不能跑定时任务时，改用设置页的 AI 专用配置（再没有就用最近用过的连接），历史里会写明这次为什么换了。Agents 页「定时任务」组的卡片上直接写着这次会用哪条。旁边还有**模型**下拉（跟随项目默认时不出现可选项；钉了连接后模型不在名单会自动用名单第一个并在历史里写明） |
| 跑在哪 | 隔离目录，不直接改课题文件夹。雷达卡上有一块「N 篇新命中待采纳」，右边是 **去评审** |
| 跑完 | 「待处理」出现「有 N 条新命中待评审」+ **去评审**。评审只列**这一次**运行新收的命中（以前各次已评过的不重复出现），一篇一行，带影响因子、分区和中文一句话。**留下**是你的标记，**排除**＝这篇不进项目。看完点 **采纳进项目**（先确认，保存前查保护路径、备份原文件）：只把这一次新收、没被你排除的命中**接在**项目收件箱后面——项目里已有的内容一字不动（你手动改过、删过的，另一条雷达收进来的，都照旧），同一篇已经在收件箱里的不再重复加；连着几次没采纳的，可以按任意顺序分别采纳。这一次新下的免费全文 PDF 进 `papers/`（被排除那篇的不进）。从定时任务页点进去的，左上角返回回到这个项目的定时任务页 |
| 采纳后 | 历史这一行多了 **已采纳** 标记，按钮变 **查看**：再点开是只读回看——当时的命中和你的留下/排除还在，但不能再改、不能再采纳。「待处理」里这次推送**只占一条**「有 N 条新命中」，点 **去看看** 跳到这个项目的文献雷达卡，想读哪篇在卡上自己挑。没跑完（取消/超时/失败）的运行没有评审内容 |
| 影响因子 | 只在雷达卡的 **筛选** 里设：不限、IF≥5、IF≥10、仅 1 区、仅 TOP。点一项立刻过滤这次命中。对不上指标的不再显示。不写入科研任务的检索步骤 |
| 列表一行 | 开关、任务名、周期、技能、运行配置在同一行。任务名旁可能标 **排队中**：到点了但还没轮到它——不同课题的巡检会同时跑，同一课题一次只跑一条，另外全局同时在跑的定时运行不超过两条（手动点 **立即跑** 不占这个额度），空出来就自动接上，不用管。**历史** 靠右。**立即跑** 和 **⋯** 悬停才出现；正在跑时停止按钮留下。文献雷达还没有关键词时 **立即跑** 不可点，订上关键词后才能跑 |
| 历史 | 点开才在这一行下面列出最近几次；有隔离产物、还没采纳的右边是 **去评审**，已采纳的显示 **已采纳 · 查看**。悬停行尾出现 **✕** 可删除这一条运行记录（历史行、冻结证据和运行账目一起删；已采纳进项目的产物不受影响）。删除整个任务时，它的运行记录、证据和隔离目录会跟着清干净 |
| 应用没开 | 不跑。下次打开后第一轮自动补跑（漏多次也只补一次）。补跑时不同课题的巡检同时开跑，不用一条等一条 |
| 超时 | 单次上限 30 分钟；历史里标 **⏱ 超时**，和失败分开 |

### 5.3 雷达上怎么读

雷达只处理**新命中**：你的积累清单（`papers/reading-list.md`）和流程的纳入清单（`papers/included.md`）都不在这张卡上，前者在卡内的「积累 N」抽屉和文件页，后者归流程管。

- 默认一条：标题截断一行 + 中文一句话 / 期刊 / **发表日期**；英文摘要点开才见（展开后还列作者）。
- 列表上方常驻一排**关键词胶囊**（竖条 + 词名 + 条数）：你订阅的词全在——没命中的也显示 0；「关联推荐」是雷达自己荐来的那批。点一枚只看这个词命中的文献（列表仍按日期分段），再点一下或点 **全部** 回来。想只看某段时间，点上面的趋势柱子；关键词、趋势选柱、搜索三者可以叠加。
- 一条两行。第一行是标题（`papers/` 里已有全文的条目标题前有一个小文件图标，点标题直接打开 PDF），右边是 **推荐** / IF / 分区、TOP 徽章。第二行是中文一句话，右端平时是来源和日期，悬停原位换成操作按钮：**加入积累**、**解读**、**打开来源**、**⋯ 更多**。点 **打开来源** 后按钮变成「收货中 ✕」——浏览器里点站方下载，90 秒内落下的 PDF 自动收进 `papers/`，点 ✕ 取消等待。
- **加入积累**把这篇记进课题的**积累清单**（`papers/reading-list.md`，一份只属于你的日常账：不进 git，永远不影响任何流程步骤，也不会拦合并）。记完不跳转——分诊节奏不断，想读的时候去积累清单。已经在清单里再点一下书标，会在抽屉里**定位到这一篇**（高亮一下）；移除在抽屉里做（行尾悬停 ✕），雷达行上不放移出。还没有全文的命中留在雷达上，用 **打开来源** 或 **关联本地 PDF**。雷达卡上有一格 **积累 N**：点开是抽屉——开头一句话说明角色，每篇一行：有全文的给 **精读**（进沉浸阅读；这篇已经有笔记时按钮显示 **继续精读**，笔记接着已写的补全）、**笔记**（直接打开这篇的精读笔记，还没有就先建档）和 **全文**（预览 PDF），缺全文的给 **关联**（选已下载的 PDF 复制进 `papers/` 并登记）。已在流程正典（`included.md`）里的，书标不动两张账：这篇归流程管，不在积累抽屉里——`papers/` 已存全文时点书标直接打开全文，还没有全文就说明去处（阅读和移出都在文件页）。
- **它和科研流程的关系**：积累清单 git 看不见，流程跑到一半你也照样攒——攒下的条目不进任何已开工的步骤，也不会再出现「主文件夹里还有没保存的改动」把它拦下来；流程中后到的文献就是下一轮的积累。**新开**一条检索/科研流程时，开工确认层会问你「要不要把 N 条清单新行 / M 篇笔记接驳进基准」——同意才把这些一起存进历史、本轮带上；不同意就按现状开工。检索步会把积累清单当作进料口之一，和已有的纳入清单、你手工放入的导入、本轮检索结果放在一起统一去重，不会重复纳入。你先读过、写过笔记的，之后流程里的精读会接着你的笔记补全，不重写。
- **忽略这条**只藏雷达行里这一条（本机记录）。文件本身不删，换一台电脑或清掉本机记录后还会出现。
- 雷达是**日常文献积累**：替你攒着以后的写作资源，不替你读。它收的文献停在雷达收件箱和 `papers/` 的 PDF 里，不写科研流程的精读清单、不进检索那一套 RIS、不动 `references.bib`——科研流程一旦开始，每天的雷达命中不会往流程里加文献。
- 什么时候读由你定：看中某篇点 **加入积累** 攒下来，想读时在「积累」抽屉里点 **精读 / 继续精读**；或者从这批积累上发起文献检索/科研流程，流程里的精读步骤才逐篇读。**某一篇已经有笔记时**（你读过的、或上一轮流程写的），之后的精读会在这份笔记上接着补全优化，你写的「我的想法」「译段」和批注原样保留，不会被重写。
- 评审里的**留下**是你的标记，**排除**＝这篇不进项目：采纳时被排除的条目不会写进收件箱，它的跟进待办和免费全文 PDF 也不进。采纳后进项目的是收件箱和跟进队列（以及这一次新下的免费全文 PDF）；你在 `papers/` 里改过名或删掉的 PDF，之后的采纳不会再拷回来。科研流程的纳入清单、精读索引和 `references.bib` 雷达一概不碰。
- 能免费直接下的 PDF（arXiv 直链、链接以 `.pdf` 结尾）在巡检结束时由 Agent 下到 `papers/`。出版商页和付费墙不下，界面上没有 **获取全文**。
- **打开来源** 在系统浏览器打开。你在站方点下载，90 秒内落下的 PDF 自动收进 `papers/`。
- **命中趋势**通栏画柱，**日 / 周 / 月** 三个粒度随时切换（近 14 天 / 近 8 周 / 近 6 月）；柱子上段亮色是**推荐**篇数、下段浅色是其余。**点一根柱子**只看那个时间桶里的命中——选中态标在趋势图自己的标题行（「日周月」旁边出现如「10月12日周 ×」的胶囊，点胶囊或再点柱子取消）；没命中的柱是灰底座，点不动。趋势数据还少时（有数的周期不超过 3 个）整块压成一句话，点「· 展开图」才出图、**收起**回去，缺日期说明和 **按巡检日补记** 两种形态都在。收件箱没写巡检日期时不画柱，写明缺了几条。旁边有 **按巡检日补记** 时，点一下就按那次巡检的完成日补上，不用论文上的发表日期。还没有可画的命中、同时有一批待采纳时，这一块不出现，只留「N 篇新命中待采纳」。
- 卡头 **筛选** 点开就是选项：**不限**、**IF≥5**、**IF≥10**、**仅 1 区**、**仅 TOP**。点一项立刻生效，再点一次取消。开了筛选后，查不到指标的条目不显示（都查不到时列表会说明并提示点「不限」看全部）。卡头的篇数是筛选后看得到的篇数；趋势旁的小字写「筛掉 N 篇」（同时选了趋势柱时写「另有 N 篇未显示」）。这只过滤雷达里已经命中的列表。

### 5.4 期刊指标表

IF、中科院分区、**TOP** 小标需要先把期刊指标表下到本机：两份 CSV（约 4MB + 2.7MB，来自 ShowJCR）。表有版权，安装包里不带，也不会自动下。下载可能要 1–4 分钟，完成后提示「期刊指标表已就绪（N 种期刊）」。

| 位置 | 入口 |
|---|---|
| 文献雷达 | 卡头 **下载期刊指标表**（下载中写「正在下载期刊指标表」） |
| 检索步清单 | 待确认那一行的右侧；没有待确认时单独靠右 |

检索步清单上的状态文字：

| 状态文字 | 含义 |
|---|---|
| 正在看指标表… | 正在对上游 |
| **指标表已是最新** | 已装，对过上游 |
| **指标表有新版** + **更新** | 上游有新版本 |
| 「没能连上上游，看不出有没有新版。」+ **重新下载** | 连不上 |
| 指标表更新中… / 已更新… / 更新失败… | 点了之后 |
| 正在按 DOI 补期刊名，影响因子稍后出现。 | 条目缺期刊名，正在补 |

没装表时没有这些标签，也不会编数字；设了筛选但表没装时，雷达卡会提示「筛选（IF≥N）需要期刊指标表，装表后才生效」。下过一次之后，这台电脑上的其他课题直接用。

## 6 文件页与沉浸阅读

### 6.1 文件页

左边文件列表（有搜索框和 **刷新**），右边预览。顶上按类型筛：**全部 / 文档 / 表格 / 幻灯 / PDF / 图片**，各带数量（没有那一类的档不出现）；末尾的 **最近** 不是类型，是把文档类文件（笔记、PDF、表格、图片这些）按修改时间从新到旧排出来——想知道 Agent 刚写出了什么，点它最直接。文件有了变动，列表会自己跟上，不用守着刷新按钮；**刷新** 想手动来一次也行，已展开的文件夹会一起重读。

| 操作 | 说明 |
|---|---|
| 点文件名 | 预览；预览头的 ↑ / ↓ 换上一个 / 下一个文件（在编辑器里打字时不会抢方向键），Esc 关预览（焦点在预览里时 Esc 先归预览自己用），× 关闭预览 |
| 悬停 | 文件：**问 AI**；文件夹：**打开终端**。都有 **显示**（在访达 / 资源管理器里定位）。图标排在行尾、临时顶替修改时间，不再叠在时间上面 |
| 右键 | 文件：**显示 / 复制路径 / 删除**；文件夹：**在此打开新终端 / 新建文件夹 / 显示 / 复制路径 / 删除**。删除都进系统回收站，可反悔 |
| **沉浸阅读** 图标 | PDF 和 `.md` / `.markdown` 笔记行有。笔记行会自动配对本篇 PDF，配不上就进不去 |
| **定位**（预览头，搜索或筛选时出现） | 回到目录树视图，展开这个文件所在的文件夹并滚到它这一行——搜索结果看着方便，但想知道它在哪个文件夹里时就点它 |
| 文件名左边 | 类型标记：M↓ 笔记、PDF、{} 数据、⚙ 配置、TeX、RIS 题录等；文件名里带 `.bak` 的备份副本标 **BAK**；认不出的类型画一个灰色文件图标，每一行都有符号，文件名对齐同一列 |
| 文件名右边 | 最近修改时间：「刚刚 / N 分钟前 / N 小时前 / N 天前」，超过 30 天写日期；悬停看具体时刻 |

改了没保存的内容，切换别的文件、关预览、打开或关掉窗口预览之前都会先问一句，不会悄悄丢掉。窗口预览开着时，↑ / ↓ 换文件、点正文里的链接跳到别的文件，大窗都保持打开。

搜索框里按 **Esc** 清掉搜索词。目录太大（2000 项展示上限）或文件太多（只列最新 400 个）时，列表上方会用一行小字说明。

**Markdown 预览**：预览头可切 **阅读** / **编辑**，有未保存修改时显示 ●。阅读态里**双击任意段落**直接切到编辑态，光标落在这一段对应的源码行上——要改哪段就在哪段上双击，不用在源码里翻找（双击链接、图片、代码块上的按钮不算，它们保持各自的原操作）。编辑态自动折行，长中文段落不用横向滚动找位置。

编辑 md 时工具条下面多一排**格式按钮**：**B** 加粗、*I* 斜体、~~S~~ 删除线、`` ` `` 行内代码、• 无序列表、☑ 任务清单、❝ 引用、`<a>` 链接（选中文字再点，接着输入地址）。快捷键同一套：**⌘B / ⌘I / ⌘⇧X / ⌘⇧C**（加粗/斜体/删除线/行内代码，Windows 用 Ctrl 组合）；选中已格式化的文字再按一次解除。在列表行末**回车**自动续下一项（任务清单续的是未勾选的），列表项内容删空后回车就退出列表；**Tab** 出两个空格，用来缩进嵌套列表。• 和 ☑ 互相切换会直接换掉原有列表标记（已勾选的行点 ☑ 变回未勾选），不会叠出两层标记。

阅读态的 **⛶ 沉浸阅读** 进三栏阅读区（见 6.2）；其它文件是 **⛶ 沉浸阅读 / 沉浸编辑** 全宽单栏，Esc 退出。

**PDF 选段「整理为笔记」**：在 **运行页**（终端标签）右侧预览里打开 PDF，选中一段文字，点 **整理为笔记**，这段连同文件名、页码和日期追加到课题的 `notes/excerpts.md`（摘录文件，第一次会自动建；文件页的 PDF 预览暂不带这个入口）。这个课题的精读步骤正在跑时，摘录写进那一步的工作区，并在终端预填「把新摘的选段并进对应文献的笔记」，确认配置后点 **启动**；精读还没开工（或课题没有研究流程）时只写进课题文件夹，不会替你开工——精读开工时这份摘录随开工确认层的「接驳」一起带进去，AI 精读到对应那篇时把选段并进笔记，摘录文件原样保留。

【待核对：HTML、表格、图片、二进制文件的预览细节（沙箱渲染 / 源码切换、缩放、「用系统应用打开」）】

### 6.2 沉浸阅读（三栏）

入口：文件页 PDF / 笔记行的 **沉浸阅读** 图标，或 Markdown 阅读态的 **⛶ 沉浸阅读**（提示「笔记｜PDF｜Agent 三栏，自动配对本篇 PDF」）。示例课题的精读步可直接点 **开读这一篇**。

| 栏 | 内容 |
|---|---|
| 左 | **笔记**，可切阅读 / 编辑（⌘E / Ctrl+E）；阅读态双击某一段直接跳到编辑态的那一行，改译词、补想法不用在源码里翻找。笔记就记在课题里，保存不再弹「改动主仓库」的确认。窄栏里标题字号收小一档，长题名不再占三四行 |
| 中 | **PDF**，可滚动、缩放、选字；工具条上有查找、目录、跳页（见下文） |
| 右上 | **译文**。译完后出现一张卡，和下面的对话分开。**问这段** 把当前译文放进下方输入行，不发送。卡上点 **钉住**，正文页边上会出现一颗可拖动的 **译** 悬浮球：点球展开译文卡（再点或 × 收回球），拖着球换位置（会记住），下次进来还钉着；卡只在 PDF 栏里展开，不会盖住笔记和对话；卡片离球远的那只角上有角柄，拖着改大小（双击恢复自动大小）；卡上点 **回栏** 回到对话上方（终端栏收着时会顺手把它展开） |
| 右下 | **对话**。标题写着 Agent 和模型，右边的 **聊天 / 终端** 切换显示方式：聊天层和终端页的聊天一样（气泡、审批按钮、模型菜单），终端是 CLI 原本的画面；选哪个会记住，下次进来沿用（默认聊天）。每次进入都新开一个会话；Agent 开好后自动发一句「我在读哪篇、笔记在哪」（只发一次），之后说「这篇」「笔记」它就知道指什么。底部状态栏不放提交推送——读文献时用不上 |

两栏之间的分隔条可以拖动，宽度会记住。译文卡底边也可以拖，用来改它占右侧多高（钉在 PDF 上时高度自适应，不拖）。没钉住时收起终端栏，会先出现悬浮球（新译好一段球自己展开）；展开终端栏译文卡自己回栏。顶栏有 **← 返回**、文献题名、收起 / 展开左侧笔记栏和右侧这一栏，以及 **护眼反色**（按文件记忆）。题名取课题题录里的真实题名（精读笔记标题、`notes/index.json`、`papers/included.json`、积累清单、雷达收件箱），雷达下载时被截断的文件名在这里看到的是完整题名；鼠标停在题名上能看到文件名。收起和展开都是平滑滑出滑入，笔记和终端的内容不会闪断，PDF 等栏位停稳后按新宽度重排一次。

**选段浮动条**：**译**、**高亮**、**◈ 问 AI**、**＋ 生词**（选段不超过 60 字时才有）、**⋯**（里面是 **＋ 批注…** 和 **↵ 直接发送**）。

**圈选**（PDF 工具栏）：框一块区域后可 **◈ 发给 agent** 或 **＋ 插入笔记**。

#### 在 PDF 里查找、看目录、跳页

长文来回滚找一句话太慢。PDF 工具条右侧的放大镜（或按 ⌘F / Ctrl+F）打开查找条：输入后自动从当前页往后找，命中处整页都淡淡标出，当前这一处颜色更深；**Enter** 下一处、**Shift+Enter** 上一处，右边显示「1 / 5」这样的计数，**Esc** 只关查找条。查找不分大小写，弯引号、各种短横线、行尾断开的单词（electro- / chemical）都能找到。焦点在笔记编辑器或右侧终端里时，⌘F 归它们自己。扫描版 PDF 没有文字层，查找条会直接告诉你「这篇是扫描件，没有文字可查」。

PDF 自带章节书签时，工具条上会出现 **目录**，点开按层级列出章节，点哪节跳到哪节；没有书签的 PDF 不出这个按钮。工具条中间的页码可以点，输入页码回车直接跳过去。

#### 高亮与批注

读到要紧的句子，选中后点浮动条上的 **高亮**：这句会以黄色底标在 PDF 上，同时以一行 `- p.3 「原文」` 记进这篇笔记的 **标注** 小节（没有这一节会自动建在「译段」前面）。想顺手写一句看法，用 **⋯ → ＋ 批注…**，在弹出的小卡里写完回车，笔记里那一行后面会跟上「—— 你的批注」。

下次再打开这篇，高亮按笔记里记的原文重新画回去，缩放、换窗口大小都不会错位。点 PDF 上的高亮会弹出一张小卡，显示批注，可以 **在笔记里看**（笔记栏收着会展开，滚到那一行闪一下）或 **删掉高亮**（同时删掉笔记里那一行）。工具条上的 **标注 N** 列出这篇的全部标注，点一条跳过去，悬停行尾 **✕** 删除。笔记里直接改、删那一行也算数，PDF 上会跟着变。精读步的 Agent 会原样保留「标注」这一节，你的批注是它写「疑问与待跟进」的线索。

#### 笔记和 PDF 互相跳

笔记阅读态里的页码和图表编号是可点的（虚下划线）：**p.3**、**pp. 12–14**、**第 3 页**、**Fig. 2**、**Figure 2a**、**图 2**、**Table 1**、**表 1**。点页码跳到那一页；页码在「标注」行或「译段」的原文引用里时，还会把那段原文在 PDF 上闪一下。点图表编号会找这张图的图注（编号在行首的那一行），找不到图注就跳到正文第一次提到它的地方，都找不到会在 PDF 栏顶上说一声。反过来，从 PDF 的高亮点 **在笔记里看** 回到笔记。

#### 让 AI 起草笔记

刚建档的笔记八个小节都是空的时，笔记栏顶上会多一行「八个小节还空着」和 **让 AI 起草**。点它，右侧对话栏的 Agent 会按精读笔记的写法通读这篇 PDF，把八个小节写进这份笔记（原地编辑，来源行和「标注」「译段」「我的想法」不动）。写好后笔记栏自动刷新，这一行也随之消失；Agent 还没开好时会提示你稍等。这一行显示「已交给右栏的 Agent」后，如果它没接住，可以点 **再发一次**。

#### 对话栏的权限

右侧对话栏的会话固定按 **请求批准** 启动：Agent 改文件前先问你，即使你本机把这家 CLI 设成了完全访问也一样。用 Claude Code 时，改本课题 `notes/` 下的笔记不用一次次批准，改别处照常先问。没有「请求批准」这一档的 CLI（如 OpenCode、Kimi、Cursor）按它本机的设置走。

**翻译的模型 / 对话栏的 agent**：翻译想快就去 **设置 → AI 与 Agent** 的「按功能单独配置 → 翻译」单独选条快模型（和右栏 agent 各用各的）；右侧对话栏自动开的会话用哪份配置，在本项目的 **Agents → 专属绑定 → 沉浸阅读对话** 指定（留空跟随项目默认）。

**Esc**：圈选模式、查找条、跳页输入、目录和标注列表、高亮小卡里，Esc 先关掉它们；再按一次退出阅读。焦点在右侧对话栏里（终端画面或聊天输入框）时 Esc 归对话栏，要退出就点 **← 返回** 或先点别处再按 Esc。

退出时这次自动开的阅读标签一起关闭（AI 正在生成的回答会被打断），你自己开着的其它终端不受影响。

## 7 对话页

| 位置 | 范围 |
|---|---|
| 侧栏 **对话** | 全应用总账 |
| 项目里的 **对话** 页签 | 只列这个课题的 |

- 列表每条两行：上行标题和时间，下行是哪家 AI、属于哪个项目（随手聊写「随手聊」；已经按项目筛选时不再重复写）。正在 Mesa 终端里跑的对话，标题前有一个绿点；停下来等你确认（批准一个操作、信任目录、切换确认）时换成黄点，回放顶上的「进行中」也换成黄色的 **等你确认**，点它们直接跳到那个终端标签。
- **筛选**：搜索框下面一行是快筛 **⚑ 保留 / 进行中 / 今天**，**更多** 里还有 **近 7 天 / 已归档**。再下面一条 **范围**，点开会把列表换成选择面，从上到下：**全部对话**、**随手聊**；**项目**（已添加的课题，用你起的名字）；**其他目录**（主目录、临时目录、没添加的仓库，默认收着）；**Agent**（点名字就只看这家，点左边的箭头再按项目细分）；最下面 **其他 → Mesa 内部 AI**（后台自动跑的对话，平时不在列表里）。每行右边的数字都是对话条数。选好一项自动回到列表；范围条上显示当前选的是什么，点 × 清掉。
- 点一条才打开回放：你的话在右，AI 在左；AI 每一轮的思考、读文件、改文件、跑命令收在回答上面一行「已工作 X 分 Y 秒」里，点开一步一行（见 [8.1 看 AI 这一轮做了什么](#看-ai-这一轮做了什么)）。方向键换上一条 / 下一条。
- 回放顶上两行：第一行是标题和 **继续** / **提炼简报** / **导出** / **⋯**；第二行是哪家 AI、哪个项目（已添加的项目可以点，直接回项目页）、多久前，右端切换 **对话** / **当前项目改动**。底部那条是 **在外部继续**，以及电脑上装了对应客户端时的 **在 Codex 客户端打开 / 在 Claude 桌面版打开**（见 [7.1](#71-在客户端接着聊)）。
- 标题尽量写成 `月日|类型|主题`；你手改过的标题不会被覆盖。不想自动起名，去 **设置 → AI 与 Agent → 会话自动命名** 关掉；起名用哪份 AI 配置也在那里管（见 [13.5](#135-ai-与-agent--会话自动命名与-ai-专用配置)）。
- 回放右上 **⋯** 分三组：**在外部终端恢复 / 复制恢复命令**；标着「AI」的 **生成摘要 / 接力到… / 提炼接力…**；**瘦身会话… / 导出 Markdown / 导出会话包 / 保留**（**瘦身会话…** 只在 Claude Code 对话带着较多截图时出现，见 [7.2](#72-对话卡在request-body-too-large413)）（保留＝即使 CLI 清掉源文件，这条对话也留快照可读）。源文件已经没了又没保留的对话，前两组是灰的，第三组里的 **导出 Markdown / 导出会话包** 也一样（只剩 **保留** 可用）。
- 列表里**右键一条对话**：**整理**（保留、归档、编辑标题与标签、移到卡片…、导出会话包）、**继续**（在终端恢复、在外部终端恢复、复制恢复命令、Codex / Claude 对话还有在客户端打开、提炼接力…），最下面红字的 **删除对话…**。**移到卡片…** 只在按项目筛选时出现，点了就在原地弹出这个项目的话题卡清单，当前所在的卡打勾，已在卡里时最下面有 **移出卡片**。在范围选择面里展开某家 Agent，右键其下的项目是 **删除该项目全部对话…**（确认框会写明是哪家 AI、哪个目录、共多少个文件）。
- **在外部终端恢复** 和 **复制恢复命令** 的区别：前者用这段对话原来的连接（密钥随一次性启动脚本带过去，用完即删），在 **设置 → 终端 → 外部终端** 选的终端里打开；后者只复制一行命令，密钥不会进这行命令，所以粘到终端里运行时，用的是那个终端自己的全局配置——Claude 对话会换到全局配置的网关和模型上；用 Mesa 连接开的 Codex 对话，终端里没设 `CODEX_API_KEY` 就接不上（复制后的提示会说明）。想原样接着聊，用前者。
- **同一段对话别两边同时开**：你在 iTerm、Ghostty 这类终端里直接运行的对话，也会出现在这个列表里，正在写的标着「进行中」。这时在 Mesa 里点 **继续**，会先问你一句——两个进程接着同一段对话，回复会交错写进同一段记录。先在那个终端里退出（Claude Code 按两次 Ctrl+C）再继续；那边刚退出时可以直接点 **仍在 Mesa 里继续**。
- 换电脑：**导入 / 导出会话包**。导出是对话原文，可能带路径，发出去前自己看一眼。OpenCode 的对话进不了这种包。
- 雷达解读、定时巡检这类后台 AI 在 **范围 → 其他 → Mesa 内部 AI** 里，不会冒充成本课题的讨论。

### 7.1 在客户端接着聊

对话是在 Mesa 里开的，想换到 Codex 客户端或 Claude 桌面版的图形界面继续，不用自己去客户端里翻。

**会看到什么**：回放底部和右键菜单里多一项 **在 Codex 客户端打开**（Codex 对话）或 **在 Claude 桌面版打开**（Claude Code 对话）。电脑上没装对应客户端就不显示；其他几家 Agent 目前没有可接上的客户端，也不显示。工作台里项目行悬停出现的外开图标是同一套，区别是它只打开这个项目目录，**不会定位到某条对话**。

**怎么点**：

1. 点按钮。Mesa 先做一次几十毫秒的检查，一切正常就直接打开，右下角提示「已交给 ××」。
2. 有事要你知道时，会先弹出一层，写明是什么、点了会发生什么：
   - **Codex 客户端不认识这条对话的渠道**（用 Mesa 的 API 连接开的对话常见）：弹层写明会把这个连接的端点和密钥写进 `~/.codex/config.toml`（密钥明文，写前自动备份），点 **写入并打开**。有多个连接都对得上时，下拉里选一个。
   - **Claude 桌面版会换账号**：这条对话是用 Mesa 的某个连接跑的，桌面版会用它自己登录的账号继续，不会走那个连接。点 **打开**。
   - **这条对话还在 Mesa 终端里运行**：两边同时写同一份记录会互相覆盖，建议先在终端里结束它；确实要开就点 **仍然打开**。
3. 被拦下时（没装客户端、这条对话的原始文件已经没了、找不到它原来用的连接）只告诉你原因，没有主按钮。没装客户端时会给下载入口。

**怎样算做成**：客户端窗口里出现这条对话，可以接着发话。两边读写的是同一份记录，客户端里新增的内容回到 Mesa 的回放里也看得到。

**常见卡在哪**：

- 打开后客户端自己提示要登录或网络不通。客户端那边的报错 Mesa 看不到，在客户端里处理完，回来再点一次。
- 想撤销写进 `config.toml` 的渠道定义：连接页 Codex 组头 **⋯ → 撤销上次写入**（回到最近一次写入前的状态；之后又写过别的就要多撤销几次）。
- Claude 桌面版导入失败：多半是桌面版没登录，或这个目录没被它信任，先在桌面版里处理。

### 7.2 对话卡在「Request body too large」（413）

做图、做视频这类要反复看画面的对话，每看一次都会往历史里存一张截图，而且 Claude Code 每次发送都把整段历史连同所有截图重发一遍。几十张之后，每次发送的数据量就会超过网关允许的上限（官方是 32 MB），网关返回 `413 Request body too large`，这段对话再也发不出去。这时点 `/compact` 也没用，压缩请求要带同样多的数据，同样被拒。

**会看到什么**：打开这条 Claude Code 对话的回放，顶部出现一条提示：「这段对话的请求体越来越大」（黄色，下一次发送约 20 MB 以上）或「这段对话的请求体已经过大」（红色，约 30 MB 以上），写着下一次发送大约多大、其中多少张截图占了多少，右边有 **瘦身…** 按钮。提示条只在文件已经很大、且确实有较早的截图可以移除时出现；其他 Agent 的对话没有这个入口。

**怎么点**：

1. 点提示条上的 **瘦身…**，或回放右上 **⋯ → 瘦身会话…**（还没到提示线、想提前处理时用这一项）。
2. 弹层先写明会动什么：较早的几十张截图换成一行文字占位，只保留最近 6 张；你的指令、Claude 的回复和操作记录都不动。写入前会先把原会话文件完整备份。
3. 点 **瘦身并在终端继续**，Mesa 瘦身后直接在终端里接着这条对话；只想处理文件、稍后再继续就点 **只瘦身**。

**怎样才算做成**：结果页写着「已移除 N 张较早的截图，保留最近 6 张」和前后大小（比如请求体 34 MB → 5 MB）。之后在终端里发消息不再报 413。原文件的备份路径也写在结果页，点路径可以在文件夹里看到；同一条对话保留最近 3 份备份，要还原就把备份文件复制回原位置。

**常见卡在哪**：

- **按钮灰着、提示「正在 Mesa 的终端标签里运行」**：先关掉那个标签。终端里的进程已经把旧历史读进内存，只改文件它看不到。
- **提示「最近一分钟内还有写入」**：有进程正在用这条对话（Claude 桌面版或别的终端）。先在那边停止并退出，再回来瘦身；Mesa 不会在有人写入时动文件。
- **对话开在 Claude 桌面版里**：瘦身之后要在桌面版里把这条对话归档再恢复一次，它才会读到瘦身后的记录；Mesa 管不到别的程序里已经启动的进程。
- **被换掉的截图想再看**：在备份文件里。瘦身后 Claude 只记得「这里有过一张截图」，需要时让它重新截图即可。
- **以后少撞**：让 Claude 只截关键画面、把图缩小；截图攒到三四十张时在撞上限之前先 `/compact`，或按阶段新开对话，用文件而不是对话历史交接。

## 8 运行页

一个标签就是一次运行。顶上一排标签。

### 8.1 聊天 / 终端

右侧两个小图标切换，**两者是同一次会话的两种看法**，切来切去字不会丢。点到 **运行** 默认显示聊天；登录、更新 CLI、跑脚本这类只有命令行的标签仍显示终端；你在某个标签上手动切过，就按你选的记住。

| 视图 | 用途 |
|---|---|
| **聊天** | 像常见对话。Enter 发送，Shift+Enter 换行。AI 在干活时，对话末尾有一行 Mesa 的「M▁」标志，标志里的琥珀色光标一闪一闪，后面写着它在做什么（已送出、正在生成回复、正在用某个工具）和已经过去的时间。很长的回复（一千五百字以上）按小标题分节，默认全部展开，点小标题可以收起那一节；普通回答照常排版。用 Claude Code、Codex、Qwen Code、Gemini CLI、Grok Build、Kimi Code、OpenCode 时，AI 正在写的那一段会直接在聊天里一行行出现（字色浅一级），回复再长也会接着往下显示，写完后换成正式排版；CodeBuddy 在终端里也是写完才整段画出，要等写完一整段才出现在聊天里，等待时旁边有 **看实时输出**，点了在下方露出终端。你在终端里敲的 `/model`、`/effort` 这类命令，在聊天里显示成一行灰字「命令 + 结果」，不当成你说的话。Codex 的 `/status` 这类命令只显示在终端里、不记进会话文件，聊天里的这条「命令 + 结果」取自它刚显示完时的终端画面，只在这次打开的聊天里保留；命令处理完，「正在生成回复」就会收起，不会一直挂着。代码块上方一条头栏写着语言名，鼠标移上去出现 **复制**。提到的项目文件可以点，在右侧改动里打开；文件不在本次改动里时改成打开文件预览。回复里提到本机的音频文件（mp3、wav、m4a、aiff 等）时，正文下方出现一个播放条，点了就能听，能暂停、拖进度、重播，这是终端做不到的。想听某个词的读音，可以对 AI 说「把读音存成音频文件」（在 Mac 上它一般会用系统自带的 `say -o` 存成 .aiff），存好就能在聊天里点着听；直接让它「读出来」，声音只会从电脑扬声器放一遍，聊天里留不下。Windows 放不了 aiff 格式，播放条会提示改用别的播放器。AI 等你确认时（批准一个操作、信任目录、切换确认），对话最末尾、紧挨输入框出现一张确认卡，按钮就是它在终端里给的选项原文（比如「Yes / Yes, and always allow… / No」），点哪个就替你在终端里选哪个。技能和 MCP 菜单只插入提示，**不替你按发送** |
| **终端** | 各家 AI 自己的界面，登录、权限确认、`/model` 都在这里 |

#### 看 AI 这一轮做了什么

AI 回答一个问题，中间往往要想一会儿、读几个文件、改几处、跑几条命令。这些步骤收在回答上面的一行里，比如「已工作 4 分 13 秒 · 改了 2 个文件 · 运行 3 条命令」；有哪一步没成功，后面再跟一句黄字「1 步没成功」。最后的回答照常显示在下面，平时只看回答就够了。

点「已工作…」这一行展开，一步一行：

- **思考 · 8 秒**：它想了多久。点开看它想了什么。
- **编辑 LitWatchCard.tsx src/components/ +2 −2**：改了哪个文件、在哪个目录、加了几行删了几行。点开是改动前后的对比，红底是删掉的行，绿底是加上的行；文件在这个项目里时，下面有 **在改动里查看**，在右侧改动面板里打开这个文件。新建的文件写「写入」或「新建」。
- **运行 跑前端测试 npm test**：AI 给命令写了说明时先写说明，命令跟在后面。点开是命令和它的输出。
- **查阅 · 读了 3 个文件，搜索 2 次**：连着的读文件、搜索并成一行，点开逐条看，每条还能再点开看结果。
- 没成功的那一行，行尾写红字 **失败**；你在确认时拒绝了的写 **被拒绝**，被打断的写 **已中断**。
- AI 中途说的话（比如「先把文案改成白话，再跑验证」）夹在这些步骤中间，和正文一个样子。

- AI 列了计划（待办清单）时，过程最上面是一张 **计划** 卡：打勾的是做完的，实心点是正在做的，空心圈是还没做的，卡头写着「计划 · 2/5 已完成」。它改计划时卡片原地更新，不再一行行重复「更新待办」。
- AI 用命令看文件、搜内容（比如 `sed -n`、`rg`、`ls`）也算 **查阅**，并进上面那一行；真正改东西、跑测试的命令才算「运行」。
- 还在跑的那一步，行尾写灰字 **进行中…**。

AI 还在干活时，这一轮不收起，做到哪一步就往下加一行；这一轮做完，自动收成「已工作…」那一行，再点开随时能看。对话页的回放也是这样显示。

#### 等你确认时：先看清它要做什么

**解决什么问题**：AI 要跑命令、改文件前问你，原先确认卡上只有一句「在等你确认」，要做什么得去终端里看。

**打开会看见**：对话最末尾的确认卡上，标题写清是哪一类事——「Codex 要运行一条命令」「Claude Code 要改文件 · app.ts」——下面直接画出要跑的命令原文，或者要改的内容（红底是删掉的行，绿底是加上的行）。

**怎么点**：
- **Codex、Qwen Code、OpenCode**：卡上的按钮是 **允许** / **拒绝**（Codex 另有 **这次会话都允许**，OpenCode 另有 **总是允许这类操作**），点了直接交给 AI，不经过终端按键。终端里也在等同一个问题，你在哪边先答都算，另一边会自动收起。
- **Claude Code、CodeBuddy 和其余几家**：按钮照终端菜单原文（比如「1. Yes / 2. Yes, and don't ask again / 3. No」），点哪个就替你在终端里选哪个；卡上同样能看到要跑的命令或要改的内容。

卡上能直接答的时候，下方终端不会自己拉起来；想对照终端看，点卡片右边的 **打开终端**。只有 Mesa 认不出终端里的菜单、卡上答不了时，才把终端拉起来让你在里面选。

**怎样才算做成**：点完卡片消失，过程里那一步从「进行中…」变成有结果。

**常见卡在哪**：卡片一直不消失时，点卡片右边的 **打开终端**，在终端里直接回答。

#### 换了一段对话，聊天跟着换

在终端里打 `/clear` 开始新对话时，聊天会跟着切到新的那一段，最上面一行灰字写「已开始新对话（/clear）」；之前的对话还在「对话」页里。Claude Code、Codex 压缩上下文时，聊天里也会记一行「正在压缩上下文」。

**还没开聊时的聊天面板**：画面中间是 Mesa 的「M▁」标志和一句问候（早上好 / 中午好 / 下午好 / 晚上好 / 夜深了），标志的光标出现时闪三下，下面是输入框和一排起手提示。起手提示按这个文件夹是什么来给：科研课题给「梳理课题进度」「把新文献做成笔记」这类，编程项目给「讲讲代码结构」「补测试」这类，主目录和随手聊给通用的。点一下只把整句填进输入框，你可以改完再发，不会替你发送。文件夹是「随手聊」时，下面再列 **最近的随手聊**（最多 5 条，左边色点代表哪家 AI），点一条就接着聊那段，这个还没说过话的空白标签会自动关掉。项目里的旧对话去项目页或「对话」页找，这里不列。

重启 Mesa 后留下、还没接回的标签，提示下面多一行「上次的对话还没接回 · 接着聊 · 看离开时的画面」；也可以直接在输入框里打字发送，会先接回原来那段再把这句发过去。

**开聊前选项目**：输入框左下角的文件夹按钮写着这次在哪聊——项目名、「随手聊」或「主目录」。点开是 **随手聊**、已添加的项目（按最近使用排，最多 6 个）、主目录，下面是 **选择文件夹…** 和 **新建项目…**（打开新建弹窗：起名、选位置和工作方式，不弹系统选文件夹窗；点 **创建** 后自动回到原来的聊天，目录已经换成新项目，可以直接开聊。科研项目的流程模板之后在项目页挑）。在项目里聊，AI 能读到这个项目的文件。发出第一句后，输入框回到底部，这个按钮就不再显示——目录跟着这段对话定下来了。

**换 Agent、模型和思考强度**：输入框右下、发送按钮左边写着这次要用的 **Agent · 模型 · 思考档**（开聊后只写模型和思考档）。点开是一个菜单，从上到下三段：
- **最上面一行**写着「Claude Code · GLM-flash」这样的 Agent 和连接配置。还没开聊时点它进入下一层，换用哪家 AI、哪份配置，选好配置自动回到主菜单；开聊后这一行只显示，要换 Agent 请新开一段对话。
- **模型**：列的是这份连接在「连接」页登记的模型，加上你用这份连接手动输入过的模型，别的连接用过的不会混进来。每个模型名下面有一行灰字，写它的上下文长度、会不会思考、能不能看图（比如「200K · 思考 · 看图」）；正在用的那个行尾打勾。名单里没有的模型，在模型列表下面输入后回车也能用。
- **思考强度**：一根滑块，刻度是各家的档位（叫法不同，比如 low / medium / high / max，Grok 有八档）。档位不多时每一格下面都写着档名，当前档加粗，直接点档名也能选；档位多的只写两头，当前档写在右上。拖到想要的那一格松手才生效，也可以点一下滑块再用左右方向键。「默认」表示用「连接」页给这个模型设的档；在这里改只影响这次对话，不改连接。调不了的组合不显示这一段。不单独设「思考开 / 关」：能关思考的模型，档位里本来就有最低或关闭那一格。

这里和终端启动栏是同一份选择，在哪边改都一样。

开聊之后同一个位置还在，写的是现在的 **模型 · 思考档**，聊到一半想换就点它。各家的换法不一样，弹层底部一句话写着这家是哪一种：
- **停下再接回**（Claude Code 的模型和思考档、Codex 的模型和思考档、Grok Build 的模型、Qwen Code 和 Kimi Code 的思考档）：这几家自己的切换命令会把你的选择存进它们的全局配置——以后你在系统终端里直接运行它，也会用这次选的。为了不动它们的配置，Mesa 换成：停下 AI，带着新的模型或思考档接回原来这段对话，聊过的内容不会丢，要等几秒。接回时 AI 会把整段对话重读一遍（Claude Code 中途切换本来也要重读）。AI 正在写回复时这几样是灰的，等这一轮写完再换。Codex 的模型也在这里直接选，不再打开它自己的选择器——那个选择器列的是官方模型，不是你连接里的。
- **直接切**（Gemini CLI 的模型、Grok Build 的思考档）：Mesa 替你把切换命令写进终端，只对这一段对话生效。
- **中途换不了**：弹层里直接写明，要换就新开一段对话。Kimi Code 用你在「连接」页加的接口连接时，模型属于这一种：它中途只认自己配置文件里的模型，要换先在连接上点「设为全局」，再到终端里用它的模型命令换。
- 少数组合启动时注不进思考档（比如 Kimi 走 OpenAI 协议的连接），只能用它自己的命令换，弹层底部会写明这一档会存成它以后的默认。

芯片上写的模型以 AI 自己报出来的为准：直接切的那几家，刚点完、AI 还没回话时，名字是斜体，后面跟「待确认」；AI 回了「已切到某某」就换成正式字样。读得到当前模型的有 Claude Code、Codex、Gemini CLI；其余的 AI 不报当前模型，芯片会在悬停提示里写「以终端里显示的为准」。思考档同理：点了某一档不会马上点亮，等 AI 确认后才变。

要是你在终端里自己敲了 `/model` 这类命令、AI 先问你确认（比如 Claude Code 的「Switch model?」），对话最末尾、紧挨输入框会出现一张确认卡，把选项照原文列成按钮（终端里默认选中的那个是实心的），点哪个就替你在终端里选哪个；也可以点 **打开终端** 自己选。卡片出现时输入框的提示字会变成「先在上面选一项，或者直接回复…」。终端底部状态栏里也能切，两边是同一份、走同一种换法。

有些命令的结果不写进对话，而是在终端里打开一个面板，比如 Claude Code 的 `/cost`、`/usage`（用量、设置那一页）。这时聊天末尾会出现一张卡，写着「这条命令的结果显示在终端的面板里」：点 **露出终端** 或 **打开终端** 去看，看完点 **关闭面板**（等于在终端里按 Esc），就能接着聊。面板关掉后，命令在聊天里留一行灰字记录。

AI 停下来以后（比如你按了停止，或它自己退出），这颗芯片不会变灰，菜单最上面写「接着聊用」：在这里选好模型和思考档，再发下一句，Mesa 会用你选的接回原来那段对话。

几个弹层都能用键盘：点开后 ↑ ↓ 选，回车确认，Esc 关闭。还没开聊、输入框在屏幕中间时，弹层往下展开；开聊后输入框贴在底部，弹层往上展开。

**权限**：输入框左下、文件夹按钮旁边是权限标记。点开的菜单标题是「AI 动手前怎么问你？」，有四档：
- **只讨论**：AI 用它自己的只读或计划模式，只看、只说，不改文件、不跑命令。
- **请求批准**：改文件、跑命令前都先问你。Codex 有一处不同：它在项目文件夹这个范围里改文件、跑命令不问，要越出这个范围（比如联网装软件、改别处的文件）才问。
- **帮我批准**：AI 自己判断——普通操作直接做，有风险的才问你。这一档用的是各家自带的「自动判断」模式（Claude Code 叫 auto，Codex 叫 approve for me，Cursor 叫 Auto-review，Kimi 叫 Ask When Needed）。不确定选哪档时选它。
- **完全访问**（橙色）：改文件、跑命令都不问你。选它时会弹出确认框，写明这次对话里 AI 可以不经同意删除文件、安装软件；点 **开启完全访问** 才生效，点取消保持原样。Claude Code 用完全访问启动时自己还会弹一次英文警告（「Bypass Permissions mode」），对话末尾会出现确认卡，选 **Yes, I accept** 才会继续。

你没手动选过时，用的是这家 AI 自己的配置：菜单里对应的那一档打勾，旁边标「本机设置」。比如你本机的 Claude Code 设成了自动批准全部操作，「完全访问 · 本机设置」打勾，标记是橙色的。本机设置对应不上四档里的任何一档（比如 Claude Code 的「自动接受改文件」）时，哪一档都不打勾，菜单底部写着本机现在的设置。

你选的档用的是各家 AI 自己的启动参数，只对这一次对话生效，不改它的配置文件。不是每家都有全部四档：比如 Gemini 没有「帮我批准」，Cursor 和 Kimi 没有「请求批准」的启动参数，OpenCode 只有「完全访问」；没有的那一档是灰的，下面写着「没有这一档的启动参数」。换 Agent 时，新那家没有你选的档，会自动回到本机设置。

开聊后也能换：点标记选新的一档，确认框会说明要重开——权限是在 AI 启动时定下的，所以 Mesa 会先停下它，再带着新权限接回原来这段对话，聊过的内容不会丢，几秒后就能接着发。AI 正在写回复时标记只显示、不能点，等这一轮写完再换。AI 停下以后改权限，下次发消息时生效，不需要重开。

用 Claude Code 时，如果你在终端里换了模式，聊天里的权限标记会跟着变成对应的档，之后停下再接着聊也按新的档启动：批准一个操作时选了顺带切换模式的那一项，几秒内就跟上；在终端里按 Shift+Tab 切的，要等你发下一句话才跟上（Claude 那时才把新模式记下来）。终端里切到「自动改文件」（acceptEdits）这类四档里没有的模式时，标记不变，以终端显示为准。

#### 新对话：随手问一句

**新对话** 在侧栏「工作」组最上面，工作台页头、⌘K 和顶部导航岛里也有，点了都一样：直接打开一段空白对话，不弹窗、不建项目。（以前叫「快速开聊」。项目里的 **＋新对话** 是同一个意思，只是开在那个项目的文件夹里，见 1.3。）

**打开会看见**：一个「随手聊 · 某家 AI」的聊天标签，文件夹是「随手聊」（`~/ccode/scratch`），左边的文件树和右栏收起。用哪家 AI、哪条连接、哪个模型和思考档，默认照你上次从这里开的对话发第一句时的选择；第一次用、或上次那条连接停用了，就换成你常用的一条，输入框右下写着这次用的是哪条。

**怎么用**：
1. 想换 AI、连接、模型、思考档，点输入框右下的芯片；想换权限，点左下的权限标记；想在某个项目里聊，点左下的文件夹按钮换成那个项目。这些都在发第一句之前改，改了不用重启。
2. 打字发送。这时 AI 才带着你的选择启动，这句话直接发过去。
3. 以后再点 **新对话**：如果已经有一个还没说过话的随手聊标签，就切回那个，不会堆一排空标签；已经聊过的不会被复用，每次都是新的一段。

**怎样才算做成**：标签条上多一个「随手聊 · 某家 AI」，发出第一句后几秒有回复。终端那一面在发第一句之前写着「在聊天里发出第一句时自动运行」，想先看 AI 启动的样子，点 **现在运行**。

**常见卡在哪**：本机这家 AI 一条连接都没有时，输入框右下的芯片写着「某家 · 还没有连接」，发送会提示先去「连接」页添加，或在芯片里换一家。

**和运行页的「＋」怎么分**：侧栏的新对话用来随手问一句，不属于任何项目；运行页标签条右边的 **＋** 用来在当前项目里再开一个 Agent，新标签的文件夹跟着你当时所在的那个标签走（当前标签在主目录，或在 Mesa 管理的工作副本 / 工作树里时，新标签开在主目录）。

**给 AI 文件**：输入框左下的 **＋** 点开有四项：
- **文件或图片**：弹出选择文件的窗口，可以一次选多个。选好的文件在输入框上方排成文件名卡片，点卡片右上的 × 去掉；发送时文件路径跟在你的话后面一起发出，AI 自己去读。拖进来、粘贴图片也是同样的效果。
- **引用项目文件**：在光标处放一个 `@`，接着打文件名的一部分，下面会列出这个项目里名字对得上的文件，↑ ↓ 选、回车确认，输入框里换成 `@相对路径`。直接在输入框里打 `@` 效果一样。还没选项目或文件夹时这一项是灰的。
- **技能**、**MCP**：和以前一样，只插入一句提示，不替你发送。

**对话操作**：在输入框里打 `/`，弹出的列表分两组。上面一组是 **Mesa** 自己做的事：新对话（在这个文件夹另开一段，原来的不动）、压缩上下文（这家 AI 有这个命令且正在运行时才有）、分叉到新标签、导出 Markdown、查看改动、打开终端，点了直接执行，不会写进终端。下面一组是这家 AI 自己的命令，选中后照原样写进终端。不习惯打斜杠的话，标签条上当前标签名旁边的 **⋯** 里是同一组 Mesa 操作（只在聊天面板显示）。

**消息上的操作**：鼠标移到一条消息上，下面会出现几个小按钮：
- 每条都有 **复制**。
- 你说的话有 **编辑后重发**：把这句放回输入框，改完自己按发送。输入框是空的时候按 ↑，也能取回你上一句。
- AI 的回复有 **从这里分叉**：新开一个标签，带着「到这条回复为止」的对话接着聊，原来的对话不动。新标签先是只讨论的，要让它改文件，点输入框左下的 **允许修改**。

**AI 还在写的时候也能发**：直接打字回车，这句话会交给 AI 排队，等它这一轮说完再处理；你那条气泡下面写着「排队中 · 这一轮结束后处理」，输入框的提示字也会说明。排队是 AI 自己做的，所以聊天里没有撤回按钮，要撤回请到终端里删掉排队的那条。

**上下文用了多少**：开聊后，模型芯片左边有一个小圆环，表示上一轮已经用掉这个模型多少上下文。鼠标停在上面会显示比例和具体数字（比如「上下文已用 63% · 126K / 200K tokens」）；超过八成时圆环变成橙色。读不到这个模型的上下文长度时不显示圆环。

**点一下圆环看明细**：弹出一张上下文卡。最上面是已用和总量，下面一条彩色横条：对话、MCP 工具、内置工具、系统提示各一个颜色，技能、记忆文件这些小类是灰色，没填满的部分是剩余；横条上的竖线是自动压缩的位置。再往下按类列出各占多少，每行前面小方块的颜色和横条对应。用 Claude Code、Qwen Code 时，分类是 Mesa 在后台让它跑一次自己的 `/context` 得来的，要等两三秒（挂了 MCP 的更久），不调用模型、不花钱，也不改你的对话；数字是它自己的估算，和上一轮实际用量可能差一点。其余几家没有这类命令，卡上只有已用和剩余。卡片底部写着离自动压缩还有多少；这家能压缩时有 **压缩上下文** 按钮，和 `/` 里的同一个，点了把前面的对话压成摘要。超过八成时标题里的数字变成橙色。

**第一次在某个文件夹开聊**：有的 AI（Claude Code、Kimi、CodeBuddy、Gemini）在一个没信任过的文件夹里启动，会先问你是否信任这个文件夹，没回答之前它不会开始干活。这个问题本来只出现在终端里；现在对话末尾会出现一张确认卡，点 **信任此目录** 就替你在终端里选好（像 CodeBuddy 这样另有「信任上级目录」「连子目录一起信任」的，只选「只信任这个文件夹」），它接着处理你刚发的那条；点 **不信任，退出** 则它直接退出。如果你是在主目录里开聊，卡片里会建议改到「随手聊」目录——主目录范围太大，信任了它就能读写你所有的文件。认不出的提问形式，聊天面板等 8 秒后会在下方拉起终端，你在终端里自己选。

### 8.2 启动栏

还没运行时，画面中间是「将在某某文件夹启动」、一行「在聊天里发出第一句时自动运行」和实心的 **现在运行**——在聊天里发第一句会自动启动，这里是给想先看终端的人用的。点「将在某某文件夹启动」这一行会弹出目录菜单：**随手聊**、最近用过的已添加项目、**主目录**，最下面是 **选择文件夹…** 和 **新建项目…**；当前目录带勾。上方启动栏依次是 Agent、配置、模型、**思考**、**权限**，点开向下列清单，选过会记住。

**思考** 和 **权限** 两格和聊天输入框里的是同一份选择：在聊天里选了「完全访问」，这里也写着「完全访问」（橙色），在哪边改都一样。权限四档的意思见 8.1；选「完全访问」同样会先弹确认框。这个连接和模型组合调不了思考档时，不显示「思考」这一格。

跑起来后这一排不再占终端高度，身份写在底下那一行，比如「Claude Code · GLM · glm-5.3 · 项目名」。**点这一行字** 打开「这次启动」卡片：
- 上半部分列出这次实际在用的 Agent、连接（网关名和钥匙尾号）、模型、思考档、权限和目录。你在托盘或设置里换了全局默认后，可以在这里确认正在跑的终端用的是哪一套。
- **换权限**：点一档，确认后 Mesa 停下 AI，带着新权限接回原来这段对话，聊过的内容不会丢。AI 正在写回复时这几个按钮是灰的，等这一轮写完再换。
- **换连接接着聊**：列出同一家 AI 的其他连接，点一条，确认后 Mesa 停下 AI、换成这条连接，再接回原来这段对话。新连接里没有当前模型时，会改用它的第一个模型，确认框里会写明。
- 模型和思考档在运行中直接用底部状态栏换，不用重开。

进程停了以后，点这一行字是展开启动栏，重新选配置再运行。

这一行右边的 **⋯** 里多了一组「对话操作」：新对话（在这个文件夹另开一段）、压缩上下文（这家 AI 有这个命令且正在运行时）、导出 Markdown、查看改动、切到聊天，和聊天输入框里打 `/` 看到的那一组相同。

运行中插入技能或 MCP 提示点当前标签上的 **✦**，菜单贴着它弹出（这一行不再另放一个「插入」；进程退出后「插入」才回到这一行）。这一行最右边有收起图标，点一下整行收掉（要再用这一行或 ⋯，去标签栏右侧点同一图标召回）。重开标签接上还在跑的进程时，这行会带一句灰字「画面大小先不动」——只是说明，不是出错，收起不受影响。

底部状态栏右边除了运行时长和用量，还有一个小圆环加百分比，表示上一轮用掉了这个模型多少上下文，超过八成变橙色，和聊天输入框里的圆环是同一个数，点一下同样弹出上下文卡。读不到这个模型的上下文长度时不显示。

**文件** 和 **改动**。改动里可以勾选后提交。

### 8.4 输入与粘贴

| 操作 | 行为 |
|---|---|
| 拖文件 / 图进终端 | 直接插入 |
| ⌘V / 右键 **粘贴** | 剪贴板是图 → 落成一条路径写进输入行，不自动发送；是文字 → 原样贴入 |
| 选中一段 | 出现 **复制**、**复制文本**、**查看**；AI 在跑时还有 **引用**、**问 AI**；在科研或办公项目里还有 **存进笔记**（右键菜单里同样有这几项） |
| **引用** | 把选中的这段加上引用符号（每行前面一个「>」）放进输入框，你接着写自己的话再发。正在看聊天时放进聊天输入框，正在看终端时放进 AI 自己的输入行 |
| **问 AI** | 带着这段直接问这里的 AI「这段终端输出是什么意思？」，不用再复制粘贴 |
| **存进笔记** | 追加到这个项目的 `notes/clips.md`，每段一个小标题，写着时间、哪家 AI、哪段对话。和文献摘录分开放，不会被精读步并进文献笔记。编程项目和随手聊目录里没有这一项 |
| **复制** | 终端里的原样，Markdown 标记还在（⌘C 同） |
| **复制文本** | 去掉标题、加粗、链接地址等标记，只留字 |
| **查看** | 不渲染，字原样铺开，方便读长段 |
| Ctrl+V | 交给各家 Agent 自己读系统剪贴板 |
| ⌘← / ⌘→ / ⌘⌫ | 和 iTerm2 一样：跳到这一行开头 / 结尾、删到行首。在各家 AI 的输入框和普通 Shell 里都管用 |
| ⌥← / ⌥→ | 按词往左 / 往右跳 |
| Shift+Enter | 在 AI 的输入框里换行，不发送。Grok Build 和 CodeBuddy 以前按了会直接把半截话发出去，现在也是换行 |
| 查找输出 | 支持正则、整词、区分大小写，显示命中「第几/共几」（搜不到写「无结果」）；输入停顿后边打边高亮 |
| 粘贴 | 开头和结尾的换行会去掉（缩进保留）；Shell 里粘多行命令会先问你一次；文件管理器里复制的文件粘进来变成带引号的路径 |
| http 链接 | 可点，用系统浏览器打开。Agent 自己在输出里画的链接（OSC 8）只认 http、https 和邮件地址 |
| 绝对路径与相对路径 | 都可点，在右侧打开那个文件。相对路径（如 `output/figures/fig1.pdf`）先确认存在，不存在会提示；带 `:行号`（或 `:行:列`）时滚到那一行；句尾的句点、逗号不算路径 |
| Agent 里的「复制」 | 写进系统剪贴板。单次大约不超过 256KB |
| 终端通知 | 标题会发一条系统通知（正文标明是哪个 Agent），只在窗口不在前台或该标签不在当前时发；任务进度不算通知 |
| 任务进度 | 支持上报进度的 Agent（kimi、Grok、CodeBuddy）在跑长任务时，标签上会显示百分比或「…」，出错时显示红色 !（后台标签同样实时更新） |
| 终端里的图片 | 只有真正的图片才会出现在画面右下角，可点 ✕ 关掉 |
| 异常退出 | Agent 崩溃时终端里会写明退出码和原因，这段说明会跟着「上次离开时的画面」一起留下来 |
| 关掉再开 | 还没恢复任务时，终端里先显示上次离开时的文字（Agent 停止或切走窗口时自动存）。点恢复任务才重新接上 |

多行文字粘贴时整段进去，不会在换行处执行。Shift 加标点（比如问号）按一下就应出现；输入法开着时组好的词只进一次。打开沉浸阅读或关掉底部状态栏后，终端会按新的宽高再排一次。

### 8.4.1 连接出问题时换一条接着聊

AI 用的连接额度用完、被限流、钥匙被拒、服务出错或超时、没有这个模型时，终端画面顶上会出一条提示，比如「「GLM」连接的额度用完了」，后面跟着网关的原话（AI 还在自动重试时会写明）。正在看聊天时，同样的提示是对话末尾的一张确认卡：同一家 AI 的其他连接各占一个按钮「换到 某某，接着这段对话」（最多列三条，第一条是实心的），点了效果和下面第 2 步一样；没有别的连接时按钮是 **去添加连接**；**先不换** 和终端提示上的 ✕ 一样。

1. 在提示右边的下拉里选一条同一家 AI 的其他连接（显示「连接名 · 默认模型」，已停用的不列）。
2. 点 **换这条接着聊**。Mesa 停下 AI，换成这条连接，再接回原来这段对话，聊过的内容不会丢；原来的模型新连接里也有就沿用，没有就用新连接的第一个模型。
3. 接回后发一句「继续」，它就接着回答刚才没答完的那句。

这家 AI 没有别的连接时，提示里是 **去连接页添加一条**。不想换就点 ✕；同一个错误不会再提示，再出新的错误照常提示。

认得出的有 Claude Code、Codex、Kimi、OpenCode、Grok Build、CodeBuddy 六家。Qwen Code 出错时会在后台安静地重试很久，屏幕上看不出来，要等它最终报错。

### 8.5 只讨论

开聊时选只讨论可禁止改文件。有的 Agent 做不到只读，Mesa 会直接拒绝，请换一家或明确允许写。

## 9 连接页

每家 Agent 一张卡片。没装过的卡片颜色更淡，上面有 **安装**。

### 9.1 安装与更新

点 **安装**，确认框会告诉你将执行的命令。

| 平台 | 渠道 |
|---|---|
| Mac | 优先 Homebrew（自动走国内镜像） |
| Windows | Claude / Codex / OpenCode / Kimi / Grok 可用 winget，其余多数走 npm |
| Linux | 页面会给命令 |

过程是一个小终端，遇到 `[y/n]` 就在下面回答。一般几十秒到几分钟；持续约 10 分钟没有任何动静才算卡住，会自动报错。卡上出现 **新版** 即可升级；Kimi 那种要方向键选择的更新会改到运行页终端里让你用键盘选。

### 9.2 加一条连接（中转 / API 密钥）

把「网关」理解成**一把密钥 + 一组网址**，「绑定」理解成**某家 Agent 用这把密钥里的哪些模型**。日常只做「添加连接」。

1. **＋ 添加连接**
2. **端点预设** 选供应商（DeepSeek、智谱、月之暗面、百炼、OpenRouter 等），地址、名称、推荐模型自动填
3. 贴 API Key（保存后只显示尾号）
4. **验证并获取**：真发一次请求。成功会列出模型并自动勾上推荐项（目录里没有的不瞎勾）；失败按红字改地址或密钥，不要先保存
5. 同一把密钥还要给别家 Agent 用：勾 **同时绑到**。灰色勾不了的几家是协议和这个端点不兼容，鼠标停上去看原因
6. 保存
7. 想确认这条连接真能聊：回到连接列表，鼠标停在这一行上点 **新对话**（对话图标），在新对话页发一句话。有回复就是通的；报错照提示改（见 [9.4](#94-连接行上的动作)）

**模型分工**（Claude Code、Grok、OpenCode 的连接才有）：模型名单下面多一块「模型分工」，决定一些「不是主对话」的请求用哪个模型。
- **后台小模型**：会话标题、摘要这类小任务（Grok 还有输入框里的下一句提示）。可以选名单里便宜、快的那个；默认「跟主模型」，就是启动时选的那个模型。
- **子 Agent 模型**（只有 Claude Code）：主对话派出去的子任务用它，默认也跟主模型。
- Claude Code 的连接在这块下半部分有一张小表「Claude 别名指向」，写着它四个模型别名（sonnet / opus / haiku / fable）分别指向哪个模型、为什么：名单前四个依次对上，haiku 跟后台小模型，名单不够四个的写「跟主模型」。你在 Claude 里用 `/model` 选这些别名，或它自己派小任务时，用的就是表里的模型。表是按上面的名单和分工自动算的，只能看不能改。

Mesa 自己的对话命名（列表里「1017|功能|…」那种标题）和这里不冲突：它用的是 **设置 → AI 与 Agent** 里「按功能单独配置」的 **会话摘要 / 起名** 那一行（留空跟「AI 专用配置」），标题存在 Mesa 里、显示时优先；Claude、Grok 自己生成的标题只在 Mesa 还没起名时兜底显示。想让 Mesa 起名也用便宜的模型，去那里选。

为什么要有这块：各家 AI 自己的配置文件里常留着别的模型设置（比如你本机 Claude 里设过子任务用 glm-5.3，Grok 里设过会话标题用另一家网关的模型）。不在这里定下来，这些小任务就会带着别家的模型名打到你这次选的网关上，换个网关就失败，或者在另一家悄悄计费。这里的设置只作用于 Mesa 启动的会话，不改各家的配置文件。名单里删掉的模型，对应的分工自动回到「跟主模型」。

**常见坑**

| 现象 / 场景 | 做法 |
|---|---|
| 一运行就 404 | Claude / CodeBuddy 的地址**不要**以 `/v1` 结尾；Codex / Kimi / Qwen 一般**要**带 `/v1` |
| 智谱还要给 Codex 用 | 普通槽 `paas/v4`，Responses 槽 `api/v1`；勾「同时绑到 Codex」预设会自动补 |
| Cursor | 没有通用预设。`CURSOR_API_KEY` 只能是 cursor.com 的用户 API Key，填 GLM 这类网关的钥匙会报 API key is invalid。要用 Cursor，选 **官方账号**，终端里执行 `cursor-agent login` |
| Gemini 一启动就要开浏览器登录，或启动被拦下说「认证方式」 | Gemini CLI 只认它自己选的认证方式：你在 Gemini 里用 Google 账号登录过，连接里的密钥和地址就全被它无视。在这条连接上点 **设为全局默认**（会先备份 `~/.gemini/settings.json`），或在终端运行 `gemini`、输入 `/auth` 选「Use Gemini API Key」 |
| 别家模型选不了思考档 | Grok 只给在它配置里声明过档位的模型调思考（点 **设为全局默认** 会写上）；CodeBuddy 接自定义网关时不发思考参数；这两种情况开聊前不显示思考档 |
| AI 只说话不建文件 | 模型没有工具调用能力，换官方 Claude 或供应商写明支持 tools 的模型 |

### 9.3 官方订阅

支持：Claude Code、Codex、Gemini、Qwen Code、Kimi Code、CodeBuddy、Cursor、Grok（九家里只有 OpenCode 不支持官方账号）。

「账号类型」选 **官方账号**，不用填密钥；对应卡片组头点 **登录**，按终端提示完成（Codex 会给设备码）。组头变成绿点「官方」即成功。

组头出现琥珀 **! N 项连接冲突** 时：本地 CLI 配置文件里残留的密钥会盖过官方登录、产生 API 计费。点开可 **备份后清理已识别项**；确实要保留这些键就点 **忽略**——只隐藏提醒，官方账号的启动拦截仍在，残留项有增减时提醒自动回来。

**网关库**（页头按钮）：每个网关一行，写端点、协议（超过三种写「前两种 等 N 种协议」）、模型数、几个连接在用、近 30 天花费（点它跳用量页）。行上 **编辑** 是主按钮，**获取模型** 重拉目录，**删除** 在最右。标题栏右边的 **拆开自动合并的连接** 只在升级后发现连接被错并到同一网关时用。

国内直连官方常失败：**设置 → 网络 → 出网代理** 填本机代理（如 `http://127.0.0.1:7890`），或点 **检测** 列出正在跑的代理。这份代理给官方登录、官方启动、Agent 安装 / 更新下载用（国内镜像源的下载自动直连、不绕代理）；走中转网关的连接不会被它拐到境外。

提示 token revoked / 请重新登录，是订阅本身过期，到连接页重新登录即可。

### 9.4 连接行上的动作

| 动作 | 位置 | 说明 |
|---|---|---|
| **编辑** | 行上常驻 | 加减模型、改名称和附加环境变量（模型列表第一个是启动默认，行上这个模型字色更深）；端点、密钥和逐模型的思考档 / 温度在网关库里改，弹窗里有 **打开网关库**。改完的模型组合若与这家 Agent 上另一条连接**一模一样**，保存会被拦下并提示「该 Agent 已经有相同模型选择的绑定」 |
| **停用此连接** | 行尾 ⋯ | 不让它被自动选中（启动栏预选、恢复会话、AI 功能回落都跳过）；列表里还在，启动栏「已停用」分组仍能手选。再点一次「取消停用」恢复 |
| **解绑** | 行尾 ⋯ | 删掉这条连接在某家 Agent 上的用法。**网关和密钥都留着**，同一把密钥给别家 Agent 的绑定不受影响 |
| **新对话**（对话图标） | 行上悬停 | 跳到新对话页，输入框里已选好这条连接。**发一句话看有没有回复，就能快速检查这条连接可不可用**。缺端点、缺密钥或已停用的连接也照样打开，问题在输入框和启动提示里如实写出来；已经开着一个还没说过话的空白对话时，会复用它并把选择改成这条 |
| **设为全局默认** | 行尾 ⋯ | 见 [9.6](#96-两种生效别混) |

**解绑前注意**：如果有课题的定时任务正用着这个配置，弹窗会告诉你有几条、叫什么（超过 3 条只列前 3 个名字加「等」）。**解绑后这些任务不会自动改用别的 AI**，会在下一次该跑的时候停下并留一条失败记录，写明连接已不存在（profile 不存在）。这是故意的。要让它继续跑：先到那个课题的「定时任务」里改连接，再回来解绑。

### 9.5 能力声明

中转的新模型有时公共能力库也查不到。症状：Claude 把它当 200K 小窗口、长对话提前压缩；Codex 模型目录里窗口写小；能看图的模型贴图被拒。

**连接 → 网关库 → 编辑 → 展开「模型策略」里那行模型 → 最下面 能力声明**：

1. 填 **上下文窗口**（如 `1048576`）、**思考 / 视觉** 选「支持」或「不支持」
2. 不确定的留「未声明」——留空字段继续走公共库和内置表推断
3. **保存声明**

面板顶部「当前解析」变成你填的值、行右侧徽章跟着变（如出现 `1024K`）即成功。字段全清空后按钮变成 **清除声明**。

| 易错点 | 说明 |
|---|---|
| 思考 / 视觉选「不支持」 | 是**硬声明**，推断链到此为止，公共库说支持也不再听。拿不准就留「未声明」 |
| 和 **max output** 的分工 | max output 是「这次让它最多写多少」，能力声明是「这个模型本身什么规格」 |

### 9.6 两种「生效」别混

| 你想要的 | 怎么做 |
|---|---|
| 只在 Mesa 里用，不改电脑上其它终端 | 什么都不用点，启动时自动带上（默认） |
| 系统终端、ChatGPT 桌面客户端也走这套 | 连接行 **⋯ → 设为全局默认** |

设为全局会改 CLI 自己的配置文件，Mesa 会先备份；可 **撤销上次写入**，也可 **恢复初始状态**（回到 Mesa 第一次改之前）。本机若装着 cc-switch 一类工具，点之前会提醒你不要两边同时改。Codex 的「设为全局」**不会**改 `auth.json`。

### 9.7 思考档位

网关库里每个模型的思考档可勾多档，勾上的档是会话里能切的范围，开场只用其中一档。斜杠串和拼写错误存不进去。

底栏滑块点亮的那一格就是这次会话**当前**的档位，判定顺序：客户端自己屏幕上写的档（你在终端里敲 `/effort` 改了也会跟上）→ 开工时这次单独选的档 → 网关库给这个模型定的开场档。各家把档写在屏上的位置不同，Mesa 认的是：Claude Code 开场那行「with xhigh effort」和输入框右上角「◉ xhigh · /effort」；Codex 底栏「模型 high · 目录」（写 default 就是没指定）；Grok 输入框边框「模型 (high) · …」；Qwen 敲 `/effort` 后那句「Reasoning effort: …」；Kimi 底栏模型名后面有「thinking」就是开着。底栏不能切档的客户端（Codex、OpenCode 等）也会在底栏写一个只读的「◈ 档名」，没指定时写「◈ 默认」，要改去客户端自己的设置里改。三样都没有时滑块一格都不亮、右边写「默认」，表示用的是客户端自己的默认档；客户端当前的档不在你勾选的范围里时，也一格不亮，右边直接写那个档名。拖动滑块、松手就把 `/effort` 发进终端。

| 客户端 | 会话里怎么切 | 中转不报档位时 |
|---|---|---|
| Claude Code、Qwen | 底栏思考滑块，或 `/effort` | 菜单是客户端自带的，不看中转目录 |
| Codex | 在 Codex 自己的模型选择器里改；Mesa 底栏没有滑块 | 启动时写入的模型目录自带 low 到 max |
| Kimi | 底栏只有开 / 关 | 不看中转目录 |
| OpenCode | 在 OpenCode 里改；思考模型会标成可推理 | 不看中转目录 |
| CodeBuddy | 只有开场那一档，会话里没有切换 | 不看中转目录 |
| Gemini、Cursor | 没有思考档入口 | — |
| Grok | `/effort` 或底栏滑块 | 中转不报档位时菜单出不来。设为全局会把勾选档写成菜单，已有菜单不覆盖，写完新开一次会话才看得到 |

## 10 技能页

**技能** 是一篇短说明书，告诉 AI「精读要写成哪几节」「图要怎么交」。有研究流程时开步自动带上，不必手选。

| 操作 | 说明 |
|---|---|
| 创建 / 从 GitHub / ZIP 导入 | 页面上 |
| 点技能行，右侧打开预览 | 上半是 **应用到 Agent**：点格子分发 / 取消，本机没装的 CLI 灰显并标「未安装」（仍可预先分发）；**一键应用** 只分发给本机装了的。Cursor 和 Grok 是复制一份过去，不是快捷方式。下半是 SKILL.md：默认按排版显示，开头的 YAML 设置拆成一张字段小表；点标题旁 **源码** 看原文 |
| 内置技能 | 第一次启动放进技能库：**只补没有的，不覆盖你改过的；你删掉的不会复活**。新加的内置技能要重启 Mesa 才会出现在列表里 |
| **内置技能有新版** | 点 **查看差异**：每个文件一行，标「有差异 / 未变」，点开左右对照本机与新版。不想要点 **保留本机版本**；要就点 **备份并采用新版**（会覆盖库里那份，先备份） |
| **◈ 优化技能（原地改）** | 技能行 ◈ 或 ⋯ 菜单进入：写优化意见 → 开终端让 Agent 按意见直改库中这份；改完自己审查 |
| **◈ 优化技能（另存为新技能）** | 同一弹层切到「另存为新技能」：勾选一个或多个源技能（当前技能已勾）→ 写优化方向 → AI 出合成稿（内置源的流水线落点为骨架、方向优先）→ 预览可改、**新技能名以你输入框里的为准**（AI 名只是预填建议）→ 确认落库。**源技能零触碰**；名字撞了换一个再确认即可；职责覆盖内置位时稿里会带 provides 声明，落库后按「顶替内置位」那行挂到流程 |
| **副本需同步** | Cursor / Grok 的复制件旧了，点旁边 **同步副本** 把库里最新版拷过去——不是 GitHub 更新 |
| **用你自己的技能顶替内置位** | 外部技能先点 ⋯ → **适配到流水线**（右边标着「AI」）：AI 按流水线路径约定改写并声明能顶替哪个内置位（`provides`），你预览确认后落盘；再到流程编辑器该步骤的技能 chips 里换上它。换上之后：步骤简报里「按 ×× 技能执行」会自动跟着写你的技能名，文献同步、开读这一篇、文献雷达卡这些入口也不会消失（雷达的运行通知与收件箱候选目前仍认内置 lit-watch 名，后续放开）。简报点名了没挂的技能位时 chips 下方会提醒（不拦开工） |

综述流程用到的内置技能见教程 [12 章](tutorial.md#12-技能与-mcp)。

## 11 MCP 页

外部工具接口。配了之后新开的对话才能用。

列表的 **用于** 一栏写分发给了几个 CLI，鼠标停上去能看到是哪几个；某家的配置被外部改过、删掉或禁用时，这里会接一句琥珀色的「· N 处异常」。点它展开分发管理：本机没装的 CLI 标「未安装」；标着 **外部已删除 · 重写** / **外部已禁用 · 重写** 的，直接点这个标签就按 Mesa 的清单重新写回去，不用先关再开。添加 / 编辑 MCP 的弹窗里每一格都有小标题（名称、命令、参数、工作目录、启动超时、URL）。

### 11.1 学术检索

| 服务 | 配置 |
|---|---|
| **Consensus** | 用预设添加，把 API 密钥填到密钥栏（不要写进命令本身） |
| **Undermind** | 同样用预设，然后 **去终端登录** 做一次浏览器授权 |

检索步的人工事项 **配置学术检索 MCP** 自动判定条件：Consensus 已添加且密钥非空，Undermind 已添加并登录。缺哪一步旁边会写一句，例如「Consensus 还没填密钥」「Undermind 未登录」。说明里注明 Consensus「本机已配置时可跳过」——这台机器的 MCP 页已存密钥就不用重做，Undermind 仍要先登录。

不配这两家，标准档用 OpenAlex 一条检索式。Semantic Scholar 与 Crossref 标题检索不参与发现；Crossref 只按 DOI 补字段。配了只是各补一轮，不替代筛选标准。

### 11.2 其他

- **Grok 的 MCP** 在 Mesa 里只能看，不能代为写入；要用 Grok 自己的 `grok mcp add`。
- **Blender**、**Origin** 是可选，用得上时再配。Origin 只在 Windows 且本机装着 Origin 时才有意义。

## 12 用量页

看今天 / 7 天 / 30 天 / 全部花了多少。官方订阅不计费，只显示「订阅」和 token。Mesa 自己写摘要、起标题、解读雷达也不计入课题费用。汇率在设置里改。

**历史会一直留着**：各家 AI 会自己清理旧对话（比如 Claude Code 默认只留 30 天），Mesa 也会清理自己的后台对话，但对话文件没了以后，它们当时的花费和 token 仍然留在用量页，年度热力图不会因此变空。只有你在对话页亲手删除某条对话时，它的用量才一起删掉。2026-10-17 之前已经被清掉的那部分找不回来了。

### 12.1 订阅余量

配了订阅套餐网关时，费用卡上面多一块「订阅余量」（这一页自上而下：订阅余量 → 网关余额 → 费用 → 活跃度 → 分布）。支持三家：

| 平台 | 地址特征 |
|---|---|
| **智谱 Coding Plan** | 含 bigmodel.cn 或 api.z.ai |
| **Kimi For Coding** | api.kimi.com |
| **MiniMax Coding Plan** | minimaxi.com / minimax.io |

有多家时卡片顶部出现切换标签，单家不占位置。

- 谁用得多谁排上面，走大数字：百分比、绝对用量、通栏粗进度条、「还有 5 天 20 小时」。另一窗收成一行。
- 70% 起转黄、90% 转红，进度条和数字同色；100% 就是已经卡住。倒计时悬停看具体重置时刻。
- 智谱和 Kimi 的绝对用量写在百分比旁（如 `140,000 / 140,000`）。站点偶尔超发，卡面按总量封顶。MiniMax 只回百分比。
- **重置卡**（仅智谱）：卡底两列 `5 小时重置卡 ×1`、`周重置卡 ×1`，有效期写到日，几点几分悬停才看。最紧的那一窗用量到 90%（红档）时按钮就用强调色；另一张是次级按钮，不会因为 0% 被禁用。点了先弹确认——**消费后不可撤销**（先用最早过期的那张）。3 天内到期会标黄。
  - Mesa 会劝你别白用但**不拦你**：确认框写明这个窗口当前已用多少；若一点没用（0%）会直说「重置不会腾出任何额度，这张卡会白费」，确认按钮变成 **仍要用**。一张都没有时写「重置卡无可用」。
- **去控制台**：卡头右侧，打开该平台的网页版（智谱直达用量页；Kimi、MiniMax 目前打开的是平台首页）。
- **自动刷新**：页面开着每 2 分钟查一次；卡头 ⟳ 立刻强查这一张；页顶 **刷新** 会顺带把订阅余量和网关余额一起强查。查到新数字前先显示上一次结果，不白屏。
- 查询失败时保留上一次成功数据并标「数据截至 几点几分」；提示密钥失效就到连接页更新这个网关的密钥。
- 智谱团队版不用单独设置：网关自定义 Header 带过 `bigmodel-organization` / `bigmodel-project` 就按团队版查。Kimi 的 5 小时窗按最紧的那个模型窗口显示；MiniMax 无周限额的套餐只显示 5 小时窗。

### 12.2 网关余额

配了预付钱包网关（目前认 **ZetaTechs** 这类 New API 站，地址含 `zetatechs.com`）时，订阅余量旁多一块「网关余额」。

**先填系统访问令牌**（不是推理用的 `sk-`）：到 **用量页** 网关余额卡头点 **去钱包 ↗** 登录站点，在个人设置里生成访问令牌，再回 **连接 → 网关库** 打开这个网关粘回来保存。用户 ID 一般不用填，只有老站点才要。

| 元素 | 含义 |
|---|---|
| 主数字 | 当前可用余额（与网页一致） |
| 通栏粗进度条 | 画的是**还剩多少**（满条 = 钱还多），条下写「已消耗 90%」 |
| 颜色 | 按已消耗分档：80% 起转黄、90% 转红 |
| 密钥额度 | 下面单独一块。不限额的不画百分比，开口条按各密钥已花多少比长短，末端淡出，旁边写「不限」和已用金额 |
| 同一站的多个网关 | 合成一张卡（共用系统访问令牌，余额本是同一个）；钱包数字只出现一次，各密钥额度按网关名列在下面 |
| 同一站的两个账户 | 分成两张卡，标题是「站点 · 账户名」 |

金额藏起来用卡头的眼睛符号（大字和密钥行金额变成 `¥•••`，百分比还在）。人民币站显示 ¥，美元站显示 $。密钥额度用到 100% 标「已用尽」；密钥快到期（14 天内，含已过期）在卡里用黄色提醒一行，其余时候悬停密钥行才看到——到期是这把推理密钥的，不是钱包的。没填令牌时主数字是这把推理密钥的额度，并有一行提醒你去连接页填。

不是这类网关不会出现这张卡。

### 12.3 活跃度热力图

上面两块看「钱」，这一块看「节奏」：从去年同一个月到今天，你什么时候在干活、密在哪、断在哪。费用卡下面一张「活跃度」卡，一格一天铺开，颜色越深当天用量越大。

- **看什么**：网格从去年同一个月的 1 日铺到今天，最右边就是今天，不再从 1 月空铺到 12 月。今天是 10 月，看到的就是去年 10 月到今年 10 月；到了 11 月，左右两端一起换成 11 月。右上角标着起止月份。四个数里，活跃天数和单日峰值按这一窗口算，当前连续和最长连续仍是全部历史（跨年不断档）。今天还没用不清零，从昨天接着数。四个数（活跃、连续、最长、峰值）和一排「少 → 多」颜色样格常驻网格下面一行。格子是固定的正方形，边长跟着卡片宽度在 11–28 像素里取放得下的最大整数：窗口拉宽格子会跟着变大，拉高不会把格子拉成长方形；到 28 像素就不再变大（管理页整页限宽之下实际最大约 21–22 像素），这张卡和上面几张卡保持一样宽，图在卡里居中、多出来的空隙分在左右两边。窗口特别宽时，用量、设置、MCP、技能、连接这几个管理页整页居中、两侧留出空白——留白宽度刚好让这张卡铺到最宽，不会往右拖出一条空页底。月份标在网格下方。今天之后的日子不画。
- **不跟页顶的时间范围走**：这块不随「今日 / 近 7 天 / 近 30 天 / 全部」切换，始终是去年同月到今天。
- **悬停 / 键盘**：指针放到格子上（或 Tab 进入后用方向键漫游）看当天的日期、token 数、对话数和花费；订阅用量会标「订阅」。
- **点开一天**：点击格子（或聚焦后按回车）弹出当天明细——四类 token、花费、哪个 agent 花的、当天的对话列表。列表里点任何一条直接跳到对话页打开那个会话（最多列 8 条）；右下角「在对话页看这天 →」把这天的全部对话列成筛选项。关掉用 Esc 或点外面。
- **只看某家 agent**：这一窗口里有两家以上 agent 干过活时出现「全部 + 各家」胶囊，跟在标题「活跃度」后面同一行（行尾还是起止月份），窄窗口放不下就自然换行；网格从下面开始、吃满卡片宽度。点了之后格子、四个数、悬浮全部按这一家算（连续天数限这一窗口）；点「全部」恢复。
- **颜色怎么分**：不是固定阈值——按你自己有用量那几天的相对大小分档，轻度用户的好日子也亮得起深色。
- **口径**：格子含订阅用量、不含 Mesa 自己的后台任务（写摘要、起标题、定时巡检）；工具栏「显示内部活动」打开后悬浮和明细里才出现「内部」条目，不改变格子颜色和统计。着色量算输入+输出+缓存读写四类，比页首 tokens 卡（只算输入+输出）口径大，两处数字对不上不是 bug。
- 日期按你电脑的时区归天（「在对话页看这天」按会话最近更新时间归日，跨天长会话可能落在相邻一天）。刚跑完会话切过来，今天的格子已经亮了。刚打开应用的头几秒，这张图会先用上次的统计立刻显示，索引在后台刷新完自动更新，不用等。

### 12.4 花费总览与分布

**总览卡**：大字是这段时间的费用和 tokens（费用下面一行和上周比涨了还是降了——固定按两个 7 天窗比较，与所选时间范围无关；tokens 下面写输入、输出各占多少）。再下面一排小格：**对话**几次、**场均**每次花多少、**缓存命中**多少、**缓存省下**多少（绿色，悬停看「若无缓存」要花多少）、**不计费**的订阅和内部 tokens。没有的项不出现。数据点多于一个时，底下是花费 / 用量的走势折线。

**分布卡**：顶上六个页签 **最贵 / Agent / 项目 / 网关 / 任务 / 模型**（没有数据的页签不出现）。每一行都是同一个样子：名称和下面一行说明 → 一根占比条 → tokens → 占比 → 费用。「最贵」那页的条和占比按**这次花费占这段时间总花费**算，其余页签按 tokens 占这一页的合计算。订阅用量的费用写「订阅」。

- 先露 10 行，多了底下有 **显示全部 N 项**；换页签自动收回。
- 能点的行悬停会出现 ›：**最贵**点了打开那段对话的回放；**Agent** 点了跳到对话页、只看这家 Agent 的对话（筛选条上多一个 Agent 标签，点 × 去掉）；**项目**点了进这个项目（Mesa 内部任务那一行不可点）。
- 右上 **复制表格**：把当前页签整张（含没展开的行）复制成表格，粘进 Excel、Numbers 或飞书表格就是整齐的五列：当前页签名（最贵 / Agent / …）、说明、tokens、占比、费用。报销、周报直接用。
- 从连接页某个网关跳过来时，网关页签里那一行会高亮，右上 **取消高亮** 恢复。

## 13 设置页

**设置** 在侧栏最下面，也可以按 ⌘, / Ctrl+,（Mac 还能走菜单栏 Mesa → 设置…）。左边是分区：上面一组「常用」是外观、终端、通用、快捷键；下面一组「管理」是 AI 与 Agent、网络、用量、更新、诊断、数据与存储、关于。每个分区标题下有一行字说明这里管什么。

找不到某一项时，在分区列表上方的搜索框里打你想到的词，比如「代理」「字体」「起名」，左边只留下相关的分区，点进去再找具体那一行。下次打开设置，会回到你上次看的分区。

有些设置项名字旁边有个小 ⓘ：鼠标停在上面能看到完整说明，比行下面那句提示说得更细。改完后页面顶部会出一条结果提示，几秒后自己消失，也可以点右边的 × 关掉；出错的提示不会自己消失，读完再关。

### 13.1 外观

**主题**：上排七套深色，下排是同名的七套浅色，点一下全站换。终端配色跟着亮暗走；已在跑的 Agent 窗口有的不会热更新，重开标签即可。

**跟随系统深浅**：「主题」卡片右上角的开关。打开后，系统切到深色或浅色时，Mesa 自动换成同名的那一套（比如「陶土」↔「陶土 · 浅」）；这时点任一张主题卡只是选配色，深浅仍随系统。自定义配色没有成对的另一套，不跟随。

**我的配色**：主题卡片下半部分。点 **＋ 自定义** 进入调色：下面出现左栏、画布、强调三个色块，点色块用系统取色器改，立即生效；**从当前主题拷入** 把正在用的主题三色填进来，在它基础上改；满意了点 **另存为色卡**，起个名字，它就和你存过的其他色卡排在一起（最多 12 张）。双击色卡改名，鼠标移上去右上角的 ✕ 删除。选中某张色卡再调色，会变成一套未存的自定义，要留着就再另存一次。

**侧栏 / 顶栏透明度**：见 [1.1](#11-界面总览与快捷键)。

**应用图标**：三个选项——跟随系统、深色、浅色。选「深色」或「浅色」，Mesa 运行期间程序坞（Windows 是任务栏）和托盘里的图标立刻换成那一版。Finder、启动台、开始菜单里的图标不受这一项影响，它们由系统决定：macOS 26 及以上会按系统外观设置在深浅两版之间切换，更早的 macOS 和 Windows 一直是深色那版。选「跟随系统」就是不干预，回到系统那一份。退出 Mesa 后程序坞图标也会回到系统那一份，下次启动再按你的选择换。

**底部状态栏**：终端和聊天底下那条，关掉后两边一起消失。

### 13.2 终端

内嵌终端怎么显示、外部终端用哪个，都在这里。

分区最上面是一块 **预览**：几行模拟的终端输出，用你当前选的字体、字号和调色板画出来（中英文、易混字符都有），改下面任一项这里马上变，不用切到运行页开标签看。

| 项 | 说明 |
|---|---|
| 终端渲染 | 改完要重开标签：在意字形选「清晰」（「自动」在 Mac 上也是清晰档、Windows 上是流畅 WebGL），要出字更快选「流畅（WebGL）」。「自动」在 Mac 上对 Gemini 标签例外用流畅档：Gemini 的消息框上下用半格方块留白，清晰档下会断成一条细线加一道缝；不想要这个例外就明确选「清晰」 |
| 字号、字体、滚动缓冲行数 | 字体立即生效，没装上的可一键装；要对齐 Ghostty 选「JetBrains Mono（内置，与 Ghostty 默认同款）」 |
| 终端调色板 | 每套色条下面写着名字，只列出和当前主题亮暗匹配的四套；你之前选的那套和主题深浅不配时，会自动用它配对的另一版，说明里会写出来 |
| 外部终端 | 对话页「在外部终端恢复」、连接页外部启动用哪个终端：自动（依次找 Ghostty、iTerm2、系统终端）、Ghostty、iTerm2、终端。装在 `/Applications` 或你自己的 `~/Applications` 里都认。选 iTerm2 时，命令打在新开的那个窗口里；iTerm2 没开着时，用它启动时自己开的窗口，不会冒出两个 |
| 自定义运行时 | 卡片平时只列已登记的条目。点右上角 **＋ 添加** 才出表单：名称、命令（绝对路径或已在 PATH 里的命令名）、参数、默认工作目录、环境变量。登记后在终端里能像普通终端一样直接跑。鼠标移到某条上出现 **编辑**、**删除** |

清晰档里，滚轮回看历史时还留在屏幕上的行会直接挪位，只重画新滚进来的几行；程序整屏重绘时仍整屏重画。

### 13.3 通用：启动、导航与通知

**启动时进入**：下次打开 Mesa 先进哪一页。

**默认导航形态**：展开侧栏、图标侧栏，或者完全隐藏、只在屏幕顶部留一个「灵动岛」。运行中随时可以临时切换，这里管的是启动时的样子。

**系统通知**：Mesa 窗口在后台、某个任务停下来等你确认时，弹系统通知。在 Mesa 里开的对话，Claude Code、Codex、Qwen Code、Gemini CLI、Kimi Code、CodeBuddy、Grok Build 这七家不用先开精确注意力标记也认得出（Mesa 读终端画面里的确认菜单）；OpenCode 和 Cursor 的确认菜单还没核实过。

**顶部灵动岛** 这一组管侧栏隐藏时屏幕顶部那座导航岛——默认导航形态选了「完全隐藏」，或者运行中按隐藏侧栏快捷键（默认 ⌘\ / Ctrl+\）临时收起侧栏，都会用到它：岛展开后鼠标移开多久收起、Agent 跑完时要不要在岛上报一句、展开后显示符号还是文字，以及岛上放哪些页面入口。

### 13.4 快捷键

**设置 → 快捷键**。点绑定钮，按下新组合就保存；按 Esc 取消。和另一条冲突时不保存。改过的那条右边会出现 **恢复**，点了回到默认；鼠标移到某一行上会出现 **禁用**，点了关掉这一条。

「页面快捷键」卡片右上角的 **页面切换** 是总开关。关掉后卡片里九条都不生效，但仍可以先改好再打开。这九条一键直达九个主页面，Mac 用 ⌘，Windows 用 Ctrl：

| 页面 | 默认 |
|---|---|
| 工作台 | ⌘1 / Ctrl+1 |
| 项目 | ⌘2 / Ctrl+2 |
| 运行 | ⌘3 / Ctrl+3 |
| 对话 | ⌘4 / Ctrl+4 |
| 连接 | ⌘5 / Ctrl+5 |
| 技能 | ⌘6 / Ctrl+6 |
| MCP | ⌘7 / Ctrl+7 |
| 用量 | ⌘8 / Ctrl+8 |
| 设置 | ⌘9 / Ctrl+9 |

**全局快捷键** 卡片里两条可改：命令面板默认 ⌘K / Ctrl+K，隐藏侧栏默认 ⌘\ / Ctrl+\。打开设置固定是 ⌘, / Ctrl+,（Mac 也可走菜单栏 Mesa → 设置…）。

### 13.5 AI 与 Agent → 会话自动命名与 AI 专用配置

这一分区分两节。上面 **内置 AI 功能**：Mesa 自己的 AI 功能（提交信息、摘要、起名、翻译等）用哪份配置，以及会话自动命名。下面 **对 Agent 的约束**：**想法期只读保护**（聊想法时不让 agent 改文件）和 **精确注意力标记**（由 CLI 自己告诉 Mesa 它在做什么、何时停下等你，比读终端画面准，确认卡上也才看得到要跑的命令和要改的内容）。Claude Code、CodeBuddy、Qwen Code、OpenCode、Codex 这五家在 Mesa 里启动时自动带上，不改你的配置，卡片上只写一行说明、没有开关；Gemini CLI、Kimi Code、Grok Build 只认它们全局配置里的 hooks，要用就打开对应的开关（会往该 CLI 的 hooks 配置里写一段，写前自动备份）；暂不支持的几家在卡片底部列一行。不开也行：Mesa 会读终端画面认出审批、信任、切换确认这类菜单，标签黄点、收件箱「待确认」、系统通知照样会响。以前给前面五家打开过开关的，Mesa 会替你把写进它们全局配置的那段收回（写前备份），之后不再需要。

**会话自动命名**（默认开）：聊完用 AI 给会话起 `月日|类型|主题` 的标题，打开对话页时顺手把过短、空泛或撞车的旧标题补好。关掉后 Mesa 不再自动改任何标题——新会话用 CLI 自带标题，已经起好的保留，你自己改过的从来不受影响。

**起名用哪份 AI 配置**：跟其他 AI 功能同一套管法——先用「按功能单独配置」里 **「会话摘要 / 起名」** 那一行选的；那行留空，跟上面 **「AI 专用配置」** 这条；这条选「自动」，就用最近用过的配置。想让起名换个便宜模型，去「会话摘要 / 起名」行单独选——注意起名和会话摘要共用这一行，换模型两边一起换。

**AI 专用配置**：提交信息、摘要、翻译这些生成用这一项。下拉里同一条配置的每个模型各占一行，写成「配置名（Agent · 模型）」，选中哪个就调用哪个。下面「按功能单独配置」卡片按用途分三组——编程（提交信息、PR 描述、冲突建议）、对话与技能（会话摘要 / 起名、接力与评审提炼、沉淀为技能、优化合成技能）、科研（翻译、雷达解读），每行下面一句话写着它用在哪；留空跟着上面这条。选「自动」则用最近用过的那条配置，模型取它的第一个。技能页的「优化合成技能」（多源合成出稿）和「沉淀为技能」各有自己的行，想让合成走便宜或更强的模型去那里单独选。

**雷达解读换模型**：文献雷达的「解读」走「按功能单独配置」里的 **「雷达解读」** 行，与翻译同款。

**翻译换快模型**：沉浸阅读区的划词翻译、⌘+点击段落翻译都走「按功能单独配置」里的 **「翻译」** 行——给它单独选一条快模型配置，阅读翻译就和右栏 agent 各用各的，互不影响。

### 13.6 网络

- **出网代理**：官方账号登录 / 启动、Agent 安装与更新下载用。见 [9.3](#93-官方订阅)。
- **brew 镜像**：用 Homebrew 安装、更新 Agent 和依赖时走国内镜像。只在 Mac 和 Linux 上有这一项，Windows 走 winget。
- **学校图书馆**：见教程「付费墙文献」。

### 13.7 用量

用量页把 token 折成钱时用的两样东西：**汇率**（美元换人民币），和 **自定义定价** 卡片。常见模型已有内置价，只有用量页算不出价、或者价格不对时，才需要在卡片里加一行：填模型名前缀和输入、输出单价（美元 / 每百万 token），改动后卡片右上角出现 **保存**，点了下一次查询生效。

不知道是哪个模型没价时，看卡片下面的 **用量里查不到价格的模型**：列出用过、但查不到价格的模型，按用量从多到少排，附最近一次使用的日期（用订阅额度跑的不计费，不列）。点某一行的 **填价** 会把模型名填进上面的表格，补上两个单价再保存即可。这一列表为空时不显示。

### 13.8 更新

有新版本时左边「更新」旁会亮「可更新」，待处理里也会有一条。进来后点 **下载并安装**，卡片里能看到下载进度和更新说明；装完自动重启，进行中的对话请先保存。没有新版本时这里写「已是最新版本」，可以点 **重新检查**。顶栏帮助菜单的「检查更新」是同一套流程，在弹窗里就能装完（见 [1.6](#16-帮助菜单反馈诊断检查更新与关于)）。

### 13.9 诊断

| 项 | 说明 |
|---|---|
| 依赖体检 | Git、Node.js、Quarto、TeX、PyMuPDF、Pillow 六行（后两个是 PDF 处理库，显示版本号）；下方写「安装渠道」（Homebrew / winget）。Quarto 要真能跑才打勾：找到了但跑不起来（比如 conda 里装出的残缺版本）会写「找到的 …/quarto 跑不起来」，装好官方版后让它排在前面或删掉那个；如果是卸载 conda 版后 Mesa 里还留着它设的环境变量，这一行会直接点名变量、不给安装按钮——从新开的终端重启 Mesa 就好。综述、论文的初稿和定稿开工时，开工确认层的工具检查也会提前说 Quarto 能不能用 |
| 后台任务 | Mesa 在后台替你跑的 Agent（定时任务、起名摘要等），卡住时点 **停止** |
| 应用日志 | 最近 100 条，时间按本机时区显示；可刷新、复制、导出、清空 |
| **导出诊断包** | 出问题时导出、附到「反馈与提需求」里。包里没有密钥；Windows 上额外含系统 / WebView2 / 显卡 / 输入法信息 |
| **生效配置快照** | 点 **导出生效配置快照**，看当前到底用了哪条连接（已脱敏） |

一键安装：PyMuPDF、Pillow 走本机 pip，总能一键；Git 在 Mac 没有 Homebrew 时弹系统安装窗口（Xcode 命令行工具）；其余要有 Homebrew 或 winget，没有就按行内提示去官网下，装完点「重新检测」。Linux 给 `sudo apt install …` 命令（Quarto 需去 quarto.org 下）。TeX 有 xelatex、tectonic、pdflatex 任一个就算 ✓。

### 13.10 数据与存储、卸载

**设置 → 数据与存储** 最上面是 **工作副本位置** 卡片：Mesa 的编程工作树、科研工作副本、定时隔离树都放在这里，用得越多占得越大；默认在用户目录下的 `ccode`（Windows 即 C 盘），C 盘紧张时点 **更改位置…**，选一个别的盘上的文件夹（比如 `D:\mesa`），Mesa 会在里面建 `ccode` 目录。点了之后会先告诉你新位置是哪，确认才生效；选的位置必须可写，不能放进 Mesa 自己的数据目录里，也不要直接选盘根。
- **只管此后新建的**：已有的工作树和工作副本不会自动搬，继续留在原处照常使用；它们在下面「本机占用」里仍会列出，标成「旧位置」。想释放 C 盘空间，到项目页把不用的归档 / 删除，空间才会回来。
- 新位置所在的盘没接上（比如移动硬盘拔了）时，新建会直接报错，不会悄悄回到 C 盘放。
- **恢复默认** 回到用户目录下的 `ccode`。
- 这一项只管工作副本。配置、会话索引、技能库等 Mesa 数据，以及各家 AI 自己的会话目录，位置不变。

下面「本机占用」卡片列出 Mesa 自己占的目录和大小，卡片说明里写总计。分组：**Mesa 数据**（配置、会话索引、技能库、快照、备份等，组名旁写一次所在目录）和 **工作副本**（编程工作树、科研工作副本、定时隔离树，往往占得最多）；换过位置的话，旧位置里还留着的工作副本另成一组。目录太大、统计提前收手时，大小前面带「≥」。右上角 **重新统计** 重算一遍。

鼠标移到某一行上会出现 **定位**，点了在访达 / 资源管理器里打开。**会话快照** 那一行还有 **清理**：快照是你 pin 会话时复制的备份，清理会把整个目录移进系统回收站（能拖回）；原文件已被 CLI 删掉、只靠快照撑着的会话会从对话列表里消失。配置、索引、备份和工作副本不能在这里清——备份里有连接页「恢复初始状态」要用的原样，工作副本里是正在进行的工作，走项目页的归档 / 删除。

**卸载…** 清的是 Mesa 的本机数据：配置与密钥、技能库、会话索引、工作副本、定时任务记录，以及界面记住的最近项目和偏好，都进系统回收站。课题文件夹、论文、各家 AI 自己的会话不动。先确认一次，再在输入框里打「卸载」，点 **确认卸载**。完成后应用退出。退出前的最后一次写入有可能把界面偏好再写回来。

**Mesa 内部对话**（同一页的卡片）：Mesa 在后台替你调 AI——起对话标题、写提交信息、做摘要、解读雷达——会在各家 AI 自己的目录里留下对话记录，一年下来上万条。卡片说明里写着现在有多少条、占多大、最早是哪天。
- 下面一行 **自动清理**：右边开关默认开，每天至多一次，删除超过 **保留** 天数（默认 30 天，可选 7 / 14 / 30 / 90 / 180）的内部对话；说明里写上次清理是什么时候。
- 卡片右上角的清理按钮：有超过保留期的对话时写成「清理 N 条（大小）」，先弹窗告诉你要删什么，确认后删除。直接删除，不进回收站。没有超期的时候按钮是灰的。
- 只清 Mesa 自己的后台对话。你在项目里和 AI 的对话、你点过「保留」的对话一条都不碰；这些后台调用的花费照样留在用量页。
- 起标题、写提交信息这类只问一次的调用，用 Claude Code 或 Codex 时现在已经不留对话记录了，以后增长会慢很多。

应用本身还在。Mac 把 Mesa.app 拖进废纸篓。Windows 到「设置 → 应用」卸载。

### 13.11 关于

**设置 → 关于** 只回答两件事：我装的是什么、出了事找谁。

最上面是 **身份卡**：应用图标、名称、版本号和构建信息（macOS · Apple 芯片这样的字样；开发模式会标出来），下面一行是版权与许可。装了 Intel Mac 自构建版、老怀疑「为什么收不到更新」的，看这里就知道自己不在官方包的架构上。卡片右边两个链接：**GitHub** 在浏览器打开仓库（源码与发布记录，顺手可以点个 Star）；**开源许可与致谢** 点开一个浮层，分两页：「致谢与数据来源」写着用到的字体、平台图标、文献数据来源（只在同步、下载或远查时访问）和设计参考的三家开源项目；「组件许可」列出随安装包分发的全部第三方组件（React、xterm、Rust 依赖……八百多项），可按名字或许可搜索。浮层 Esc 或点外面关掉。有新版本时卡片右边还会多一个 **去安装**，点了跳到「更新」分区。

下面一行 **反馈与提需求**：**打开反馈表单** 与顶栏帮助菜单里的是同一张表单（填法、发送方式与附件见 [1.6](#16-帮助菜单反馈诊断检查更新与关于)）；**去 GitHub 提 Issue** 在浏览器打开仓库的 Issue 页。

页脚一句隐私说明：密钥只存本机，除检查更新、文献检索和你发出的反馈外不上传任何数据；鼠标停在上面能看到每一项具体发给谁。

macOS 用户还会在屏幕顶部的应用菜单里看到 About Mesa——系统标准位置，内容和这里一致。

### 14.2 课题文件夹里有什么

| 路径 | 内容 | 谁写 |
|---|---|---|
| `papers/` | 原始文献 PDF、纳入清单、检索记录、RIS | AI + 你下载的 PDF |
| `papers/imports/` | 你手工放入的题录（RIS / BibTeX / CSV / EndNote 导出） | 你 |
| `.ccode/watch/<巡检任务>/watchlist.md` | 这条文献雷达巡检自己的订阅 | 界面或你直接编辑 |
| `papers/reading-list.md` | 积累清单（**加入积累**的落点），不进 git | 界面或你直接编辑 |
| `notes/inbox.md`、`papers/watch-seen.md`、`papers/watch-followup.md` | 文献雷达的收件箱与台账，不进 git | 雷达采纳后把新命中接在后面 |
| `notes/excerpts.md` | PDF 选段摘录（「整理为笔记」） | 你；精读时 AI 只读并并进笔记 |
| `notes/` | 精读笔记、`index.json`、`handoff.md` | AI |
| `references.bib` | 引文库，正文只用 `[@键]` 引用 | AI 追加 |
| `manuscript/` | 大纲、初稿、定稿、审查报告、`typeface.md` | AI |
| `figures/` | 源图（拼图脚本产出） | AI |
| `output/` | 渲染产物（PDF / Word / 两份域稿），不进 git | AI |
| `submission/` | 目标期刊等投稿材料 | AI |
| `.ccode/` | 项目档案、规则、状态 | Mesa |
| `.ccode/help-wanted.md` | Agent 写给你的求助条（也是「人工请求」的来源） | AI |

项目根 `papers/` 是原始文献专用：AI 下载或关联的 PDF 直接进这里，不经评审。

### 14.3 引用与文献库

| 软件 | 导入 | 同步 | 交稿 |
|---|---|---|---|
| 不用 | PDF 留在项目里，按 DOI 写入 `references.bib` | 无 | Quarto 的 docx |
| **Zotero** | 拖进分类后点「从 Zotero 导入」；要与项目共用同一份 PDF，用「链接到文件」并把链接附件根目录指到 `papers/` | 待获取页或精读步的 **同步到 Zotero**：只交库里还没有的条目（已有的跳过；全都在时提示「新增 0 条」，不拉起 Zotero），并体检你的库、点名旧脏记录 | `output/zotero.docx`，先开 Zotero 应用再用 Word 打开 → 点 **Refresh**（首次弹样式选择框，属正常；插件无反应是 Zotero 未就绪，等它加载完或重开文档）→ 光标点进 References 标题下面的空行（不是标题行本身），点 **Add/Edit Bibliography** 插入参考文献表。**换 Document Preferences 里的 CSL 样式再 Refresh，参考文献格式全局跟着变** |
| **EndNote** | 在 EndNote 导出 XML 或 RIS，放进 `papers/imports/`。不要把 `papers/` 设成 EndNote 的自动导入文件夹 | **同步到 EndNote**（打开 `papers/endnote-import.ris`），并体检你的库、点名旧脏记录 | `output/endnote.docx`，先开 EndNote 应用再用 Word 打开 → 点一次 **Update Citations and Bibliography**（插件无反应是 EndNote 未就绪，等它加载完或重开文档）。引用绑定你的库：**换 Output Style 再 Update，全部参考文献格式一键重排**，不用手动调一条 |

注意事项：

- Mesa 不读 `.enl`，也不把 Zotero 库再倒一遍进 EndNote。
- PDF 要拖到 EndNote 里对应的那一条上；拖到库列表的空白处会另建一条重复记录。
- 域稿绑定的是库里的记录号：在库里删过条目或重新导入过，就要重新生成域稿再 Update/Refresh，否则 Word 里会落到「漫游个人图书馆」。
- 步骤说明不会替你点 Word。
- 润色与定稿、学位论文的格式与定稿、期刊格式适配同时写出两份带引用域的 Word；正文里的拼图会嵌进这两份。LaTeX 稿不交这两份。
- 渲染时复制到 `output/figures/` 的图不另交，源图在 `figures/`。

## 15 出问题了

| 现象 | 处理 |
|---|---|
| Mac 说应用已损坏 | 不是损坏。终端执行 `xattr -cr /Applications/Mesa.app` |
| 点了按钮没反应 | Mesa 不用系统自带弹窗。看页面中间有没有内联输入框或确认层；仍不行到 **设置 → 诊断** 导出日志 |
| AI 只会说话，不建文件、不检索 | 中转上的模型没有「工具调用」，换官方 Claude 或写明支持 tools 的模型 |
| 配置保存了，一运行就 404 | Claude 类地址不要带 `/v1`；Codex / Kimi / Qwen 类通常要带。回连接里再点一次 **验证并获取** |
| 官方账号提示 token revoked | 订阅本身过期，不是 Mesa 搞混了官方和 API。到连接页重新登录；国内配出网代理 |
| 改了模型，窗口里 `/model` 还是旧的 | 只对**新开的**标签生效。停掉当前这次再运行 |
| 待获取点了 **官网**，一直不是 **✓ 已存** | 看按钮是不是「等待收货…」。PDF 要落到系统「下载」文件夹或浏览器的默认下载目录，尽量在一分半钟内下完。对不上会有右下角横幅。实在不行用 **关联** |
| 想一次下完几十篇付费墙 | 不要。出版商会封学校 IP，一篇一篇点 |
| 切到文件看 PDF，再回来清单跳顶 | 应已修好：回来停在原行、已存仍在。若仍跳动，确认更新到含这项的版本，并把现象发到诊断包 |
| 工作区里的对话找不到 | 在所属课题的「对话」里，带步骤名。工作区删了记录还在，可能显示成单独一项 |
| Git / Node 缺失，改动面板报找不到 git | **设置 → 诊断** 一键安装。Mac 若还没同意 Xcode 许可，先处理系统弹窗，不要反复点 |
| 渲染 PDF 失败、拼图失败 | 诊断页看 Quarto / TeX / PyMuPDF / Pillow 是否就绪；正文字体是否装在本机 |
| 不确定 Mesa 用了哪条连接 | **设置 → 诊断 → 生效配置快照** |

问题与想法用应用内「**? 帮助 → 反馈与提需求**」表单，或提到 [GitHub Issues](https://github.com/hongtongzhou-design/ccode/issues)。报缺陷时在表单里点「诊断包」附上一份（或先在「**? 帮助 → 诊断与日志**」导出，再点「附到反馈…」）。不要贴 API 密钥或 token。
