侧栏收成图标、完全隐藏时怎么切对话

背景：「运行」已从展开侧栏、⌘ 快捷键、命令面板、灵动岛撤掉，你也决定图标态侧栏不再留它。那图标态下看不到项目树，完全隐藏时连图标都没有，切对话要有别的路。 已经有的路：⌘K「打开的对话」（这一轮刚加，等确认 / 干活的排前面）、运行页里 ⌃Tab 按最近看过的顺序切、顶栏 / 岛上的活动芯片（只列开着 Agent 的）。 下面是还缺的那一块——鼠标怎么切。示意只画结构，排版、尺寸、动效你来定。

怎么用：鼠标停在图标栏中间那段空白（原来放项目树的位置）约 0.3 秒，或按 ⌘0，整棵项目树从图标栏右边滑出来、盖在内容上（不挤动聊天区）；点一段就打开并收回，鼠标移走 / Esc 也收回。⌘0 进来时光标已在正看着那段，↑↓ 回车照旧。

怎么用：完全隐藏时按 ⌘0 也是方案 A 的「探出整栏」，从窗口左边缘滑出、选完收回，侧栏仍保持隐藏；鼠标贴左边缘停一下同样探出。

我的建议

A + D + E：图标态和完全隐藏都用「探出整栏」（同一棵树，⌘0 / 悬停空白处 / 贴左边缘），完全隐藏时岛上的对话名再当一个快捷切换器。图标态的「运行」图标等探出做好后一起撤掉（先撤就没有鼠标路径回到对话）。 B 适合「收成图标也要盯着几个课题在跑」的用法，代价是多一套长相；C 等于把「运行」换个样子留着，不建议。
