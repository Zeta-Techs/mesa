  • 何时出：第一次选上一段时（⌘ 点进来的，或 B 的「从这段开始选」进来的）
  • 贴在树底「已选 1 段」那条上方，不带按钮
  • 选到第 2 段、或取消选择时自己消失；之后永不再出
  • 它只教「接下来怎么选」，不负责让人发现多选——要和 A / B / C 之一搭配

我的建议：B + D

B 只在用户正一段段收拾时出现，这时候说「可以一起选」最有用、最不烦人；点「从这段开始选」接上 D，教完 ⌘ / ⇧ 两种选法后自己消失。

如果希望每个人都至少看到一次，把 B 换成 A（文字气泡），C 的小动画留给发版后「新功能」提示用。
