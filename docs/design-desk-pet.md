# 桌宠「小桌」设计稿

2026-11-09 用户问「桌面助手可以做成桌宠吗，任务跑完、步骤跑完、各种事项交给桌宠」，看过方案后拍板「按你推荐全部做吧，设置里也要对其设置」。

## 1. 是什么

项目助手的形象小桌待在桌面上：一个透明、无边框、置顶的小窗（`src-tauri/src/desk_pet.rs` 建，`pet.html` → `src/pet/`）。
它跨项目报信——哪件事在等你、哪一步跑完了等评审、哪里出错了；点开能就地办一部分，其余「去看看」回 Mesa 里办。
默认关，设置 → 通用「桌宠」与托盘「在桌面上显示小桌」开关（同一项设置）。

## 2. 规则

1. **桌宠是第三个出口，不是新的判定。** 「等你的事」照搬项目助手的调度台（`assistant-queue.ts` buildDeskItems，手机同一份），
   「做完 / 出错」照搬「现在的情况」卡的取数（`gatherBriefInput`）。卡在哪仍只经 `run-blocker.ts`。桌宠不另写一套判断。
2. **能点什么按 `assistant-ops.ts` 分级，与手机同档。** 就地：选人工请求的选项、写一句送过去、放宽重跑一次 / 不用、
   替你按信任菜单（只限经项目助手派出去的活）。只在桌面的（评审采纳、写回、确认命令、删除……）一律「去看看」。
3. **话由 Mesa 按记录拼，不经 AI**（同 `guardClaims` 口径：项目助手的话不当事实）。
4. **少占注意力。** 冒话只在新来一件事时冒一次（第一次拿到清单不冒，开机不冒一串），挑最要紧的一件（出错 > 等你拍板 > 做完），
   8 秒自己收起；设置可改成「不说话，只换样子和数字」；右键「勿扰一小时」期间不冒话、不做反应、不挂角标。
5. **清单由主窗口拼。** 原定在 Rust 后端另做汇总，动手时核出「等你的事」有一部分（终端里等确认、AI 在对话里问你）只在主窗口读屏才知道，
   后端另做一份既重复判定、又比手机看到的少，改为主窗口 `desk-pet-host.ts` 每 20 秒拼一份发给小窗（小窗刚开时立刻发）。
   主窗口关着只是藏到后台，照常供数；退出 Mesa 时桌宠一起走。等常驻后端落地，调度台连同桌宠的取数一起搬。
6. **小窗不挡桌面。** 平时只有小桌那么大；冒话 / 点开时临时变大，往屏幕里侧、往上长（上面放不下就往下），小桌在屏幕上的位置不动。
   拖动换位置，拖完记下；记下的位置不在任何一块屏上（拔了外接屏）时回到主屏右下角。

## 3. 样子

精灵图同项目助手（`src/assets/buddy/xiaozhuo.webp`），为桌宠补了三行：等你回（歪头、手抬到肩）、被拖着往右走、往左走（右走镜像）。
先后：被拖着走 > 刚来的反应（出错垂头丧气、做完蹦一下）> 有事等你（等你回 + 琥珀角标数）> 有活在做（托腮想）> 按时间（早上咖啡、傍晚台灯、夜深盘腿睡）。
夜深了有事等你照样醒着等。

## 4. 交互

- 左键点小桌：开 / 收「要你看一眼」小卡片（按项目列，类别小字同调度台叫法），最下面问项目助手（第二期）；一个项目都没有时最下面是「打开 Mesa」。
- 冒的话：点一下展开小卡片，✕ 知道了。
- 拖动：按住移动超过 4px 交给系统拖窗口，按移动方向往左 / 往右走，停下 300ms 记位置。
- 右键（系统菜单）：打开 Mesa、勿扰一小时 / 结束勿扰、桌宠设置…、隐藏桌宠（关掉开关）。
- 去看看：步骤出错 → 工作台那一步的任务面板；做完等评审 → 评审页；目标 → 项目页；等确认 / 卡住 → 那个终端标签；其余 → 那个项目的项目助手。

## 5. 第二期（2026-11-09 用户「接着第二期」）

- **问小桌**：「要你看一眼」卡片最下面一个项目下拉 + 一句话，交给那个项目的项目助手（同手机 `askProjectAssistant`，问答照常记进那个项目，
  `where` 写「桌面上的小桌」）。默认问哪个项目：上次问的那个还在就用它，否则最上面那件事的项目，再否则第一个；下拉里有事的项目排前面。
  边想边显示它在读什么；回答经 `guardClaims`。它的追问带选项时选项成按钮，点了当下一句问回去（clarify_answer = tap）；
  起草了派活单 / 补料单 / 以后照这样办、或给了去处按钮的，桌宠上不办，只说一句并给「在 Mesa 里看这条回答」（打开那个项目的项目助手）。
- **朝鼠标倾身**（原「眼睛跟鼠标」）：出图模型照 hatch-pet 出了两版「看向八方」，眼睛是实心黑椭圆，看向只靠高光挪一点，112px 下分不出，
  质检不过、不进图；改成整个小桌朝鼠标那边转几度、挪几像素（`petLean`，封顶 6° / 4px，太近太远站正），只在面板收着、没在走 / 做反应时，
  约 150ms 取一次鼠标位置（`desk_pet_cursor`）；睡着不转；减弱动态效果时不动。
- **系统通知不重复**：桌宠开着、会说话、不在勿扰时，终端里等你确认、新的人工请求这两类由小桌说，不再另弹系统通知（`petSpeaksInstead`）；
  定时任务跑完、手机发来东西照旧弹。勿扰时间存在本机，主窗口与小窗同源共用。

## 6. 平台

Tauri 透明置顶窗：macOS 已开 `macOSPrivateApi`；Windows 透明 WebView2；Linux 本版本未开发。
小窗权限单独一份 `src-tauri/capabilities/desk-pet.json`（拖动、量位置、改大小、右键菜单），不给文件、对话框、更新等。
建窗的命令一律 async（同步命令跑在主线程，Windows 上在里面建窗会卡死）。
