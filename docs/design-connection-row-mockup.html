方案 A · 只说例外，行收成两行

推荐
  • 正常不写字：测试通过、未测都不占位置；只有测试失败 / 缺密钥 / 模型不在目录这类要你处理的才在行尾写字（和网关库「出问题才写字」同一口径）。
  • 想确认测过没有：图标右下角一个小点（绿 = 上次测试通过，没点 = 没测过），悬停名字写「上次测试通过 · 10-30 14:02」；悬停行出「测试」。
  • 「全局使用中」改成名字旁的小签「全局」，整行淡蓝底和左缘短条保留；外部改过时小签变黄「外部改过」。
  • 「上次使用」并进第二行右端，行高从三行变两行；「编辑」和 ⋯ 悬停才出，点整行空白处也是编辑（网关库同口径）。
  • 官方账号行去掉右侧重复的「官方账号」，套餐（Free）留在第二行开头。
