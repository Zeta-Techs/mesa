# README 展示素材清单

README.md / README.en.md 里注释掉的图位按这里的文件名取图。素材放进本目录后取消对应注释即可。

## 通用要求

- 只在 `npm run tauri:dev` 的 **Mesa Dev - 热更新** 窗口拍，不用旧安装版。
- 窗口拉到 1600×1000 左右，界面大小用默认档；导出 PNG，单张控制在 1 MB 以内（`pngquant` 或转高质量 JPEG 都行）。
- 主题统一用默认「极简灰蓝」深色；另想要浅色版的话同名加 `-light` 后缀。
- 用示例课题（侧栏 **新项目 → 创建示例课题**）或干净的演示项目，**画面里不能出现真实密钥尾号、邮箱、个人路径和未公开的课题名**。连接页用示例名称（如「DeepSeek」「智谱」），官方账号悬停邮箱的提示不要截进去。
- 侧栏里的对话标题换成演示用的标题。

## 视频

`docs/guide/tutorial.md` 里已有 80 秒上手视频（`user-attachments/assets/d1e26c7a-…`），拍在上手向导和管理页改版之前，**不建议直接放首屏**。

建议重录一段 30～45 秒的首屏视频，无配音、极简配乐或静音：

1. 打开 Mesa → 上手向导里接上一家 Agent（5 秒）
2. 新对话，发一句，聊天层流出回答（10 秒）
3. `⌘⇧T` 切到终端再切回（5 秒）
4. 示例课题的步骤点「开始」，进评审页看改动、点保存进项目（15 秒）

导出 MP4（≤10 MB），拖进任意一个 GitHub Issue 或 PR 的评论框，拿到 `https://github.com/user-attachments/assets/...` 链接，把链接给我，我把它放进 README 首屏（GitHub 会渲染成可播放的视频）。
