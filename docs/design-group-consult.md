# Mesa 设计稿：会诊——同一个问题请几家 AI 一起看

> 状态：**草稿，待拍板**（2026-11-11）。界面稿 `docs/design-group-consult-mockup.html`。
> 起因：用户问「ClawChat 的哪些 Mesa 可以借鉴，创建群组？」。对照 ClawChat（`Lenka0605/ClawChat`，本地多 AI 群聊）与 Mesa 已有的
> 项目内协作（`design-project-coordination.md`）、项目助手（`design-project-assistant.md`）、跨厂商复核（`design-research-moat.md` §3.1）后，
> 推荐不照搬「什么都能干的群」，只做**只读、先各答各的、人收尾**的会诊。§11 列待拍板的几处。
> 同日修订（用户追问「同一个 CLI 换不同模型会诊有什么区别」后要求改）：成员差别看**模型族**、能不能看项目看**CLI 外壳**，两件事分开；
> 默认先保证模型族不同，再挑能看项目的外壳；成员按模型族起名。见 §3 第 6 条、§4.1、§5.2、§5.4。

## 0. 一句话

科研里有些判断不该只听一家：这个方法站不站得住、这段结论有没有说过头、这条审稿意见该接受还是反驳。
会诊让你把一个问题连同材料交给二到四家 AI，**第一轮各答各的、互相看不见**，再亮出彼此的答案让它们补充或反驳一轮，
最后由你决定记下什么、要不要派活。会诊只看不动：不改文件、不跑命令，要动手就交给已有的派活单。

## 1. 参考：ClawChat 怎么做，Mesa 取什么

ClawChat 把 Claude Code、Codex、Gemini、Grok、Cursor 以及借 Claude Code 跑的 DeepSeek / GLM / 任意 OpenAI 兼容平台拉进一个群，
共用一个项目文件夹。调度核心在 `lib/hub.js`（谁接话、接力、轮数上限、停止）。

| ClawChat | 做法 | Mesa 取舍 |
|---|---|---|
| 群 + `@` 点名、`@所有人` | 输入 `@` 弹成员菜单；只有被 @ 的才被叫醒 | **取**。会诊里追问用 `@某家` / `@所有人` |
| AI 互相 @ 接力 | 人不说话时连续接力到上限就停，等人发话（默认 25 轮，`store.js maxAutoTurns`） | **取，上限压低**：默认 2 次，可调 0–6。会诊是为了让人判断，不是让几家自己聊到天亮 |
| `[PASS]` | 跟自己无关或没有新东西就只回 `[PASS]`，群里不显示 | **取**。交叉轮和接力里没补充的不占版面，记录里留「没补充」 |
| 动手权限三档（项目内放手干 / 完全放开 / 只读讨论） | 每个群单独设 | **只取只读**。改文件走目标 / 步骤的隔离副本和评审，会诊不开第二条写路 |
| 私聊（`<私聊老板>`、AI 之间 `<私聊 X>`） | 用标签把话只发给某一位 | **不取**。要人回答的事走人工请求（`.ccode/help-wanted.md`），AI 之间不需要背着人说话 |
| 分身 | 本体忙时复制会话开只读分身回话 | 会诊不需要（每轮都是新的无头调用，没有「忙着的本体」）；作为独立小改动见 §10.2 |
| 换新会话时请另一位 AI 交代 | 三选一：AI 交代 / 带最近 40 条 / 我自己交代 | Mesa 已有「换 Agent」接力简报，不重复 |
| 联合群（经 Tailscale 和同事的 AI 同群、Touch ID 确认传文件） | 跨机器、跨主人 | **不取**。违反「跨项目不直连」，安全面太大 |
| 气泡配色、消息朗读 | | 不取（朗读已否） |

ClawChat 没有、Mesa 要加的：**第一轮互相看不见**（防后答的跟着先答的走）、**依据必须能定位到文件**、**结论由人记**。

## 2. 和已有功能的分工

| 已有 | 管什么 | 会诊和它的关系 |
|---|---|---|
| 跟 AI 商量一下（步骤卡、聊想法、问 AI） | 和**一家** AI 聊课题内容，能接着在原对话里干活 | 会诊是「商量」的多家版。一家能聊清楚的照旧用商量 |
| 项目助手 | 问项目和 Mesa 的运转：进度、报错、规划；起草派活单 / 补料单 | 不重叠。项目助手判断你在问一个需要几家意见的内容问题时，给按钮「找几家会诊」（预填问题）；会诊要动手时，把会诊记录交给项目助手起草派活单 |
| 跨厂商复核（评审页「请另一家复核」） | 一家逐条核对稿件里的引用是否被原文支持，结论进核验记录 | 不合并。复核是**有固定对象的核验**，结果进 `.ccode/checks/`；会诊是**开放问题的讨论**，不产核验结论 |
| 留话（`mesa_helper tell`） | 同项目两段工作之间传话 | 不重叠。会诊成员不是在干活的工作，不收也不发留话 |
| 拆成几路做 | 出拆分方案、人批准一次开齐 | 不重叠。会诊不拆活 |
| 换 Agent / 接力 | 一段对话换一家接着做 | 不重叠 |

**为什么不做 ClawChat 式自由群**：11-03 的协调对话已经因为「为了协调另开一段对话没必要」并回工作台（`design-project-coordination.md` §11）；
项目助手是问进度的唯一入口；群里的 AI 能写文件、互相派活，就绕过了隔离副本、评审和「AI 提议、人批准一次」。
剩下真正需要「一屋子 AI」的，只有要几家各自判断的内容问题，这就是会诊。

## 3. 规矩（写死在提示词，Mesa 兜底）

1. **只看不动**：成员只能读项目里的文件，不改文件、不跑命令、不联网、不调 MCP。能读项目的那几家走进程级只读（§5.2），其余几家只看 Mesa 附上的材料。
2. **先各答各的**：第一轮所有成员同时作答，提示词里没有别家的答案；Mesa 等这一轮全部回来（或单家超时 / 被停）才一起亮出来。
3. **再交叉一轮**：亮答案后自动进交叉轮。每家拿到其他几家第一轮的回答，只写补充、反驳或改判；没有就回 `[PASS]`。交叉轮数默认 1，开会诊时可选 0–2。
4. **接力有上限**：之后 AI 回答里 `@` 别家会叫醒对方，但你不说话时最多连续 2 次（可调 0–6），到了就停，写一句「先停一下，等你发话」。你说一句话计数清零。
5. **回答格式固定尾段**：每条回答末尾三行——`结论：`一句话；`依据：`项目内相对路径加位置（行号、页码或章节），可多条；`没把握的：`可空。
   Mesa 只做两件事：把各家「结论」并排成对照条；把「依据」里的路径查一遍，不存在的标「找不到这处」。**Mesa 不判谁对、不投票、不出共识、不打分。**
6. **差别看模型族，不看 CLI**：会诊要的是几种互相独立的判断，判断的差别来自模型——训练数据和偏好不同，盲区才不同。
   同一家的几档模型（Claude 的 Opus / Sonnet / Haiku，GPT 的大小两档）盲区相近，三位一起答接近一票；同一个模型换个 CLI 外壳更是同一票。
   反过来，同一个 CLI 外壳接不同家的模型（Claude Code 分别接 Claude、GLM、DeepSeek、Kimi）是**几家**，而且读材料的工具一样，差别更干净地落在判断上。
   所以「同一家」一律按模型族判（`cross-review.ts modelFamily`，与跨厂商复核同口径）：两位成员同族时，开会诊和成员胶囊上都标「同一家模型，意见可能雷同」，不拦——
   有时你就是想看大小模型答得差多少，只是那不算会诊。
7. **不替人拍板**：结论只由你记（§4.4）；不替你回答人工请求、决策项，不建议换模型（「Mesa 不替人自动回答」「不做模型路由」照旧）。
8. **只认这个项目**：材料只能是这个项目里的文件；记录不出项目，别的项目看不到。

## 4. 一次会诊怎么走

### 4.1 开会诊

入口（不在步骤卡上加按钮，`step-panel.md` 主路径唯一）：

- **对话页**：左栏「新对话」旁的下拉里加「会诊…」。
- **对话回放头部 ⋯ 菜单**：「请几家会诊这个问题」——当前对话里你最后一句话作问题、这段对话作材料。
- **项目助手**：回答里的动作标记 `会诊`（白名单加一项），预填问题和它点到的文件。
- **评审页**（二期，待拍板 §11-4）：不加常驻按钮，只在 ⋯ 菜单里加「请几家会诊这一处」（选中段落作材料）。

弹层一屏填完：

| 栏 | 内容 | 默认 |
|---|---|---|
| 问题 | 一句到一段话 | 入口预填 |
| 材料 | 项目里的文件（可选到段落 / 页码范围）、选中的文字、贴图 | 入口预填；最多 8 份，超过总长度上限时提示删 |
| 成员 | 二到四位，每位 = 连接 × 模型（与复核下拉同一份 `reviewerOptions`），卡片上写模型族、经哪个 CLI、「能看项目」或「只看材料」 | 见下方「默认挑法」；记住上次选的 |
| 交叉 | 0 / 1 / 2 轮 | 1 |
| 预估花费 | 成员数 × (1 + 交叉轮数) 次调用，按各连接上次同类调用的花费估 | 只显示，不拦 |

**默认挑法**（没有上次的选择时）：

1. 第一位是「问 AI / 聊想法」那条连接与模型。
2. 之后每一位**先保证模型族和已选的都不同**；同族的不进默认。
3. 同一个模型族有几条连接可选时，**优先 CLI 外壳能看项目的**（§5.2：Claude Code、Codex 外壳），其次一等 Agent，再其次最近用过的。
4. 凑不满三个不同模型族就少选，不拿同族的补；只挑得出一族时弹层写「只配了一家模型，会诊意义不大」，仍允许你手动加。

这样默认组合多半是「Claude Code 外壳 + 三家不同的模型」，几位都能看项目。不按问题内容挑模型（「不做模型路由」照旧），只按上面的固定次序。

主按钮「开始会诊」。

### 4.2 第一轮：各答各的

- 所有成员同时开跑，每家一张卡片**并排**（窗口够宽三列，否则两列，再窄纵向），卡头写成员名（模型族）、模型、经哪个 CLI、「能看项目 / 只看材料」。
- 进行中显示「正在看 `methods.md`」这一类过程摘要（来自流式事件，只给读了哪个文件，不给内容）；每张卡有「停止」。
- 有人先答完时，**它的卡片只显示「已答完 · 等其他几家」，内容先不展开**（防止你先读了一家就带着它的看法读别家）。全部回来后一起展开。
  这条是待拍板项（§11-2）：也可以先答完先看。
- 单家 240 秒没答完按超时处理（同 `INSPECT_TIMEOUT`），卡片写「超时，没答」，不挡其他家；出错的写一句白话原因加「重试这一家」。

### 4.3 亮答案、交叉、追问

- 第一轮卡片下面出现**结论对照条**：一行一家，左边成员名，右边它的「结论」原话；「依据」里找不到的路径标黄。Mesa 只排版、不加评语。
- 交叉轮的回答按普通聊天流排在下面，每条开头写「回应 GPT」「回应 Claude」这类，由成员自己 @ 出来；`[PASS]` 的不显示，在对照条那一家后面加小字「交叉：没补充」。
- 你随时可以在下面的输入框说话：`@GPT 你说的样本量不足依据在哪` 只叫那一家；不 @ 就是 `@所有人`。输入 `@` 弹成员菜单。
- 停止：单家停在它的卡片 / 消息上；输入框右边「全部停止」。

### 4.4 收尾：只由你记

每条回答悬停出现三个动作，会诊顶栏有「收尾」菜单：

- **记进项目知识**：打开项目助手同一张 `RememberCard`，预填这条回答的「结论」，你改写后点「记进项目知识」才写进「已定 / 不做」。一次只记一条，不批量采纳。
- **起草派活单**：把这次会诊的问题、对照条和你选中的那几条回答交给项目助手（作为本次重点），由它起草派活单；派不派你在项目助手里点。会诊自己不出派活单。
- **复制**：Markdown 原文。

会诊结束不需要「关闭」：没有进行中的调用时它就是一份记录，可以接着追问。

## 5. 每家怎么跑

### 5.1 一轮一次无头调用，不续 CLI 会话

- 每位成员每次被叫到 = 一次一次性无头调用；**记忆就是 Mesa 拼的会诊记录**，不续 CLI 自己的会话。
  理由：①只读无头已经验证过的路径都是一次性的（Claude Code `--no-session-persistence`、Codex `--ephemeral`）；②一次性内部调用不落盘（AGENTS.md）；
  ③第一轮「互相看不见」要求提示词完全由 Mesa 控制，续 CLI 会话做不到。
- 代价是每轮都要重读材料、重付上下文。缓解：提示词里先放会诊开场（规矩 + 问题 + 材料摘录），记录超过长度上限时，先把最早的交叉轮全文换成各家「结论」一句。
- 每家每次调用照无头调用记账（`record_ephemeral_usage`），归在用量页「内部活动」之外——会诊是你主动开的，算正常用量，按成员所用连接记。（待拍板 §11-5）

### 5.2 能看项目 / 只看材料

档位**按成员那条连接的 CLI 外壳定，与接的是哪个模型无关**：只读靠的是 CLI 的进程级参数（Claude Code 的工具白名单、Codex 的只读沙箱），
对任何模型都一样生效。所以 Claude Code 接 GLM、DeepSeek、Kimi 模型的 API 连接，一样能看项目。

| 档 | 哪些连接 | 怎么跑 |
|---|---|---|
| 能看项目 | CLI 外壳是 Claude Code、Codex 的连接，不论模型（一期）；Kimi CLI 外壳在一期内实测后加 | `ai_inspect_readonly`：工作目录 = 项目根，进程级只读（Claude Code `--tools Read Grep Glob --strict-mcp-config`，Codex `-s read-only`），提示词里点名材料路径，让它自己读，也可以顺着依据去翻别的文件 |
| 只看材料 | 外壳是其余几家 CLI 的连接 | `ai_prompt` 在临时目录跑（不碰项目）；Mesa 把材料摘录贴进提示词，有总长度上限；提示词写明「你看不到项目文件，只能依据下面的摘录，依据写摘录里的路径和位置」 |

- 成员卡片和开会诊弹层都写明是哪一档；「只看材料」的成员提的依据如果超出摘录范围，Mesa 照样查路径存不存在，并标「它没看到这份文件」。
- 贴图：看图看的是**模型**（`model_registry` 的 vision，`model_supports_vision_for`），认不出的按看不了。能看图的模型、外壳又能看项目时走 `image_prompt_note` 同一套（Codex `--image`、Claude Code 点名路径 Read）；其余情况卡片上写「图没给它看」。
- 同一个外壳接别家模型要留意两件事：①有的模型调用工具弱，不会自己去翻文件，只凭提示词里那点东西回答——依据核对（§3 第 5 条）能暴露，挡不住；提示词里把材料路径点名、要求先读再答。②思考档位的线协议各家不同（如 GLM 的 effort），一律沿用连接页已有的注入规则，会诊不另设。

### 5.3 调度

- 第一轮并发（最多 4 家）；交叉轮并发（彼此看的都是第一轮，互不依赖）；之后按 `@` 的先后串行，同一条消息 @ 了几家就并发。
- 接力计数按会诊记，你发一句话清零；到上限写系统提示一句，不再叫醒。
- 停止走 `kill_process_tree`，被停的那次记「你停了」，下次叫到它时提示词里写「上次被你停了」。
- Mesa 关着时会诊不跑（长循环不进前端：调度写在后端，`consult.rs`，见 AGENTS.md「终局方向」）。

### 5.4 成员名与 @

- 成员显示名 = **模型族名**（Claude、GPT、Gemini、GLM、DeepSeek、Kimi…，与 `vendor-icon` 同一份），不用 CLI 名——三位都经 Claude Code 时按 CLI 起名分不开。
  同族两位时加短模型名区分（Claude·Opus、Claude·Sonnet）；认不出模型族的用连接名。经哪个 CLI 写在胶囊小字里，不进名字。
- 成员标记跟模型族走：用 `vendor-icon` 的厂商图标（认不出的首字占位，与连接页同口径），不用 CLI 的 `AGENT_BRAND` 色；不为会诊另起一份颜色表。
- `@` 只认本会诊的成员名和「所有人 / 大家」；回答里 @ 了不在会诊里的名字当普通文字。

## 6. 界面（见 `docs/design-group-consult-mockup.html`）

- **对话页左栏**：会诊和普通对话在同一个列表里。行的 Agent 胶囊换成成员的厂商图标叠（最多四个），标题照 `MMDD|类型|主题`（类型多半是「研究」），meta 行写「会诊 · N 家」。
  点开右侧回放区换成会诊视图。
- **会诊视图顶栏**：标题、成员胶囊（厂商图标 + 模型族名 + 模型 · 经哪个 CLI · 档位小字）、本次花费、「收尾 ▾」、⋯。
- **问题卡**：问题原话 + 材料清单（文件名 + 位置，点开在文件面板看）。
- **第一轮并排卡片 → 结论对照条 → 交叉与追问聊天流 → 输入框**，自上而下一条主线。
- 输入框：`@` 菜单、附材料、右侧发送；有成员在跑时右侧是「全部停止」。输入框上方一行小字写「你不说话时，它们最多再互相叫 2 次」。
- 颜色：成员标记见 §5.4（厂商图标，不按 CLI 上色），卡片底是普通 `.ccode-well`，不按家给气泡上色。

## 7. 数据与文件

| 东西 | 放哪 | 说明 |
|---|---|---|
| 会诊记录 | 项目 `.ccode/consults/<时间>-<短id>.jsonl` | 一行一条：问题、材料清单、成员（连接 id、模型、档位）、每条回答原文、轮次、花费、停止 / 超时。与研究记录同口径不进 git；出 Rust 前脱敏 |
| 会诊列表索引 | `app.db` 新表 `consults`（项目、标题、成员、最后活动时间、title_source） | 对话页列表读它；标题自动起名照会话标题规则，人改过的不覆盖 |
| 上次选的成员 | localStorage `consultLast:<项目>` | 只是预填 |

- 删除会诊 = 删那份 jsonl 和索引行（回收站）；用量行照「用量历史永久保留」不删。
- 不进项目助手的问答记录，不进收件箱；会诊里有成员出错不弹窗，只在卡片上写。

## 8. 不做什么

- 不写文件、不跑命令、不联网；不开「项目内放手干」「完全放开」档。
- 不做 AI 私聊、分身、跨项目、联合群。
- 不投票、不出「共识」、不打分、不自动采纳任何结论。
- 不自动开会诊（事件规则、定时任务都不能开），不自动把结论写进任务书或项目知识。
- 不按问题自动挑成员或模型（只记住你上次的选择）。
- 不替代商量、复核、项目助手。

## 9. 分期

| 期 | 内容 |
|---|---|
| 一 | 后端 `consult.rs`（调度、记录、路径核对）；对话页列表与会诊视图；开会诊弹层（含默认挑法）；Claude Code / Codex 外壳的连接不论模型都能看项目，其余只看材料；接力上限；收尾两条（记进项目知识、起草派活单）；项目助手动作标记 |
| 一（续） | Kimi CLI 外壳的只读无头实测（`kimi --print` + 只读参数），过了就进「能看项目」。在那之前 Kimi 模型可以经 Claude Code 外壳的连接参加并能看项目 |
| 二 | 对话回放 ⋯「请几家会诊这个问题」；评审页入口（看 §11-4 拍板）；预估花费按历史校准 |
| 三 | 会诊结论可「提升到研究档案」，研究记录写清这条判断经过哪几家、谁用什么模型 |

## 10. 同批可做的三处小改动（同样借自 ClawChat，和会诊无依赖）

1. **留话接力上限**：`project_mail.rs` 现在只限单条 2000 字，两段工作互相 `tell` 没有次数上限。照会诊同一条规则：人不在工作台操作时，同一对工作之间连续自动送达超过 N 条（默认 4）就停送，
   工作台「同项目留话」那一行写「它们来回了 4 次，等你看一眼」，你点「接着送」才恢复。
2. **问正在干活的那段一句**：任务面板里一段工作正在跑时加「问它一句（不打断）」：用原生分叉（`pty.rs fork_session_id`）在临时目录以只读无头起一份它当前会话的副本回答你，答完丢掉；不进它的会话、不打断本体。
   一期只做 Claude Code / Codex。
3. **Codex 会话里图片太重的提醒**：ClawChat 实测 Codex 会把看过的每张图原样存进会话、每轮重发，8MB 起变慢、超过 17MB 几分钟没反应。
   Mesa 的做图步骤正好会让 Codex 反复看图，但 `ContextRing` 不算图片体积。在上下文用量圈上加：会话里图片累计 8MB 变橙、13MB 变红，点开说明并给「换新会话接着做」（走已有接力简报）。阈值待在 Mesa 里实测。

## 11. 待拍板

1. **名字**：「会诊」（推荐，一个词说清「几家看同一个问题」）/「几家一起看」/「圆桌」。定了要进说明书 §14.1。
2. **第一轮先答完的能不能先看**：推荐**全部回来再一起展开**（防先入为主）；代价是要等最慢的那家（有 240 秒上限，可单家停）。
3. **交叉轮默认 1 轮、接力上限默认 2 次**：推荐照此；ClawChat 默认 25 轮接力，对会诊太多。
4. **评审页要不要放入口**：推荐二期放在评审页 ⋯ 菜单里（不加常驻按钮），与「请另一家复核」并存。
5. **会诊花费算不算内部活动**：推荐**不算**（是你主动开的，算正常用量，热力图照常着色）。
6. **成员上限 4 家**：推荐照此，超过四家对照条读不过来，花费也翻倍。
7. **§10 三处小改动**做不做、和会诊一起排还是先做。

## 13. 验收清单（落地时逐条过）

- 第一轮提示词里确实没有别家答案（单测钉住提示词拼装）；全部回来前卡片不展开。
- 能看项目的成员在真实项目里只读：试着让它改文件、跑命令，都被挡住（Claude Code、Codex 各一次，macOS + Windows）；Claude Code 外壳接一个非 Anthropic 模型（如 GLM）再挡一次。
- 默认挑法：只配了同族几条连接时不凑同族、弹层写明；有 Claude Code 接三家模型的连接时，默认三位都是能看项目的。
- 工具调用弱的模型没读材料就作答时，依据核对能标出来（拿一个实际表现差的模型干跑一次）。
- 只看材料的成员不碰项目目录（工作目录是临时目录，跑完删掉）。
- 依据路径：存在的不标、不存在的标「找不到这处」、超出摘录范围的标「它没看到这份文件」。
- 接力到上限停下并提示；你发一句话后计数清零。
- `[PASS]` 不显示，对照条写「交叉：没补充」。
- 停止单家 / 全部，进程树都收掉；超时不挡别家。
- 记进项目知识只经人点，写进的是你改写后的那句；起草派活单落到项目助手、派不派由人点。
- 会诊记录出 Rust 前脱敏；记录不进 git、不进评审带回清单。
- 花费逐次记账，用量页能看到。
- 在 Mesa Dev 窗口实际开一次三家会诊走完全程（按「动真实数据先干跑」规则，先在测试项目上）。
