对话页的样子 → MCP 页怎么套

标题栏2xl 大标题 + 蓝色主按钮 → 40px 栏，左「MCP 3 个」，右「全部检测」「添加 MCP」两个中性小按钮（同对话头右侧按钮）
宽度1440px 铺满 → 742px 居中，等于对话栏
分层卡片底 + 表头 + 行间横线 → 不画框，名称 l1、类型·命令 l4 两行，靠留白隔开
底色只有展开着的那条铺对话气泡色，其余只有悬停反馈
展开区卡底 + 九宫格小卡 → 左侧细线缩进（同「已思考 ›」展开），各 Agent 开关排成无底的两到四列
徽章stdio / remote 灰底徽章、告警色块 → 纯文字，告警用字色

保持不变

  • 条目顺序、每行信息（健康点、名称、需登录 / 连不上、类型、命令、用于 N 个 Agent、N 处异常、启用开关）。
  • 悬停才出现的检测 / 编辑 / 删除；点「N 个 Agent」也能展开。
  • 展开区内容：完整命令、相对路径修复、环境变量 / 请求头、密钥已填 / 未填、分发五态、未安装、Grok 只读。
  • 「添加 MCP」菜单原样，编辑 / 删除 / 收编 / 粘贴的弹窗不动。

要你拍板

  1. 列宽 742px 居中：改的是 2026-10-13「资源五页 wide 1440」的口径（MCP 先试，其余页后跟）。
  2. 页头去掉 2xl 大标题和蓝色主按钮，换成 40px 标题栏 + 中性小按钮。
  3. 去掉表头，类型和命令并成名称下一行灰字。
