Mesa 连接模块全链路 UI 优化对比
01 · 两层心智一眼看懂
「网关存钥匙」→「连接绑 Agent」
入口按钮直接带网关数与健康点（网关库 · 4），编辑连接顶部固定单行「来源网关摘要条」，不再靠零散说明文字解释两层关系。
02 · 砍掉断头路与双层开关
新建即闭环 · 来源三选一平铺
「新建网关」合并 验证连通并拉取模型，并支持顺手勾选绑给哪些 Agent（告别建完 0 连接）；「添加连接」把叠两层的 SegTabs 收成一行三卡片。
03 · 高频信息外露、低频收拢
不靠悬停猜，不被冷门项刷屏
网关库直接展示密钥尾号、已通协议槽、模型数与「一键配齐 CLI」；连接页左栏折叠未安装 CLI、对齐数字，行内突出默认启动模型。
04 · 严守 Mesa 设计语言
全幅 PagePanel · 无嵌套卡片棋盘
保持全内容区推入页（不回退小弹窗、不加无用表单左侧目录），严守 --l1..--l4 四级字色、--well 凹槽与第三方首字图标规范。
