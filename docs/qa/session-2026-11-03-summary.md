## 验证情况

- **每个提交**：改到的那一侧基线全绿（Rust `cargo test`、前端 `npm test` + `npm run build`）。
- **真实数据 / 真 Agent 干跑**（都在临时目录或只读，不动你的项目）：
  - Codex 按固定格式写人工请求、真解析器读成卡片并回写；送达后先记已定口径再删条目
  - 真实项目副本另存 / 加进我的任务；Codex 按 SOP 写包 0 问题；Codex 跑包内核验，解析成拦下 1、待判断 2
  - 六套内置模板经后端存取一轮比对全等（「内置有更新」不误报）
  - 看一眼：真实 app.db 只读干跑；Codex 沙箱里自己调 peek（发现终端乱码事件与大文件占满片段，已修）
  - 留话：真实库的拒收与空态
  - 协调对话：Codex 写方案（发现「依赖」被误接、汇总要等前几路，已修）
  - 分路：Codex 当第 1 路两轮（第一轮先跑了写共享清单的脚本，开场加禁令后第二轮照做）
- **没验**：以上所有界面都没在 Mesa Dev 窗口里实际点过；Claude Code / Kimi 当协调对话与分路；Windows。
