# 出图（Mesa 出图模型）

Mesa 启动你时在环境变量 `MESA_IMAGE_TOOL` 里放了出图工具的路径。它用用户在 Mesa 连接页左栏「出图模型」选的网关和模型，密钥由工具自己取——**你看不到也不需要密钥，不要去找、不要打印任何密钥**。

## 先确认能用

macOS / Linux 跑 `"$MESA_IMAGE_TOOL" image --list`，Windows PowerShell 跑 `& $env:MESA_IMAGE_TOOL image --list`。输出第一行是这次不加 `--model` 时用的模型（用户在 Mesa 聊天输入框「出图」胶囊里给这个对话选过的写「本对话选的出图模型」，否则是连接页默认），后面列出各网关能直接文生图的模型，以及「仅改图可用（须带 `--image`）」的专用改图模型。`MESA_IMAGE_TOOL` 为空：说明不是在 Mesa 里启动的、当前无头任务未授权联网，或这版 Mesa 还没带出图工具——停下告诉用户，不要改用别的方式绕过。第一行说「还没配置出图模型」：请用户到 Mesa 连接页左栏「出图模型」里选一个，或者用户指定了模型时加 `--model`。

## 聊天里的出图模式

用户那句话第一行是 `使用 image-gen 技能出图（出图模型 X，用 $MESA_IMAGE_TOOL 出图工具）：`（改图写「改图」）时，是用户在 Mesa 输入框打开了「出图」，下面才是描述：

- 这一句**必须**调出图工具出图（改图带 `--image` 原图），不要改用 matplotlib / SVG / HTML 等代码自己画，也不要只回文字；出不来就照实转述工具报错。
- 模型就用 X：命令里加 `--model X`（工具默认也用这个对话选的，但更新前开的对话读不到），不要自己换。之后「再来一张」「换个颜色」照样用它；用户在胶囊里换了模型，下一句第一行会写新的。
- X 做不到要求（画幅、分辨率、透明底，见下文「各家能做到什么」）：照样用 X 出，交付时按 `note:` 说清差在哪，建议在输入框胶囊里换哪个模型。
- 写成 `出图模型 A、B、C 各出一版对比` 时：每个模型各调一次，`--model` 分别写 A、B、C，描述和参数完全一样（描述写进一个 `--prompt-file` 共用；改图都用同一张原图）。能同时跑就同时跑（macOS / Linux 每条命令输出重定向到各自的日志、末尾加 `&`，最后 `wait` 再读日志），总耗时约等于最慢的那个；文件名带模型短名（如 `cover-gpt-image-2.5.png`），不互相覆盖。回复里按模型逐行写出每张图的完整路径和各自的 `note:`，某个失败照实写、不影响其余几张；不替用户挑，问要哪张。

## 动笔前先定三件事

> **先判分工与期刊 AI 红线**：
> - **科研机理图、实验流程图、技术路线图、图形摘要（TOC）**：交给 **schematic-forge** 出可编辑 PPTX + SVG，不要绕过它直接交带字死图 PNG。
> - **独立对话里如果用户要放进正式期刊正文**（尤其是 Springer Nature / EER / Elsevier / ACS / RSC / Wiley 等明确限制或禁止生成式 AI 图像进科研正文的期刊）：**先提醒合规风险并问一句走哪条路**——推荐零 AI 像素路线（有 Blender 走 `blender-research` 3D 插画 + `schematic-forge` 矢量叠层，没装 Blender 走 `schematic-forge` 纯矢量极简风）；只有用户确认目标期刊允许，或用于**封面艺术图 / 组会 PPT / 海报 / 概念配图 / 构思草图 / 已有图改图**时，才用本技能（`$MESA_IMAGE_TOOL`）生成图像。

1. **用途**：草图 / 看方向、schematic-forge 无字主视觉底图、封面、海报/概念配图、图标。用途决定画幅、分辨率和风格，用户没说就按下表取默认，交付时说明取了什么。
2. **画幅**：`--size` 写宽高，比如方图 `1024x1024`、横版 `1536x1024`、竖版封面 `1024x1536`。期刊对封面或配图有尺寸要求时按要求比例写。
3. **清晰度**：看方向用默认就行；要放进稿件、要打印的才加 `--resolution` / `--quality`（见下文），它们更慢、更贵。

| 用途 | 画幅 | 清晰度 | 风格默认 |
|---|---|---|---|
| 草图、看方向 | 默认 | 默认，可加 `--n 2` 多出几张让用户挑 | 按用户说的 |
| 示意图无字主视觉底图（配 schematic-forge） | 按面板比例，常用横版 `1536x1024` | `--resolution 2k` | 2.5D 科研渲染或扁平矢量风、纯白底、绝对无字、少装饰 |
| 概念配图、海报 | 按版面或期刊要求 | `--resolution 2k` | 主题明确、留白干净，一眼看懂一个主要信息 |
| 封面 | 竖版 `1024x1536` | `--resolution 2k` 或 `4k` | 可以写实或艺术化，留出放标题的空白 |
| 图标、贴纸 | 方图 `1024x1024` | `--transparent` | 简单图形、粗轮廓、透明底 |

## 描述怎么写

描述用英文写，效果通常更稳；用户说中文时由你翻译。按这个顺序写成一段话，每项一两个短语，不要堆砌形容词：

1. **主体**：画什么，数量和相互位置写清（「three cells in a row, the middle one larger」）。
2. **构图**：视角、主体在画面哪里、留白（「centered, top-down view, generous white space on the right」）。
3. **风格**：flat vector illustration / isometric diagram / watercolor / photorealistic 等，挑一个，不要混写。
4. **配色与光线**：给两三个具体颜色或色系（「muted blue and orange palette」），写实图再写光线。
5. **不要什么**：「no text, no watermark, no extra objects」——这样写比单独列一串负面词更管用。

科研无字插画 / `schematic-forge` 主视觉底图的写法示例：

```text
A clean flat vector diagram of a lipid nanoparticle delivering mRNA into a cell:
the nanoparticle on the left, the cell membrane in the middle, mRNA strands released
inside the cytoplasm on the right. Side view, left-to-right flow, white background,
thin dark outlines, muted blue and coral palette, no text, no labels.
```

描述超过一两行、带引号或换行时，写进文件用 `--prompt-file`。这个文件就是留档用的 `<图名>.prompt.txt`（见「放哪、怎么交代」）：开头以 `#` 起头的行是备注，工具不会发给模型。

## 图里的文字

出图模型写短标题多数能写对，但仍会重字、漏字、拼错，还会自己编出没要的小字；字越多越长越容易错。

- **默认不让模型画文字**：描述里写 `no text, no labels`。标注、图例、标题交给后面一步：示意图、图形摘要按 schematic-forge 技能写图纸、文字是真文字（出图模型只画无字 2.5D 主视觉底图或局部图标）。
- 用户确实要图里带字（海报标题、标牌）：字越少越好，原文写进引号，比如 `a title that reads "OPEN LAB"`、`标题写着“开放日”`。2026-10-30 用一中一英两个短标题实测：gpt-image-1.5 / 2.5、gemini-3-pro-image、qwen-image-2.0-pro、wan2.6-t2i 都写对了；豆包 seedream-4 把「细胞信号实验室」写成了「细胞信号实验验室」；gemini-3.1-flash-image 标题对，却自己编了日期、地点等小字。要字时优先用写对的那几家，描述里加 `no other text`。
- 长句、小字、公式、图例，任何模型都不可靠，不要让模型画。
- 画完必须逐字核对（见「画完自检」），错一个字就不能当成品交。

## 出图

```bash
"$MESA_IMAGE_TOOL" image --prompt "…" --size 1536x1024 --out figures/mechanism.png
```

Windows PowerShell：`& $env:MESA_IMAGE_TOOL image --prompt "…" --out figures/mechanism.png`

可选参数：

- `--model <模型名>`：用户点名某家（如 `gemini-3-pro-image`、`doubao-seedream-4-0-250828`）或下表说该换模型时才加（出图模式见上文，不自己换）；工具会去有这个模型的网关找。
- `--size 1536x1024`：画幅。OpenAI 系按尺寸，Gemini 系换成最接近的宽高比；有的模型只出自己支持的尺寸。
- `--resolution 1k|2k|4k`：分辨率档位，按 `--size` 的比例把长边放到 1024 / 2048 / 4096 像素。4K 一张常要 2 到 4 分钟。
- `--quality low|medium|high`：画质档位。`low` 出草图快，`high` 用于定稿。
- `--transparent`：透明背景（png）。
- `--n 2`：一次几张（1–4），文件名自动加 `-1`、`-2`；Gemini 系几张同时出，不会多等几倍时间。
- `--prompt-file 描述.txt`：从文件读描述；文件开头以 `#` 起头的行跳过不发。

一张图常要 20 秒到 3 分钟，带 `--image` 改图常更久（2026-10-31 gpt-image-2.5 改一张 1536x1024 用了 260 秒），耐心等，别重复提交；你的命令工具有超时设置的，设到 6 分钟以上。在带沙箱的 Agent 里（如 Codex 的 workspace-write），命令联网会被拦、报「连不上网关」：按你自己的提权流程申请联网重跑这一条，不要改用别的方式。

### 输出怎么读

成功时每张图输出 `saved: 绝对路径`（**以这一行为准**：扩展名按实际格式改，模型回 JPEG 就存成 .jpg；同名文件已存在时自动加 `-2`，不覆盖）和 `size: 宽x高`（实际出了多大）。

可能还有一行 `note:`，**必须读，并转告用户**。网关收下参数不等于模型照做，工具出完图会按实际的图核对：不支持的选项（比如给 Gemini 加 `--transparent`）说明没生效；网关拒收某个选项时去掉它自动重出一次并说明去掉了什么；画幅和 `--size` 对不上、分辨率没到 `--resolution` 那档、要了透明底但没有透明像素，都会写明。

`note:` 说没达到要求，这张图就不能当成按要求交付的成品：要么换模型重出（用户同意后加 `--model`），要么交给用户时讲清差在哪。

### 各家能做到什么

2026-10-30 在一个中转网关上实测。用户的网关可能不同，**以 `size:` 和 `note:` 为准**，这张表只用来提前挑模型：

| 模型 | 按 `--size` 出画幅 | 能到多大 | `--quality` | `--transparent` |
|---|---|---|---|---|
| gpt-image-1.5、gpt-image-1-mini | 只有 1024×1024、1536×1024、1024×1536 三种 | 1536（工具保留画幅不强拉 2K，并在 `note:` 说明） | 有效 | 有效 |
| gpt-image-2、gpt-image-2.5、chatgpt-image-* | **不按**：gpt-image-2 / 2.5 画幅常由模型自定（10-30 实测近方形约 1250 见方；11-05 要 1536x1024 出 1774x887） | 约 1250–1800 | 网关接受 | 有效 |
| gemini-3-pro-image、gemini-3.1-flash-image、gemini-nano-banana-2.1 | 按（取最接近的宽高比） | 2K、4K | 不支持 | 不支持 |
| gemini-3.1-flash-lite-image、gemini-2.5-flash-image | 按 | 只出 1K | 不支持 | 不支持 |
| 豆包 doubao-seedream-4-0 | 按 | 4K | 不支持 | 不支持 |
| 通义 wan2.5 / wan2.6-t2i、qwen-image-2.0-pro | 按 | 未测大图 | 不支持 | 不支持 |

所以：要横版、竖版别用 gpt-image-2 / 2.5，换 gpt-image-1.5、Gemini 或豆包；要 2K / 4K 换 gemini-3-pro-image 或豆包 seedream-4；要透明底用 gpt-image 系。默认模型做不到时，告诉用户换哪个、为什么，用户同意了再加 `--model`。

- `wan2.6-image`、`qwen-image-edit-*`、`doubao-seededit-*` 只能改图（`--list` 会另列在「仅改图可用」下），文生图要用 `wan2.6-t2i` 等；豆包默认的右下角「AI生成」水印工具已经替你关了。
- 境外官方网关或图片地址（如 x.ai 的 `imgen.x.ai`）直连不通时，工具会自动尝试走 Mesa「设置 → 网络」里填的出网代理；没填代理时请用户去那里补上。

## 画完自检

每张图交付前你自己先看：能读图就用读文件的工具打开 `saved:` 那张图（太大时先缩小一份再看，别把几十 MB 的原图直接读进来）。逐条对：

1. **要的东西都在**：主体、数量、位置、朝向和描述一致；没有多出来的手指、部件、物体。
2. **科学上没画错**：结构、方向、比例不违背常识（细胞膜是双层、箭头方向对、分子没有凭空多出来的键）。拿不准的点照实告诉用户，不要替用户判定「差不多」。
3. **文字**：要求无字的确实没字；有字的逐字核对（重字、漏字、错字），也要找模型自己编出来的小字（日期、地点、署名、假的说明文字），有一处就不合格。
4. **画面质量**：没有明显糊、拼接缝、变形；`size:` 的画幅和大小符合要求，`note:` 没说哪项没达到。

不合格就改描述再出，说清这次改了什么。最多重出三轮；三轮还不行就停下，把最好的一张交给用户，说明哪里还不对、建议换哪个模型或让人手工修。不能看图时直说「我看不了图，请你确认」，不要声称检查过。

## 在已有图上改

用户发来一张图并说怎么改时，带上原图改，不要只凭文字重画——重画会丢掉原图的构图和细节。要改的图在消息里是这几种写法：

- `原图：路径`：Mesa 聊天里点图「接着改」发来的，就是要改的那张，`--image` 用它；
- `标注图：路径`：同一张图上画了框、箭头、编号（①② 对应消息里的话），只用来看位置。你能看图就用读文件的工具看它，把位置写进描述；看不了图就只按文字改，**不要**把标注图传给 `--image`（框和编号会被画进新图）；
- 单独一行的图片路径：用户粘贴或拖进来的图，也是要改的那张。
- 消息里另有 `图纸：…/figure.json` 一行时，这张是示意图（schematic-forge 渲出的）：**不要用出图模型改**，按 schematic-forge 技能改图纸重渲（人改过的 PPTX 就在它上面局部改）。

```bash
"$MESA_IMAGE_TOOL" image --image 原图.jpg --prompt "Keep everything else the same, change the straw hat to a blue baseball cap" --out figures/cover-v2.png
```

- 描述只写要改的地方，并写明其余保持不变；用户说中文时照样可以翻成英文描述。
- 「去背景」「擦掉某处」「换画幅」也走这条：分别写成 remove the background / remove the … / extend to 16:9 等。要真正透明的底，用 gpt-image 系加 `--transparent`。
- 新图另存一个名字（`-v2`、`-blue-cap`），不覆盖原图；`--image` 最多 4 张（比如「把这两张合成一张」）。
- 改完同样走「画完自检」，额外核对没要改的地方确实没变：原图和新图各缩小一份，两张都打开对照着看（只看新图看不出哪里变了），交付时说清对照看到的——要加的加在了哪、其余哪些部分和原图一致、哪里有出入。

## 用进论文时

- 期刊一般要求按成品尺寸 300 dpi：单栏宽约 8.5 cm，约 1000 像素；双栏宽约 17.5 cm，约 2100 像素。要进稿件的图至少 `--resolution 2k`，出不到就照实告诉用户这张只够当草图或预览。
- 出图模型不会把小图「变清晰」：不要拿放大、插值冒充高分辨率。
- 尺寸、字体、配色的期刊规格归 figure-forge 管；出图模型只出插画部分，规格对齐和叠字在后面一步做。
- **期刊 AI 图像政策前置核对**：Springer Nature（含 *Nature* 系列 / *EER*）、Elsevier（含 *Cell* / *Joule*）等主流出版商严格限制或禁止生成式 AI 图像进入正式科研正文图（封面艺术图或概念草图除外）。用户说明要放进正式论文正文时，先提醒该红线并确认是否改走零 AI 像素管线（`blender-research` / `schematic-forge` 纯矢量）；确已核实允许再出图，交付时提醒在图注或方法里如实披露模型名。

## 放哪、怎么交代

- 研究项目放 `figures/`，编程项目放用户指定的位置（没说就问）；文件名用英文短词。
- 把最终用的描述原文和参数记下来（同目录 `<图名>.prompt.txt`），方便重画。开头用 `#` 行写参数，出完图按 `model:` 行补上实际模型；改图的写上底图路径。`#` 行之后只放描述，同一个文件直接给 `--prompt-file` 用：

  ```text
  # 模型 gpt-image-2.5 · --size 1536x1024 · --resolution 2k
  # 底图 figures/rainy-seaside.png（改图时写）
  Keep everything else exactly the same. Add one person ...
  ```
- 交付时说清：用的哪个模型、画幅和分辨率、存在哪、自检看到了什么（不要把描述换个说法当结论）、还有哪些拿不准，并说明是 AI 生成的示意图。写出图片完整路径，Mesa 聊天会直接显示成图、点图可接着改。

## 边界

- 不生成冒充实验观测、显微照片、电泳条带、病理切片、仪器截图等「看起来像真实数据」的图；用户要的话说明风险，只做明确标注为示意的版本。
- 数据驱动的图（曲线、柱状图、统计图）用脚本画，不用出图模型。
- 失败时照实转述工具的报错（网关没开通这个模型、额度不足、内容被拒等），不要换个模型偷偷重试；可以建议用户换哪个模型。自检不合格时重出属于正常流程，不算偷偷重试，但要在交付时说重出了几次。
